# Whitelist & Users (Rotating)

Rotating currently requires a username and password. **IP whitelist for Rotating is coming soon.**

Create credentials in [Whitelist & Users](https://www.joyproxy.com/admin-authorization.html) before you generate Rotating endpoints.

### Username / password

- Open Whitelist & Users → Username / Password
- Create a credential (username 3+ characters, password 6+ characters)
- When you connect, use this **password** together with the **generated username** from Endpoints. That long username encodes geo and session. Do not type the short credential name as the proxy user, and do not edit the generated string.

**IP whitelist**IP whitelist for Rotating is **coming soon**. You cannot skip username/password on Rotating today. Whitelist still works for Static and Custom — see those guides.
