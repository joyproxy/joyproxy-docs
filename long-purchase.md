# Purchase Static Residential

Dedicated residential lines with country targeting locked in at checkout. Select **Residential** + **Static** on the purchase page.

- Sign in and open [Purchase → Static](https://www.joyproxy.com/admin-purchase.html?tab=long-term)
- Confirm network type is **Residential**
- Search or pick a country (optional province / city)
- Pick a duration plan (daily / weekly / monthly / yearly)
- Review checkout → **Buy Now**
- Allocation becomes active in [My Proxies](https://www.joyproxy.com/admin-my-orders.html)

**📌 Related**Business ISP or Datacenter static lines use the same Static purchase flow — switch network type on the purchase page, or see sections 2.4 / 2.5.
