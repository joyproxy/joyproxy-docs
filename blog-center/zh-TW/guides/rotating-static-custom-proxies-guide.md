# 動態、靜態與自訂住宅代理：哪款適合您的業務架構？

在 JoyProxy 的產品體系中，代理服務被劃分為三大核心系列：**動態住宅代理（Rotating Residential）** 、**靜態獨享住宅代理（Static Residential）** 以及**自訂住宅代理（Custom Residential）** 。這些分類並非行銷話術，而是直接對應了底層的技術實現、IP 輪換生命週期以及連接埠控制顆粒度。

在管理主控台中，無論選購哪款產品，均在統一的「代理 IP」主選單下完成。您都可以透過「購買代理」、「我的代理」、「白名單與用戶」以及「端點產生器」這四個標準化模組完成從採購到擷取的完整流程。

## 1\. 動態住宅代理（按流量計費，海量池輪換）

**適用情境：** 每一次網絡連線或每個短時工作階段都應當呈現為來自全球各地的不同真實家庭寬頻出口。

  * **計費模式：** 按實際消耗的資料流量包（GB）計費，預付扣抵，流量永久有效；
  * **行為特徵：** 按需動態產生端點。平台在伺服器端自動調度家庭寬頻 IP 池，支援按請求更換 IP 或維持短時工作階段保持；
  * **核心業務：** 大規模網絡資料爬取、公開電商價格監控、搜尋引擎 SERP 擷取、廣告欺詐驗證；
  * **地域定位：** 擷取端點時可自由指定國家、省份、城市（基於精準 GeoNames 定位）。



## 2\. 靜態獨享住宅代理（按時長租賃，IP 絕對固定）

**適用情境：** 目標平台要求您的網絡身分在數天、數月甚至數年內保持高度穩定與一致。

  * **計費模式：** 按 IP / 連接埠的數量與租期（日租、月租、季租、年租）計費；
  * **行為特徵：** 分配給您的 `host:port` 在租賃週期內出口 IP 永不跳動，城市歸屬在購買時鎖定；
  * **核心業務：** 跨境電商多店鋪日常營運（Amazon、eBay、Shopee）、PayPal / Stripe 財務後台、社群主帳號精細化維護；
  * **地域定位：** 結帳時支援在國家乃至指定省份、都會區中精準鎖定。



## 3\. 自訂住宅代理（多埠叢集 + 可控定時輪換）

**適用情境：** 介於純動態與純靜態之間的企業級形態。在單一訂單中管理一組專屬連接埠，既具備靜態埠的專屬獨立性，又賦予了**自主設定定時輪換（例如每 N 分鐘刷新）** 和**不換埠自由切換國家地區** 的彈性。

  * **計費模式：** 按連接埠數量 × 租用時長計費；
  * **行為特徵：** 單帳號下劃分多個彼此隔離的測試槽位（店鋪通道、自動化測試分支）；
  * **核心業務：** 跨區域自動化迴歸測試、中型社群矩陣自動化管理、需要固定入口但週期性變更出口的業務通道。

## 生產環境常見迷思警示

  * **迷思一：** 用頻繁變動 IP 的「動態代理」直接登入高權重的電商店鋪。短時間內跨城市甚至跨大洲漂移，會立刻觸發平台的風控審查甚至停權；
  * **迷思二：** 為只擷取公開文字的輕量爬蟲採購昂貴的「獨享靜態 IP」。這不僅造成成本大幅浪費，且單一 IP 極易被目標站的速率限制攔截；
  * **迷思三：** 把自訂 IP 誤當成按量流量包使用——自訂 IP 是按連接埠獨佔時長計費，適合需要固定入口連線的基礎設施。



業界成熟團隊的標準做法通常是：**用動態住宅流量池承載高並發的資料收集器，用靜態住宅與自訂連接埠承載核心帳號的登入與互動。** 新用戶可充分利用 [$5 美元新手體驗金](https://www.joyproxy.com/blog/getting-started/five-dollar-credit-onboarding/)，分別擷取動態與靜態端點進行完整測試。
