# 別把出口 IP 當入口：JoyProxy 靜態 ISP 與資料中心代理設定全解

在購買了 JoyProxy 的 **ISP（獨享靜態住宅）代理** 或 **靜態資料中心代理** 之後，不少用戶在設定防關聯瀏覽器或連線程式碼時，經常會遇到這樣令人困惑的現象：

* 無論怎麼測試，連線測試始終提示 `Connection Timed Out`（連線逾時）或 `Connection Refused`（連線被拒絕）；
* 檢查控制台，該靜態節點明明顯示「正常運作中」；
* 檢查密碼與白名單，似乎也挑不出毛病。

排查過上千起客服案例後，我們發現超過 80% 的新手連線失敗，都源於同一個極具迷惑性的觀念混淆：**把控制台裡的「出口 IP（Dedicated Exit IP）」直接當成了代理「入口主機（Host）」填進了客戶端**。

本文將徹底釐清靜態代理的雙層網路架構，詳解 IP 白名單免密與帳密認證的設定技巧，並分享在多帳號防關聯場景下的指紋調校實踐。

## 一、核心概念：Entry Point（入口）與 Exit IP（出口）的差異

靜態代理與傳統的雲端伺服器不同。為了保證高可用、網路加速以及防 DDoS 攻擊，靜態代理在架構上分為**客戶端接入層**與**公網出口層**：

```text
你的裝置 (腳本/防關聯瀏覽器)
   │
   ▼ [透過 Entry Point 建立連線]
JoyProxy 接入閘道 (isp.joyproxy.com:專用連接埠)
   │
   ▼ [內部專用高速專線中繼]
專屬靜態出口節點 (Dedicated Exit IP，如 68.195.42.18)
   │
   ▼ [對外呈現真實住宅/機房 IP]
目標平台 (Amazon / Stripe / Google / TikTok)
```

在 JoyProxy 控制台的 **我的代理（My Proxies）** 或 **提取中心（Endpoint Generator）** 中，你會看到兩個與 IP 相關的欄位：

1. **入口位址（Entry Point）**：
   * 格式通常為 `isp.joyproxy.com:連接埠` 或 `dc.joyproxy.com:連接埠`（例如 `isp.joyproxy.com:10001`）。
   * **這是你的客戶端唯一需要連線的伺服器主機與連接埠！** 所有的代理連線交握都是在這裡發生的。
2. **專屬出口 IP（Dedicated Exit IP）**：
   * 格式為一般的公網 IP 位址（例如 `68.195.42.18`，歸屬於美國紐約 AT&T）。
   * **這是遠端目標網站最終看到的公網身分標識。** 該節點只負責向外發送與接收資料，**它本身並沒有對外開放 10001 連接埠接受代理請求**。

**結論**：如果你把 `68.195.42.18` 和連接埠 `10001` 填進瀏覽器，你的電腦就會嘗試直接向一台沒有開放該連接埠的普通終端發起代理交握，結果自然是永遠逾時或連線被拒。

## 二、兩種認證模式：IP 白名單免密 vs 帳密連線

與動態代理不同，靜態代理（ISP / 資料中心）為用戶分配了**完全獨立的專屬連接埠**。因此，它在認證方式上更加靈活，支援兩種接入方式：

### 模式 1：IP 白名單免密連線（最推薦、最省心）
如果你在固定辦公網路、家庭寬頻或有一台固定的雲端伺服器（VPS），推薦使用白名單模式：
1. 登入 JoyProxy 控制台，進入 **使用者與白名單（Users & Whitelist）**；
2. 在 **IP 白名單** 欄目中，將你本機電腦或伺服器的當前公網 IP 新增進去；
3. 設定客戶端時：
   * **代理主機**：填入控制台的 Entry Point（如 `isp.joyproxy.com`）
   * **代理連接埠**：填入購買分配的專用連接埠（如 `10001`）
   * **使用者名稱 / 密碼**：**直接留空不填！**

**適用場景**：
* **Windows / macOS 系統級全域代理**：作業系統自帶的代理設定面板往往不支援儲存帳號密碼，白名單模式是唯一的選擇；
* **Playwright / Puppeteer 啟動參數**：無需在 `--proxy-server` 啟動參數中以純文字暴露帳密；
* **Docker / 腳本多執行緒部署**：大幅簡化設定檔維護。

### 模式 2：帳號密碼認證連線
如果你的本機寬頻公網 IP 經常變動（如手機熱點、行動辦公），或者你在多個團隊成員之間共享該節點，可以使用帳密模式：
* 在「使用者與白名單」中設定好認證帳號與密碼；
* 在客戶端填入 Entry Point、連接埠，以及對應的使用者名稱與密碼即可。

## 三、防關聯瀏覽器環境設定最佳實踐

靜態 ISP 代理最核心的價值，就是為高敏感電商店鋪、金融帳戶以及社群矩陣提供 **1:1 獨佔、長期固定且信譽極高** 的網路環境。

在 AdsPower、BitBrowser、Hubstudio 等工具中整合時，建議注意以下細節：

1. **協定選擇**：優先選擇 `HTTP` 或 `SOCKS5`（JoyProxy 靜態節點原生同時支援兩種協定）；
2. **同城指紋自動對齊**：務必開啟瀏覽器設定中的**「依據 IP 自動設定語言、時區與地理經緯度」**：
   * 如果購買的是紐約（AT&T）的靜態 ISP，瀏覽器啟動後時區應自動同步為 `America/New_York (EDT/EST)`，語言首選 `en-US`；
   * 嚴禁在靜態住宅代理之上隨意開啟額外的 VPN 或二次中繼，避免 WebRTC 洩漏本機真實路由。
3. **一店一號一 IP**：為每一個核心帳號分配單獨的連接埠，切勿在同一個靜態 IP 上交叉登入多個競爭或同類店鋪，維持最高等級的安全隔離。

## 四、突發風控怎麼辦？善用「免費換 IP」權益無損容災

在實際營運中，哪怕網路本身沒有任何問題，有時也可能因為本地指紋環境除錯失誤（如不小心誤刪了 Cookie、觸發了平台嚴格的異常頻次偵測），導致該出口 IP 在某個特定網站短期受阻。

傳統代理商遇到這種情況，通常會要求用戶「重新自費購買一個新 IP」。

而在 JoyProxy 中，**所有獨享靜態 ISP 與資料中心代理，在租期內均享有一次無損免費更換 IP 的權益**：
1. 登入控制台，進入 **我的代理（My Proxies）** 列表；
2. 找到需要更換的靜態節點，點擊操作欄中的 **更換 IP（Change IP）**；
3. 系統會在同一個國家或城市區域內，自動為你調度分配一個**全新的純淨出口 IP**；
4. **關鍵便利**：更換完成後，你的 **Entry Point 與專屬連接埠保持不變**，你甚至不需要重新修改腳本或防關聯瀏覽器的連線設定，重新整理即可立即生效！
