# 动态、静态与自定义住宅代理：哪款适合你的业务架构？

在 JoyProxy 的产品体系中，代理服务被划分为三大核心线：**动态住宅代理（Rotating Residential）** 、**静态独享住宅代理（Static Residential）** 以及**自定义住宅代理（Custom Residential）** 。这些分类并非营销概念，而是直接对应了底层的技术实现、IP 轮换生命周期以及端口控制颗粒度。

在管理控制台中，无论选购哪款产品，都是在统一的「代理 IP」主菜单下完成。你均可以通过「购买代理」、「我的代理」、「白名单与用户」以及「端点生成器」这四个标准化模块来完成从采购到提取的全流程。

## 1\. 动态住宅代理（按流量计费，海量池轮换）

**适用场景：** 每一次网络请求或每个短时任务都应当呈现为来自全球各地的不同真实家庭宽带出口。

  * **计费模式：** 按实际消耗的数据流量包（GB）计费，预付扣费，流量不过期；
  * **行为特征：** 按需动态生成端点。平台在服务端底层自动调度家庭宽带 IP 池，支持按请求更换 IP 或保持短时粘滞会话；
  * **核心业务：** 大规模网络数据爬取、公开电商价格监控、搜索引擎 SERP 抓取、广告欺诈验证；
  * **地域定位：** 提取端点时可自由指定国家、大州、城市（基于精确 GeoNames 定位）。



## 2\. 静态独享住宅代理（按时长租赁，IP 绝对固定）

**适用场景：** 目标平台要求你的网络身份在数天、数月甚至数年内保持高度稳定与一致。

  * **计费模式：** 按 IP / 端口的数量与租期（日付、月付、季付、年付）计费；
  * **行为特征：** 分配给你的 `host:port` 在租赁周期内出口 IP 永不跳动，城市归属在购买时锁定；
  * **核心业务：** 跨境电商多店铺日常管理（亚马逊、eBay、Shopee）、PayPal / Stripe 财务后台、社媒主账号精细化运维；
  * **地域定位：** 下单时支持在国家乃至指定省份、大都市圈中精准锁定。



## 3\. 自定义住宅代理（多端口集群 + 可控定时轮换）

**适用场景：** 介于纯动态与纯静态之间的企业级形态。在一个订单中管理一组专属端口，既具备静态端口的专属独立性，又赋予了**自主设定定时轮换（例如每 N 分钟刷新）** 和**不换端口自由切换国家地区** 的灵活性。

  * **计费模式：** 按端口数量 × 租用时长计费；
  * **行为特征：** 单账户下划分多个彼此隔离的测试槽位（店铺通道、自动化测试分支）；
  * **核心业务：** 多区域自动化回归测试、中型社媒矩阵自动化管理、需要固定入口但周期性变更出口的业务通道。

## 生产环境常见误区警示

  * **误区一：** 用频繁变动 IP 的「动态代理」直接登录高权重的电商店铺。短时间内跨城市甚至跨大洲漂移，会立刻触发平台的风控审计甚至冻结；
  * **误区二：** 为只抓取公开文本的轻量爬虫采购昂贵的「独享静态 IP」。这不仅造成成本大幅浪费，且单一 IP 极易被目标站的限频规则拦截；
  * **误区三：** 把自定义 IP 误当成按量流量包使用——自定义 IP 是按端口独占时长计费，适合需要固定端口连接的基础设施。



行业成熟团队的标准做法通常是：**用动态住宅流量池承载高并发的数据收集器，用静态住宅与自定义端口承载核心账号的登录与交互。** 新用户可以充分利用 [$5 美元新手体验金](https://www.joyproxy.com/blog/getting-started/five-dollar-credit-onboarding/)，分别提取动态和静态端点进行全链路验证。
