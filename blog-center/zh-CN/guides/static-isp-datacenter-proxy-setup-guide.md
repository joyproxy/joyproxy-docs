# 别把出口 IP 当入口：JoyProxy 静态 ISP 与数据中心代理配置全解

在购买了 JoyProxy 的 **ISP（独享静态住宅）代理** 或 **静态数据中心代理** 之后，不少用户在配置指纹浏览器或连接代码时，经常会遇到这样令人抓狂的现象：

* 无论怎么测试，连接测试始终提示 `Connection Timed Out`（连接超时）或 `Connection Refused`（连接被拒绝）；
* 检查控制台，该静态节点明明显示“正常运行中”；
* 检查密码和白名单，似乎也挑不出毛病。

排查过上千起工单后，我们发现超过 80% 的新手连接失败，都源于同一个极具迷惑性的概念混淆：**把控制台里的“出口 IP（Dedicated Exit IP）”直接当成了代理“入口主机（Host）”填进了客户端**。

本文将彻底澄清静态代理的双层网络架构，详解 IP 白名单免密与账密认证的配置技巧，并分享在多账号防关联场景下的指纹调优实践。

## 一、核心概念：Entry Point（入口）与 Exit IP（出口）的区别

静态代理与传统的云服务器不同。为了保证高可用、网络加速以及防 DDoS 攻击，静态代理在架构上分为**客户端接入层**与**公网出口层**：

```text
你的设备 (脚本/指纹浏览器)
   │
   ▼ [通过 Entry Point 建立连接]
JoyProxy 接入网关 (isp.joyproxy.com:专用端口)
   │
   ▼ [内部专用高速专线中继]
专属静态出口节点 (Dedicated Exit IP，如 68.195.42.18)
   │
   ▼ [对外呈现真实住宅/机房 IP]
目标平台 (Amazon / Stripe / Google / TikTok)
```

在 JoyProxy 控制台的 **我的代理（My Proxies）** 或 **提取中心（Endpoint Generator）** 中，你会看到两个与 IP 相关的字段：

1. **入口地址（Entry Point）**：
   * 格式通常为 `isp.joyproxy.com:端口` 或 `dc.joyproxy.com:端口`（例如 `isp.joyproxy.com:10001`）。
   * **这是你的客户端唯一需要连接的服务器主机和端口！** 所有的代理连接握手都是在这里发生的。
2. **专属出口 IP（Dedicated Exit IP）**：
   * 格式为普通的公网 IP 地址（例如 `68.195.42.18`，归属于美国纽约 AT&T）。
   * **这是远端目标网站最终看到的公网身份标识。** 该节点只负责向外发送和接收数据，**它本身并没有对外开放 10001 端口接受代理请求**。

**结论**：如果你把 `68.195.42.18` 和端口 `10001` 填进浏览器，你的电脑就会尝试直接向一台没有开放该端口的普通终端发起代理握手，结果自然是永远超时或连接被拒。

## 二、两种认证模式：IP 白名单免密 vs 账密连接

与动态代理不同，静态代理（ISP / 数据中心）为用户分配了**完全独立的专属端口**。因此，它在认证方式上更加灵活，支持两种接入方式：

### 模式 1：IP 白名单免密连接（最推荐、最省心）
如果你在固定办公网络、家庭宽带或有一台固定的云服务器（VPS），推荐使用白名单模式：
1. 登录 JoyProxy 控制台，进入 **用户与白名单（Users & Whitelist）**；
2. 在 **IP 白名单** 栏目中，将你本地电脑或服务器的当前公网 IP 添加进去；
3. 配置客户端时：
   * **代理主机**：填入控制台的 Entry Point（如 `isp.joyproxy.com`）
   * **代理端口**：填入购买分配的专用端口（如 `10001`）
   * **用户名 / 密码**：**直接留空不填！**

**适用场景**：
* **Windows / macOS 系统级全局代理**：操作系统自带的代理设置面板往往不支持保存账号密码，白名单模式是唯一的选择；
* **Playwright / Puppeteer 启动参数**：无需在 `--proxy-server` 启动参数中以明文暴露账密；
* **Docker / 脚本多线程部署**：极大简化配置文件维护。

### 模式 2：账号密码认证连接
如果你的本地宽带公网 IP 经常发生变化（如手机热点、移动办公），或者你在多个团队成员之间共享该节点，可以使用账密模式：
* 在“用户与白名单”中配置好认证账号和密码；
* 在客户端填入 Entry Point、端口，以及对应的用户名与密码即可。

## 三、指纹浏览器环境配置最佳实践

静态 ISP 代理最核心的价值，就是为高敏感电商店铺、金融账户以及社交矩阵提供 **1:1 独占、长期固定且信誉极高** 的网络环境。

在 AdsPower、BitBrowser、Hubstudio 等工具中集成时，建议注意以下细节：

1. **协议选择**：优先选择 `HTTP` 或 `SOCKS5`（JoyProxy 静态节点原生同时支持两种协议）；
2. **同城指纹自动对齐**：务必开启浏览器配置中的**“基于 IP 自动设置语言、时区与地理经纬度”**：
   * 如果购买的是纽约（AT&T）的静态 ISP，浏览器启动后时区应自动同步为 `America/New_York (EDT/EST)`，语言首选 `en-US`；
   * 严禁在静态住宅代理之上随意开启额外的 VPN 或二次中继，避免 WebRTC 泄漏本地真实路由。
3. **一店一号一 IP**：为每一个核心账号分配单独的端口，切勿在同一个静态 IP 上交叉登录多个竞争或同类店铺，维持最高级别的安全隔离。

## 四、突发风控怎么办？利用“免费换 IP”权益无损容灾

在实际运营中，哪怕网络本身没有任何问题，有时也可能因为本地指纹环境调试失误（如不小心误删了 Cookie、触发了平台严格的异常频次检测），导致该出口 IP 在某个特定站点短期受阻。

传统代理商遇到这种情况，通常会要求用户“重新自费购买一个新 IP”。

而在 JoyProxy 中，**所有独享静态 ISP 与数据中心代理，在租期内均享有一次无损免费更换 IP 的权益**：
1. 登录控制台，进入 **我的代理（My Proxies）** 列表；
2. 找到需要更换的静态节点，点击操作栏中的 **更换 IP（Change IP）**；
3. 系统会在同一个国家或城市区域内，自动为你调度分配一个**全新的纯净出口 IP**；
4. **关键便利**：更换完成后，你的 **Entry Point 与专属端口保持不变**，你甚至不需要重新修改脚本或指纹浏览器的连接配置，刷新即可立即生效！

## 五、静态代理 vs 动态代理配置速查表

| **接入入口 (Host:Port)** | 控制台专属 Entry Point（如 `isp.joyproxy.com:10001`） | 全球统一网关：`gate.joyproxy.com:9001` |
| **出口 IP 稳定性** | **租期内 100% 独享固定不变** | 每请求轮换，或 1~30 分钟粘性保持 |
