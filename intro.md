Complete guides for purchasing, authorizing, generating endpoints, and using Proxy IP products — plus the Web Scraping API.

## Quick start

- [Create account](https://www.joyproxy.com/register.html) and sign in
- Choose a network on [Purchase Proxies](https://www.joyproxy.com/admin-purchase.html) (Residential · Mobile · Business · Datacenter) — or buy [Web Scraping API credits](https://www.joyproxy.com/admin-web-unblocker.html?view=buy)
- Set **whitelist** or **username/password** in Whitelist & Users (proxy IP)
- Extract from [Endpoint generator](https://www.joyproxy.com/admin-ip-extraction-center.html) or call `/v1/fetch` (Web Scraping API)
- Configure proxy in your app or browser

**💡 Tip**API testing: [OpenAPI Center](https://www.joyproxy.com/admin-openapi.html).
