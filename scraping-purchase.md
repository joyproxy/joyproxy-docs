# Purchase Web Scraping API Credits

Credit packs are bought from account balance in the Web Scraping API console — separate from Proxy IP traffic packages.

- Sign in and open [Web Scraping API → Buy](https://www.joyproxy.com/admin-web-unblocker.html?view=buy)
- Pick a preset pack ($5 entry tier) or enter a custom credit amount (minimum 10K credits)
- Pay with account balance (PayPal top-up if needed)
- Credits are added immediately and **never expire**
- Larger balances unlock higher concurrency limits — see [pricing table](https://www.joyproxy.com/pricing.html?network_type=smart-fetch)

**💡 Tip**New users still receive the $5 sign-up credit — you can apply it toward your first proxy or scraping pack.
