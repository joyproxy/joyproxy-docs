# 受限目标

为保障全部独享移动运营商线路的长期合规与稳定运行，严禁将 JoyProxy 独享移动代理用于以下场景：

- 任何违反所在国家/地区法律法规的活动（含欺诈、盗刷、钓鱼、恶意入侵、勒索软件等）；
- 垃圾邮件群发（SMTP 25/465/587 端口默认封禁）、DDoS 攻击、端口扫描或暴力破解；
- 政府、军工、关键基础设施站点及明确禁止代理访问的受控目标；
- 侵犯他人知识产权、传播非法内容或恶意滥用运营商网络带宽。

一旦触发上游运营商安全拦截或违反 [《可接受使用政策》](https://www.joyproxy.com/zh-CN/terms.html)，平台有权在不退费的前提下立即暂停或终止相关端口服务。
