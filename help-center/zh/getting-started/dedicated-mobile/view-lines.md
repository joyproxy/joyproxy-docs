# 查看已购端口

进入控制台 **真机 4G/5G 代理 → 我的代理**（`/admin-proxy-mobile-dedicated.html?tab=orders`），即可集中管理您名下的全部端口资产。

## 顶部状态看板

页面顶部实时统计四类核心状态，便于快速掌握资源健康度：

| 状态 | 含义说明 |
| :--- | :--- |
| **待开通（预订中）** | 预订订单已付款，运维正在 24 小时内为您配网交付，此时尚未开始计算租期 |
| **运行中** | 端口已交付就绪，可随时复制凭据连接或按需切换 IP |
| **即将到期** | 距离到期不足 48 小时，建议尽早发起续费以避免卡槽回收 |
| **已过期** | 租期已结束，端口已停止转发 |

## 行内备注与资产检索

- **自定义备注**：点击任意端口行的备注图标，可随时填写业务标签（例如 `Claude主号`、`TikTok-US-01`、`Amazon美区店`），方便多端口精准对应。
- **订单编号与到期时间**：列表清晰展示每条端口的订单号、所属国家/运营商、4G/5G 制式、开通时间与精确到期时间。
