# 响应码与故障排查

使用独享移动代理发起请求时，常见的状态码与排查方法如下：

| 现象 / 响应码 | 常见原因 | 排查与解决方法 |
| :--- | :--- | :--- |
| **`407 Proxy Authentication Required`** | 代理账号或密码填写错误，或包含首尾多余空格 | 前往 **我的独享移动代理** 重新复制完整凭据，确认区分大小写且无空格 |
| **连接超时 / `502` / `504`** | 正在执行「切换 IP」重拨（耗时 5–15 秒），或本地网络拦截了代理端口 | 等待 15 秒后重试；确认所选协议与端口对应（HTTP 端口勿填成 SOCKS5 端口） |
| **切换 IP API 返回 `429`** | 距离上次切换不足 45 秒防抖冷却期 | 等待至少 45 秒后再发起下一次切换请求 |
| **端口状态显示 `已过期`** | 当前租期已到期，端口已停止转发 | 前往控制台确认到期时间；如需继续使用请重新购买或提前续费 |
| **基础网站正常，但特定目标站报错** | 目标站点自身的账号风控、Cookie 残留或浏览器指纹异常 | 清理浏览器缓存/指纹，或按需切换一次新 IP 后重试 |

如确认基础公开网站（如 `https://ipinfo.io/json`）持续无法连通超过 5 分钟，请点击该订单行的 **「工单售后」** 提交报错截图与测试时间，运维将第一时间为您排查或更换端口。
