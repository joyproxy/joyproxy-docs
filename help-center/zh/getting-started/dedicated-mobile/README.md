# 独享静态移动代理（4G/5G 真机）使用指南

## 1. 产品简介

**独享移动代理（Dedicated Static Mobile Proxies）** 由真实物理手机 SIM 卡槽与 4G/5G 运营商移动网络驱动，提供 **100% 独享的静态移动端口**、**无限流量（∞）**，原生支持 HTTP/HTTPS 与 SOCKS5 直连。

与按流量计费的动态轮换代理不同，独享移动代理在租期内为您**固定分配专属端口与稳定出口**；当您因业务需要更换新 IP 时，随时可在控制台一键按需切换，无需被迫频繁变动 IP。

得益于移动运营商的 **CGNAT（运营商级地址转换）** 机制，真实移动 IP 具备互联网最高级别的防封信誉度，尤其适合：

- **AI 账号防封**：Claude、ChatGPT、Gemini、Cursor、Midjourney 等长期稳定登录与防风控。
- **海外社媒运营**：TikTok、Instagram、X、Facebook、YouTube 长期养号、发内容与视频运营（无限流量不额外计费）。
- **跨境电商与支付**：Amazon、TikTok Shop、Shopify、eBay、PayPal / Stripe 多账号隔离防关联。

## 2. 预订与 24 小时开通说明

1. 登录 JoyProxy 控制台，点击左侧菜单 **独享移动代理**（`/admin-proxy-mobile-dedicated.html`）。
2. 选择目标国家、4G/5G 运营商与租期（**2 天 / 7 天 / 14 天 / 30 天**）。
3. 点击 **「立即预订 · 24小时内开通」** 并通过账户余额、微信支付、USDT (TRC20)、银行卡或 PayPal 完成支付（*一期「立即开通」按钮暂显示已售罄，后续开放自动库存*）。
4. 运维团队将在 **24 小时内** 完成物理真机卡槽配网与交付，并自动发送邮件通知。**您的有效租期从实际交付开通时刻起算，不消耗等待时间。**

---

## 3. 连接配置与按需切换 IP

在控制台 **「我的独享移动代理」** 中，已开通的端口会展示：

- **Host / HTTP 端口 / SOCKS5 端口 / 账号 / 密码**（支持一键复制 HTTP URL、SOCKS5 URL 及指纹浏览器格式）。
- **行内备注**：可随时为每个端口添加业务备注，便于多账号区分管理。
- **按需一键切换 IP**：默认保持静态移动出口稳定；仅当您有需要时，点击 **「切换 IP」** 或调用专属 API 链接，即可触发运营商基带重拨获取同运营商新 IP（约 5–15 秒生效，内置 45 秒冷却保护）。
