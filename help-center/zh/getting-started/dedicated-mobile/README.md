# 独享移动代理

**独享移动代理**由真实物理手机 SIM 卡槽与 4G/5G 运营商移动网络驱动，提供单人 100% 独享的静态移动端口与**无限流量（∞）**，原生支持 HTTP/HTTPS 与 SOCKS5 直连。

得益于移动运营商的 **CGNAT（运营商级地址转换）** 机制，真实移动出口具备互联网最高等级的防封信誉，默认保持稳定静态连接，仅在您有业务需要时支持一键按需切换新 IP。

---

## 核心特性

| 特性 | 说明 |
| :--- | :--- |
| **IP 来源** | 真实物理 4G/5G 手机 SIM 卡槽，单端口 100% 独享，无共享污染 |
| **流量计费** | 按租期包时计费（2 / 7 / 14 / 30 天），全线**无限流量（∞）** |
| **连接方式** | 固定 `host:port` 与独立账密，原生支持 HTTP/HTTPS 与 SOCKS5 |
| **IP 稳定性** | 默认保持静态移动出口稳定；需要时可通过控制台按钮或专属 API 按需切换 |
| **覆盖范围** | 17 个国家、31 个主流 4G/5G 运营商（含美国 AT&T / Verizon / T-Mobile 等） |
