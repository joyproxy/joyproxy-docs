# 独享真机 4G/5G 移动代理使用指南

## 1. 产品简介

**独享移动代理（Dedicated Mobile Proxies）** 由真实物理手机 SIM 卡槽与 4G/5G 运营商网络驱动，单端口 100% 独享、**无限流量（∞）**，原生支持 HTTP/HTTPS 与 SOCKS5 直连。

得益于移动运营商的 **CGNAT（运营商级地址转换）** 机制，真机移动 IP 与成千上万真实手机用户共享出口池，具备互联网最高级别的防封信誉度，尤其适合：

- **AI 账号防封**：Claude、ChatGPT、Gemini、Cursor、Midjourney 等防封号、防降智。
- **海外社媒矩阵**：TikTok、Instagram、X、Facebook、YouTube 刷视频、发内容、养号（无限流量不烧钱）。
- **跨境电商与支付**：Amazon、TikTok Shop、Shopify、eBay、PayPal / Stripe 防关联。

---

## 2. 预订与 24 小时开通说明

1. 登录 JoyProxy 控制台，点击左侧菜单 **独享移动代理**（`/admin-proxy-mobile-dedicated.html`）。
2. 选择目标国家、4G/5G 运营商、IP 轮换方式与租期（**2 天 / 7 天 / 14 天 / 30 天**）。
3. 点击 **「立即预订 · 24小时内开通」** 并通过余额、微信支付、USDT (TRC20)、信用卡或 PayPal 完成支付（*一期「立即开通」按钮暂显示已售罄，后续开放*）。
4. 运维将在 **24 小时内** 完成物理真机配网与交付，并自动发送邮件通知。**您的有效租期从实际交付开通时刻起算，不消耗等待时间。**

---

## 3. 连接配置与一键换 IP

在控制台 **「我的独享移动代理」** 列表中，开通就绪的端口会显示：

- **Host / HTTP 端口 / SOCKS5 端口 / 账号 / 密码**（支持一键复制常规格式、HTTP/SOCKS5 URL 及 AdsPower / 比特浏览器粘贴格式）。
- **一键换 IP**：点击控制台「一键换 IP」按钮即可向运营商基带发起重拨切换新 IP（约 5–15 秒生效，内置 45 秒防抖冷却）。
- **专属 API 轮换链接**：点击「复制换 IP API」即可获得 JoyProxy 私有轮换 URL，可直接填入指纹浏览器或自动化脚本调用。

---

## 4. 续费与工单售后

- **续费**：在「我的独享移动代理」点击对应端口的 **「续费」**，选择 2/7/14/30 天并付款，运维完成上游续期后自动为您顺延到期时间并邮件通知。
- **异常与退款**：如遇无法按时开通、连接异常或需申请退款，请直接点击该订单行的 **「工单售后」** 提交工单，客服核实后支持更换端口或手工退回 JoyProxy 账户余额。
