# 快速开始

按照以下 4 个步骤，即可快速完成独享移动代理的下单、配置与连通性验证：

## 步骤 1：选择国家、运营商与租期

1. 登录 [JoyProxy 控制台](https://www.joyproxy.com/admin-proxy-mobile-dedicated.html)，点击左侧导航栏 **独享移动代理**。
2. 在 **购买** 页签中，按国家标签或 **5G Only** 筛选目标运营商。
3. 选择租期（**2 天 / 7 天 / 14 天 / 30 天**）与购买数量。

## 步骤 2：完成下单（现货直购或售罄预订）

- 有即时库存时，可直接点击 **立即购买** 付款并自动开通。
- 如目标运营商当前显示 **已售罄**，可直接点击 **立即预订（24 小时内开通）** 完成支付。预订订单将在 24 小时内完成配网交付并邮件通知，**有效租期严格自实际交付时刻起算**。

## 步骤 3：复制连接信息

端口状态变为 **运行中** 后，切换到 **我的独享移动代理** 页签，获取该端口专属的：
- `Host`（固定服务器地址）
- `HTTP 端口` 与 `SOCKS5 端口`
- `Username` 与 `Password`

点击列表快捷按钮即可一键复制 HTTP URL、SOCKS5 URL 或指纹浏览器粘贴格式（`host:port:user:pass`）。

## 步骤 4：验证连通性与出口 IP

使用 `curl` 快速验证（将参数替换为控制台中的实际值）：

```bash
curl -x "http://USERNAME:PASSWORD@HOST:HTTP_PORT" https://api.ipify.org?format=json
```

正常返回目标国家移动运营商的公网 IP 即表示配置成功。更多代码示例见 [发起代理请求](first-request.md)。
