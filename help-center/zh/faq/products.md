# 产品与网络选型

本章汇总了 JoyProxy 的平台定位、网络特性对比、动态与静态独享差异、合规范围、试用政策及售前常见选型疑问，帮助你快速评估最适合业务的代理方案。

## 核心业务与平台概览

### JoyProxy 主要提供哪些服务？
JoyProxy 专注于全球网络代理与数据采集基础设施，主要提供以下三大核心产品与服务（以及面向开发者的 AI 集成能力）：
1. **五大云端代理 IP 产品线**：覆盖全球 200+ 国家和地区、25,000+ 城市，分为**动态代理**（住宅代理、移动代理）与**静态代理**（真机独享 4G/5G 代理、ISP（静态住宅）代理、数据中心代理）。
2. **网页抓取 API**：无需自建代理池与无头浏览器的托管式数据采集接口，自动应对反爬机制与动态渲染，仅对 HTTP 2xx 成功响应扣除积分。
3. **免费开源软件矩阵**：提供免 Root 分流的 Android 客户端、批量连通性测试桌面端 Proxy Tester、轻量级网关 Proxy Server 以及即开即用的 Chromium 浏览器扩展。
4. **AI 开发者集成**：提供面向开发者和大模型的 OpenClaw Skill、AI MCP 插件与全天候智能问答能力。

### 五大代理产品（2 动态 + 3 静态）有什么区别？如何选择？
不同业务场景对代理 IP 的网络属性要求不同：
- **住宅代理**：出口 IP 来源于真实的家庭宽带网络，信誉度极高，目标网站风控感知自然。非常适合大规模电商数据采集、社交媒体多账号防关联运营、搜索引擎结果抓取以及跨国多语言本地化验证。
- **移动代理**：出口 IP 来源于真实移动运营商的 4G/5G 蜂窝网络。移动基站天然具备多个移动终端共享公网 IP 的特点，目标平台对其容忍度最高。特别适合移动端 App 抓取、移动广告展示合规检测及短视频自动化业务。
- **真机独享 4G/5G 代理（静态）**：真实物理手机 SIM 卡槽 100% 单人独享，无限流量，默认保持稳定静态移动出口，支持按需一键/API 切换新 IP。具备运营商 CGNAT 最高等级防封信誉，专为 AI 账号、TikTok/社媒矩阵与高风控跨境电商打造。
- **ISP（静态住宅）代理（静态）**：运营商 ISP 专线静态住宅固定出口，无限流量。适合指纹浏览器防关联、跨境店铺长期登录、企业 B2B 门户访问与海外财税接口调用等场景。
- **数据中心代理**：出口位于云服务商机房。网络带宽充足、延迟极低、单价成本低，且支持极高并发。适合目标网站风控较宽松的大规模批量请求、搜索引擎索引监测及高吞吐量数据同步。

### 动态代理与静态独享有什么区别？

| 产品形态 | 计费模式 | 线路属性 | 更换 IP 机制 | 典型适用场景 |

> - 数据中心代理：仅提供静态独享，不提供动态流量包。

## 选型与功能疑问

### 网页抓取 API 与代理 IP 有何本质区别？
- **代理 IP**：平台提供的是代理服务器的连接地址（`host:port`）。你需要自己在代码或软件中处理网络协议、身份认证、请求头指纹、Cookie 保持、验证码识别及失败重试逻辑。
- **网页抓取 API**：属于全托管数据采集接口。你只需提交目标网址，服务端自动调度合适代理出口、处理常见网站防护系统、执行 JavaScript 脚本渲染，并直接将干净的 HTML 或结构化 JSON 返回给你。
- **选型建议**：如果核心诉求是「拿到特定网页的内容」且希望省去维护代理池和爬虫架构的精力，优先选用 Web Scraping API；如果需要底层控制 TCP/SOCKS 链路、运行特定桌面软件或直接登录国外网页，请选择代理 IP。

### 动态移动代理与真机独享 4G/5G 代理有什么区别？该如何选择？
两者出口均为真实 4G/5G 移动运营商网络，核心区别在于**共享按量 vs 独享真机**：
- **移动代理（动态）**：共享 4G/5G 移动 IP 池，按 GB 计费（$4.00/GB 起，流量不过期），支持按请求轮换或短粘性会话，适合移动端采集、广告验证与批量测活。
- **真机独享 4G/5G 代理（静态）**：独立物理手机 SIM 卡槽 100% 单人独享，按租期（2/7/14/30 天）计费且**无限流量**，默认静态稳定，仅在需要时一键或通过 API 切换同运营商新 IP，适合 AI 稳号、海外短视频/社媒矩阵及高风控跨境电商。

### 覆盖多少国家和地区？购买静态代理前可以选城市或指定运营商（ASN）吗？
JoyProxy 的代理网络覆盖全球 200 多个国家与地区，拥有超过 25,000 个城市节点。
- **动态代理**：在提取中心支持精确指定国家（ISO 二字代码）、省份/州、城市与运营商/ASN。
- **真机独享 4G/5G 代理**：覆盖 17 个国家、31 个主流 4G/5G 运营商（如美国 AT&T、Verizon、T-Mobile，英国 Vodafone 等），下单时直接选定具体国家与运营商。
- **静态独享代理（ISP / 数据中心）**：控制台下单页支持直接按实时可用下拉选项选择**国家、省份/州、城市，以及指定运营商/ASN**（如 AT&T、Verizon、Comcast 等，具体以购买页实时下拉选项为准）。仅**具体单个 IP 地址或特定 `/24` 网段**暂不支持在下单前挑死；如有特定号段需求，可在下单前提交工单咨询库存。

### 支持哪些网络协议？提供 `.ovpn`（OpenVPN）或 WireGuard 文件吗？
平台云端代理节点完整支持 **HTTP**、**HTTPS** 与 **SOCKS5**（支持 TCP/UDP 转发）协议。常见的浏览器与网页爬虫一般使用 HTTP/HTTPS；需要更底层套接字转发时建议使用 SOCKS5。
- **不提供 `.ovpn` / OpenVPN / WireGuard 配置文件**：JoyProxy 提供的是标准代理协议（`host:port` + 账密/白名单），并非传统 VPN 服务。

### 各类代理的带宽有多大？静态代理包含流量、需要反复提取吗？
- **常规带宽参考**：单条动态代理（住宅/移动）约 **10–20 Mbps**；真机独享 4G/5G 代理依托真实当地 4G/5G 蜂窝基站速率且**无限流量**；ISP（静态住宅）代理约 **10–100 Mbps**；数据中心代理约 **20–300 Mbps**（实际速率受访问端所在地区与目标网站线路影响）。如需直播等持续稳定大带宽或超低延迟场景，可提交工单申请**直连专属代理**。
- **静态代理流量与提取说明**：静态独享按 IP 数量 × 时长计费，**有效期内不限流量和并发，无需额外购买流量包**；购买后直接在控制台「已购代理」拿到固定的接入地址（`host:port`）即可长期配置使用，**不需要像动态代理那样反复提取**。

### 需要长期固定 IP 时，选 ISP 代理还是数据中心代理？
- **ISP 代理**：适合目标站点要求独享静态 IP，且对出口运营商商业资质有硬性风控要求的场景（例如供应商系统要求接入方必须是正规商业宽带而非住宅宽带）。
- **数据中心代理**：适合公开数据采集、API 中转、性能测试等对机房 ASN 不敏感、更看重吞吐与成本的场景。
- 需要频繁更换出口时，请使用住宅或移动的动态代理，而不是静态独享。

### 能否保证 100% 不被目标网站封禁？
不能。代理 IP 的作用是改变客户端对外展示的网络出口与地理属地。但现代目标网站的风控系统除了校验 IP 属性外，还会综合分析请求频率、访问行为轨迹、浏览器硬件指纹（Canvas/WebGL/Audio）、请求头一致性以及账号操作行为。
因此，使用代理时仍需合理控制请求并发与频率、完善反指纹对抗策略。

## 合规政策与试用咨询

### 是否可以从中国大陆网络环境直接连接代理？
**不可以**。出于网络合规与国际专线链路要求：
1. 位于中国大陆境内的网络无法直接连接 JoyProxy 的代理服务器（连接会被阻断或提示地区不支持）；
2. JoyProxy 的所有代理出口节点均无法访问中国大陆境内的网站与网络服务。
请务必在中国大陆以外的境外服务器、海外 VPS 或合规出海网络环境下配置和使用本服务，并仅用于合规出海业务。

### 能否购买中国大陆境内的代理 IP？
**不能**。JoyProxy 的全球地区节点列表中不包含中国大陆境内的任何 IP 资源。
