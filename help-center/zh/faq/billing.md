# 购买、计费与财务账单

本章汇总了 JoyProxy 的计费模式、价格阶梯、支付通道、充值满赠政策、发票账单开具以及退款流程。

---

## 计费模式与套餐阶梯

### 平台是否强制要求按月订阅绑定？
**绝不强制订阅**。JoyProxy 承诺 **No subscription / Instant activation / Secure checkout**（无需预设订阅扣款、即时全自动开通、安全加密结账）：
- 平台默认采用「按需购买」模式，买多久用多久，用多少买多少；
- 除非你自己在控制台针对特定的静态线路主动开启了「自动续费」，或者针对动态流量开启了「自动购买流量」，否则系统**绝不会在周期到期或额度耗尽时私自扣取你的银行卡款项**。

### 动态流量没用完会作废过期吗？
**不会过期**。无论是住宅代理、移动代理还是商业代理，你购买的流量包**均无有效期限限制**，永久有效，直到实际使用完毕为止。（网页抓取 API 的 Credits 积分同样无到期时间，永久有效）。

## 支付通道、手续费与充值满赠

### 目前支持哪些付款方式？
- **账户余额支付**：推荐首选方式，免收任何额外手续费，支持一键结算。
- **信用卡 / 借记卡**：支持全球主流 Visa、Mastercard、American Express、JCB 卡种。
- **电子钱包**：支持 PayPal、Apple Pay、Google Pay。
- **加密货币**：支持 **USDT、USDC、TRX、BNB、ETH、SOL、BTC** 等多链币种充值或直付（涵盖 **TRON TRC20**、**BSC BEP20**、**Polygon**、**Arbitrum One**、**Solana SPL**、**Ethereum ERC20** 与 **Bitcoin Native SegWit**）。
- **微信支付**：支持微信支付通道。
- **UPI**：支持印度本地 UPI 快捷支付。
> 注：银联卡及大额对公转账通道正陆续上线中。

### 为什么推荐先充值到「账户余额」再购买？
1. **免手续费**：使用信用卡或 PayPal 单笔直付时，第三方网关会收取每笔 6.5% + $0.50 的通道处理费；而直接使用账户余额结算商品订单，**JoyProxy 免除所有手续费**。
2. **享受充值满赠福利**：在控制台点击「充值」时，单笔达到对应档位即可享受直接赠金：
   - 单笔充值满 **$100**：额外加赠 **10%**（到账 $110）
   - 单笔充值满 **$1,000**：额外加赠 **20%**（到账 $1,200）
   - 单笔充值满 **$10,000**：额外加赠 **30%**（到账 $13,000）
   赠送金将在付款成功后连同本金实时注入账户可用余额。

### 支持哪些加密货币和链网络？转账与未到账如何处理？
1. **支持币种与网络清单**（支持充值到余额及订单直付，最低 `$1 USD` 等值起）：
   - **USDT (Tether)**：支持 **TRON (TRC20)**、**BSC (BEP20)**、**Polygon**、**Arbitrum One**、**Solana (SPL)**、**Ethereum (ERC20)**
   - **USDC (USD Coin)**：支持 **BSC (BEP20)**、**Polygon**、**Arbitrum One**、**Solana (SPL)**、**Ethereum (ERC20)** *(注：USDC 不支持 TRC20)*
   - **TRX**：TRON Network (TRC20)
   - **BNB**：BSC (BEP20)
   - **ETH**：Arbitrum One、Ethereum Mainnet (ERC20)
   - **SOL**：Solana Mainnet
   - **BTC**：Bitcoin (Native SegWit)
2. **务必选对链与网络**：选定币种与网络后，系统会生成收款地址与二维码。请确保转账钱包或交易所选用的网络与页面**完全一致**（例如选择 `BSC (BEP20)` 则必须走 BEP20 链），切勿跨链或转错网络，否则链上资产将无法找回。
3. **务必按页面的精确小数金额转账**：为精准识别您的入账订单，收银台会为每次支付生成一个**带唯一小数尾数的精确金额**（例如 `$10.00` 可能锁定为 `10.01 USDT`，非稳定币则按锁定汇率折算，订单倒计时 **25 分钟**）。转账时请**一分不差、切勿自行四舍五入**；实付总额（扣除您自身钱包 Gas 费后到账平台的金额）会按实际金额全额折算入账。
4. **自动到账与异常排查**：发出转账后，可点击页面「**我已支付（I Have Paid）**」按钮，系统每隔数秒会自动扫描全链入账并在区块确认后秒级入账。如果因网络拥堵、不小心关闭窗口或转账金额与锁定小数不一致导致 **10～30 分钟内未自动到账**：
   - 如使用早期波场（TRC20）子钱包地址充值，可前往控制台 **我的账户 → 资料** 中的 **USDT 充值认领** 卡片输入金额或 TxID 点击 **Claim** 补认领；
   - 其他所有多链加密货币充值/支付问题，请直接登录控制台提交工单，提供**充值/订单编号、所选币种与网络（如 `USDT-BSC`、`USDC-Polygon`、`SOL` 等）、实际转账金额与交易哈希（TxID / Hash）**，客服核实后将为您人工匹配入账。

### 购买后订单单价会随着官网调价而上涨吗？
不会。你下单采购时的单价已被系统完整快照锁定。后续若开启自动续费，续费单价以续费当时界面的有效定价为准。

## 账单、发票与退款政策

### 消费凭据与账单在哪里查看和下载？
登录控制台后，点击左侧导航栏的「账单与交易记录」，即可在一个页面掌握所有财务流水：
- **余额流水明细**：查看每一次充值、满赠入账及订单扣款明细；
- **订单记录**：查看所有采购订单的生效时间、产品名称与实际结算金额；
- **下载发票**：每笔订单右侧均有 **PDF 发票下载** 按钮，格式符合国际通用财务报销规范；你也可以在页面右上角勾选时间区间，一键批量打包下载为 ZIP 压缩包。

### 平台的退款政策是怎样的？用了一半能退款吗？
JoyProxy 对符合条件的订单提供 **7 天退款窗口**，具体以 [服务条款 · 退款政策](https://www.joyproxy.com/terms.html#refund) 为准：
1. **7 天退款窗口**：符合条件的订单须自付款之日起 **7 天内** 提交工单申请退款；购买超过 7 天一概不予退款。
2. **「通用网络故障」界定**：代理服务正常与否，以能否通过代理正常连接常规、无访问限制的公开互联网网站为准。基础网络正常、仅客户要求的特定目标网站/应用/端口不通，**不构成故障，不能作为退款条件**。
3. **不支持退款与提现的情形**：
   - 仅购买 **1 天有效期** 的订单（非经核实的通用网络故障）；
   - 使用 **加密货币（USDT / USDC / TRX / BNB / ETH / SOL / BTC 等任意链）** 或 **UPI** 支付的订单（非经核实的通用网络故障）；
   - **账户余额充值**及使用**账户余额消费**的订单（**均不支持提现，亦不支持退款**）；
   - 基础网络正常但特定目标网站/网络不通的申请；
   - 超过 7 天、因违规被封禁账户或活动赠送额度。
4. **可退款订单的金额核算**：
   - **完全未使用**：全额退回（现金渠道优先原路退回，支付渠道不支持则退入不可提现的账户余额）；
   - **已部分使用**：按实付单价扣除已消耗额度后退还剩余价值——**按时长计费的不足 1 天按 1 天扣除**（每 24 小时计为 1 天），**按流量计费的不足 1 GB 按 1 GB 扣除**。
5. **申请方式**：登录控制台，进入「工单系统」选择财务分类，说明原因并提供订单编号（若涉及通用网络故障，请一并提供测试日志或报错截图）。

### 付款成功但余额或订单未到账怎么办？
请先检查支付渠道（PayPal、银行卡）账单是否显示为已完成扣款。
- 若付款完成超过 30 分钟仍未入账，请登录控制台提交工单，提供站内订单号及 PayPal Capture ID、信用卡交易流水号或加密货币交易哈希（TxID，附注币种与网络），客服团队将人工核验并补录入账。

### 动态代理的流量消耗扣费标准是怎样的？上传和下载都计费吗？连接失败扣费吗？
1. **上下行总流量计费**：动态代理（住宅代理、移动代理、商业代理）按实际通过代理网关转发的**请求上行数据（Upload）与响应下行数据（Download）之和**进行精确统计扣费（包含 HTTP Header 报文与传输 Body 体积）；
2. **连接与鉴权失败不扣费**：如果请求因代理账号密码错误、白名单未生效或网关配置错误导致 407 拒绝连接，由于数据未实际向目标网站转发，**系统一律不扣除任何动态流量**；
3. **目标网站报错扣费说明**：如果请求已成功由代理网关发送给目标网站，即便目标网站返回 403、404 或 500 页面，由于该传输已真实消耗了海外宽带节点的网络带宽，系统会按实际传输的响应体积计费；
4. **流量节省技巧**：建议在客户端或爬虫请求头中开启 `Accept-Encoding: gzip, deflate, br`，利用网页压缩可大幅降低实际消耗的下行流量体积。
