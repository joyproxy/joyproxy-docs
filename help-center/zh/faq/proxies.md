# 代理提取与使用

本章汇总了关于动态代理与静态独享代理的提取流程、参数配置、接入规范与高阶使用技巧。

---

## 动态代理提取与使用

### 购买了动态流量后，该如何提取代理并开始使用？
动态代理的使用非常简便，只需以下三步：
1. **配置代理认证凭据**：登录控制台，进入对应网络类型（如「住宅代理」）页面，切换到顶部的「账密与白名单」标签页，创建一个专用的用户名与密码（例如用户名前缀 `user1`，设置好密码）。
2. **提取代理 IP**：切换到控制台的「提取」标签页（或进入 <a href="https://www.joyproxy.com/admin-ip-extraction-center.html" target="_blank" rel="noopener noreferrer">提取</a> 页面）：
   - 在 **Web 提取** 中选择订单、协议（HTTP 或 SOCKS5）、目标国家/城市以及会话模式（轮换或黏性保持）；
   - 点击 **立即生成** 即可在结果列表中获取代理地址。
3. **填入客户端配置**：将生成的连接信息配置到你的软件中：
   - **代理主机**：固定为 `gate.joyproxy.com`
   - **代理端口**：固定为 `9001`
   - **用户名**：完整复制生成出来的整长串文本（切勿手动修改或删减）
   - **密码**：填写你在第一步中自己设置的代理密码

### 为什么所有动态代理连接的都是同一个 gate.joyproxy.com:9001？
这是云端动态网关的标准化架构。`gate.joyproxy.com:9001` 是 JoyProxy 全球动态分发集群的统一入口。
当你的客户端带着特定用户名连接该网关时，网关服务会毫秒级解析用户名中携带的参数（例如包含的目标国家、城市以及会话 ID），并在庞大的云端池中实时调度最匹配的真实宽带节点作为出口转发你的请求。这种架构不仅保证了高吞吐与高可用，还省去了爬虫频繁维护海量代理列表的麻烦。

### 动态提取出来的用户名为什么那么长？能否自己改短？
**绝对不能自行删减或更改**。动态代理的用户名并不是普通的纯字母账号，而是高度编码的指令字符串，格式通常类似：
`user1-zone-resi-region-us-city-los_angeles-session-ab12cd-sessTime-30`
其中每一段都代表明确的路由规则：
- `user1`：你的代理账号
- `region-us` / `city-...`：目标出境地理位置
- `session-...`：黏性会话标识
- `sessTime-30`：会话保持时间（分钟）

如果手动截断或修改该字符串，网关将无法识别你的路由需求，会导致鉴权失败（407 错误）或将流量错误路由至随机国家。

### 轮换模式与黏性会话该如何选择？
- **轮换会话（每次换 IP）**：每次发起新的 HTTP 请求，出口 IP 都会自动更换。适合大规模抓取网页、高频采集数据，能最大程度分散单个 IP 的请求频率。
- **黏性会话**：在指定时间内（支持 1~30 分钟自定义）尽可能保持使用同一个公网出口 IP。当时间到期或原宽带离线时，系统会自动平滑切换到同地区的新 IP。非常适合模拟真人浏览、电商网站多步骤登录加购或社交平台操作。

### 黏性会话时间到期后，连接会自动断开吗？
不会中断底层 TCP 链路。在设定的时间窗口内，网关会尽最大努力保持出口公网 IP 不变；时间到期后，**连接本身不会被切断，原来的连接字符串依然有效**，只是下一次网络请求时网关会自动分配同地区的新出口 IP。

## 静态独享代理提取与使用

### 提取静态代理时，Entry Point（接入地址）与 Exit IP（出口 IP）有什么区别？
这是新手最容易混淆的概念：
- **Entry Point（接入地址）**：格式形如 `isp.joyproxy.com:端口` 或 `dc.joyproxy.com:端口`（历史分配的 `*.std.joyproxy.com` / `*.pro.joyproxy.com` 亦兼容可用）。这是你在客户端、爬虫或浏览器扩展中**唯一需要且必须填入的代理主机与端口**。
- **Dedicated Exit IP（专属出口 IP）**：形如 `198.51.100.24`。这是该线路实际对公网展示的真实 IP 地址，仅供你核对出口属地与外部网络环境，**绝对不能把 Exit IP 当作代理主机填入客户端**，否则会导致连接被拒。
> **控制台提示**：在控制台已购列表中，你可以通过表头的「隐藏出口 IP / 显示出口 IP」开关来避免混淆。

### 静态独享代理可以更换 IP 或地区吗？
- **更换出口 IP**：仅限 **30 天及以上（月付或更长）** 周期的静态代理，在有效期内置于控制台「已购」列表操作列点击 **更换 IP（New IP）**，每条线路每 30 天可免费自助更换 1 次同地区新出口 IP（连接域名与端口不变）。1 天、7 天等 30 天以下短周期套餐不支持自助换 IP。
- **更换地区**：不可以。静态独享在下单付款时就已经锁定国家与城市，自助换 IP 不支持跨国或跨城市变更。若下单时误选了国家，请提交工单联系客服协助调整；如需动态切换多地区，建议使用动态代理并在提取时指定地区。

### 我的静态代理 Exit IP 为什么变了？是不是被平台偷偷换掉了？
平台绝对不会无故更换用户的独享出口。静态代理承诺提供专享固定出口，但在极少数情况下可能发生变化：
- **触发了线路健康容灾**：平台具备全天候线路健康监测系统。如果底层宽带节点发生断电、运营商机房割接或物理故障导致出口长时间失活，为了保证你的业务不中断，系统会自动将出口平滑切换为同地区的可用健康 IP；
- **用户主动操作**：团队成员在控制台点击了「更换 IP」。
切换后的出口依然为你专属独占，不会与他人共用。

### 可以先买 1 天静态代理测试，满意后续费 30 天并保留原 IP 吗？
可以。您可以先购买 1 天静态代理（如 ISP 单条 1 天 $0.60）验证线路质量与目标站适配度；在 **1 天有效期到期前** 于控制台对该线路直接续费为 30 天套餐，即可继续保留原出口 IP 与端口不变（若到期未续费，IP 会被释放回池）。

### 为什么静态 ISP 代理在部分第三方检测库（如 Scamalytics / IPQS / ping0）会显示为“机房 / 商业 / 广播”或非双 ISP？
静态 ISP 代理在网络架构上是通过机房托管的运营商商业专线带宽广播或接入，因此不同第三方 IP 数据库（更新周期与判定规则各不相同）可能会将其标记为商业/机房属性或非“双 ISP”。
- 如果您的业务（如社媒、跨境电商、常规站点）看重固定独享 IP 与稳定大带宽，静态 ISP 非常合适；
- 如果目标平台（如部分支付站、AI 平台、高敏风控站）严格要求 100% 真实家庭宽带且不允许任何机房/商业标记，建议改用 **动态住宅代理（Residential Proxies）** 或 **移动代理（Mobile Proxies）** 并配合长粘性会话（如 `sesstime-1440` 或更长）。

### 购买静态代理前能自选运营商或查询号段/ASN吗？
可以。在控制台购买静态代理时，下单页面支持直接从实时下拉菜单中选择目标 **国家、省份/州、城市以及指定运营商（ASN）**，仅具体的单个公网 IP 或特定 `/24` 子网无法在下单前锁定预选。如果您对特定 `/24` 网段或运营商库存有明确要求，请在控制台左侧导航栏点击「工单」提交咨询，客服会为您核实可用情况。

### 静态代理的账号密码是每个 IP 独立一个，还是按产品通用？
静态代理的账号密码在「账密与白名单」页面按产品维度统一管理，不支持为每条单独购买的静态 IP 各自设置不同的用户名和密码。不同静态线路之间通过各自独立的 **端口号（Port）** 或 **入口地址** 区分；如需免密认证，也可以在「账密与白名单」绑定您的公网 IP 白名单。

### 代理网关是否支持客户端到网关直连 TLS（如 `https://HOST:PORT`）？
JoyProxy 代理网关采用标准的 **HTTP `CONNECT` 隧道** 与 **SOCKS5** 协议。访问 HTTPS 目标网站时，客户端通过标准 HTTP `CONNECT`（或 SOCKS5）与网关建立隧道后，再与目标网站完成端到端 TLS 加密握手（无需在客户端安装任何自定义根证书），不支持将代理地址直接配置为客户端到网关的 TLS 加密直连。

### 对分配的 ISP 或数据中心代理质量不满意，或需要更高带宽、更低延迟怎么办？
如果当前分配的静态线路无法满足业务需求，可先在控制台「已购代理」中尝试「更换 IP」重新分配出口。如需超低延迟、大带宽的静态代理，请通过工单申请直连专属代理，我们将根据您的地区与带宽需求定制专属方案。

### 静态独享代理有流量、限速或连接设备限制吗？
没有任何流量、带宽、并发连接或使用设备数量的限制。
静态独享代理按「IP 数量 × 租用时间」计费。在服务有效期内，您可以不受限制地传输流量和连接多个设备，适合大吞吐量与长连接业务场景。

### 静态独享代理到期后会发生什么？
如果服务到期前未完成续费，系统会在到期时刻立即停止代理转发，并在保留缓冲期后彻底释放该固定端口与底层出口资源。已释放的端口或特定出口 IP 将无法重新找回。如果需要长期保留，建议在控制台开启「自动续费」。

## 真机独享 4G/5G 代理使用与切换 IP

### 真机独享 4G/5G 代理会自动轮换 IP 吗？如何主动切换出口 IP？
- **默认静态稳定**：真机独享 4G/5G 代理默认保持长期稳定的移动出口 IP，不会在未操作时频繁自动跳变，非常适合需要固定登录环境的 AI 账号、社媒与电商业务。
- **按需一键 / API 切换**：当需要更换新 IP 时，可在控制台「真机独享 4G/5G 代理 → 已购端口」点击 **切换 IP**，或调用每个端口专属的私有切换 API URL（无需登录控制台即可触发）。切换期间物理调制解调器会重新向基站拨号，通常 **5–15 秒** 内即可恢复连通并获得同运营商新 IP。

### 真机独享 4G/5G 代理支持哪些协议与认证方式？
原生支持 **HTTP/HTTPS** 与 **SOCKS5** 直连，开通后每个端口会分配独立的固定 `host:port` 与专属用户名/密码（在控制台支持一键复制标准格式及指纹浏览器格式），直接填入客户端即可使用。

## 提取方式与工具配置

### 在控制台有哪些提取代理 IP 的方式？
JoyProxy 提取页面提供三种提取渠道：
1. **Web 提取**：在页面上可视化筛选国家、城市、协议和会话类型，实时生成直连链接，支持一键复制或导出为 CSV/JSON/TXT；
2. **API 提取**：适合写进自动化程序中批量拉取代理列表，支持 CRLF 换行文本与 JSON 格式输出；
3. **AI 提取**：在 Cursor、VS Code、Claude Desktop 或 OpenClaw 中使用自然语言调取代理端点。

### 代理 API 提取接口支持一次提取多少条？调用频率有什么限制？
通过 API 提取代理 IP 时，`count` 参数的有效取值范围为 **1 到 200**（单次最多返回 200 条代理）。
由于动态代理的网关地址与凭据长期有效（只要账户内仍有流量额度即可持续使用），你不需要高频死循环轮询提取接口。如果调用过于频繁触发了速率保护，接口将返回 `429 Too Many Requests`，适当调大调用间隔即可恢复。详细参数请参阅控制台 <a href="https://www.joyproxy.com/admin-openapi.html" target="_blank" rel="noopener noreferrer">OpenAPI 中心</a> 或 <a href="../best-practices/developer/build-proxy-list.md" target="_blank" rel="noopener noreferrer">程序化提取指南</a>。

### 静态独享更换 IP 能否通过 API 自动化执行？
目前不可以。静态独享更换出口 IP 需要在控制台「已购」页面人工点击确认完成。API 提取接口仅负责读取当前已经配置就绪的接入域名与端口，不会自动触发底层换 IP 流程。

### 如何在指纹浏览器（如 AdsPower、Hubstudio、Octobrowser 等）中配置？
以静态独享线路为例：
1. 打开指纹浏览器，新建或编辑浏览器环境；
2. 代理类型选择 `HTTP` 或 `SOCKS5`；
3. 将 JoyProxy 控制台「已购」中显示的 **Entry Point** 拆分填入：域名填在代理主机栏，冒号后的数字填在端口栏；
4. 填写该网络下「账密与白名单」中设置的代理账号与密码（若使用的是静态独享线路且已绑定本机公网 IP 到白名单，账密可免密留空；动态代理网关必须填写账密）；
5. 点击「测试连接」，检测通过且出口 IP 符合预期后即可保存启动。

### 可以把 JoyProxy 代理添加到 Clash、v2rayN 或 Shadowrocket 客户端吗？
可以。JoyProxy 提供标准的 HTTP、HTTPS 与 SOCKS5 代理协议。只要第三方客户端支持标准 HTTP 或 SOCKS5 代理协议类型（带有用户名密码认证或白名单鉴权），均可按照提取到的 `host:port` 与账密填入作为常规代理节点使用。
