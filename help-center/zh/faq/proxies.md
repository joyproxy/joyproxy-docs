# 代理提取与使用

本章汇总了关于动态代理、静态独享代理以及自定义独享代理的提取流程、参数配置、接入规范与高阶使用技巧。

---

## 动态代理提取与使用

### 购买了动态流量后，该如何提取代理并开始使用？
动态代理的使用非常简便，只需以下三步：
1. **配置代理认证凭据**：登录控制台，进入对应网络类型（如「住宅代理」）页面，切换到顶部的「账密与白名单」标签页，创建一个专用的用户名与密码（例如用户名前缀 `user1`，设置好密码）。
2. **提取代理 IP**：切换到控制台的「提取」标签页（或进入 <a href="https://www.joyproxy.com/admin-ip-extraction-center.html" target="_blank" rel="noopener noreferrer">提取</a> 页面）：
   - 在 **Web 提取** 中选择订单、协议（HTTP 或 SOCKS5）、目标国家/城市以及会话模式（轮换或黏性保持）；
   - 点击 **立即生成** 即可在结果列表中获取代理地址。
3. **填入客户端配置**：将生成的连接信息配置到你的软件中：
   - **代理主机（Host）**：固定为 `gate.joyproxy.com`
   - **代理端口（Port）**：固定为 `9001`
   - **用户名（Username）**：完整复制生成出来的整长串文本（切勿手动修改或删减）
   - **密码（Password）**：填写你在第一步中自己设置的代理密码

### 为什么所有动态代理连接的都是同一个 gate.joyproxy.com:9001？
这是云端动态网关的标准化架构。`gate.joyproxy.com:9001` 是 JoyProxy 全球动态分发集群的统一入口。
当你的客户端带着特定用户名连接该网关时，网关服务会毫秒级解析用户名中携带的参数（例如包含的目标国家、城市以及会话 ID），并在庞大的云端池中实时调度最匹配的真实宽带节点作为出口转发你的请求。这种架构不仅保证了高吞吐与高可用，还省去了爬虫频繁维护海量代理列表的麻烦。

### 动态提取出来的用户名为什么那么长？能否自己改短？
**绝对不能自行删减或更改**。动态代理的用户名并不是普通的纯字母账号，而是高度编码的指令字符串，格式通常类似：
`user1-zone-resi-region-us-city-los_angeles-session-ab12cd-sessTime-30`
其中每一段都代表明确的路由规则：
- `user1`：你的代理账号
- `region-us` / `city-...`：目标出境地理位置
- `session-...`：黏性会话标识
- `sessTime-30`：会话保持时间（分钟）

如果手动截断或修改该字符串，网关将无法识别你的路由需求，会导致鉴权失败（407 错误）或将流量错误路由至随机国家。

### 轮换模式（Rotating）与黏性会话（Sticky）该如何选择？
- **轮换会话（每次换 IP）**：每次发起新的 HTTP 请求，出口 IP 都会自动更换。适合大规模抓取网页、高频采集数据，能最大程度分散单个 IP 的请求频率。
- **黏性会话（Sticky Session）**：在指定时间内（支持 1~30 分钟自定义）尽可能保持使用同一个公网出口 IP。当时间到期或原宽带离线时，系统会自动平滑切换到同地区的新 IP。非常适合模拟真人浏览、电商网站多步骤登录加购或社交平台操作。

### 黏性会话时间到期后，连接会自动断开吗？
不会中断底层 TCP 链路。在设定的时间窗口内，网关会尽最大努力保持出口公网 IP 不变；时间到期后，**连接本身不会被切断，原来的连接字符串依然有效**，只是下一次网络请求时网关会自动分配同地区的新出口 IP。

## 静态与自定义独享代理提取与使用

### 提取静态代理时，Entry Point（接入地址）与 Exit IP（出口 IP）有什么区别？
这是新手最容易混淆的概念：
- **Entry Point（接入地址）**：格式形如 `us-ca.edge.joyproxy.com:10001`（或 `*.std.joyproxy.com:端口`）。这是你在客户端、爬虫或浏览器扩展中**唯一需要且必须填入的代理主机与端口**。
- **Dedicated Exit IP（专属出口 IP）**：形如 `198.51.100.24`。这是该线路实际对公网展示的真实 IP 地址，仅供你核对出口属地与外部网络环境，**绝对不能把 Exit IP 当作代理主机填入客户端**，否则会导致连接被拒。
> **控制台提示**：在控制台已购列表中，你可以通过表头的「隐藏出口 IP / 显示出口 IP」开关来避免混淆。

### 静态独享代理可以更换 IP 或地区吗？
- **更换出口 IP**：可以。在控制台「已购」列表中找到对应的静态线路，在操作列点击 **更换 IP（Refresh IP / New IP）**，系统会在同地区为你免费分配一个新的专属出口 IP。更换后，你的连接域名和端口保持不变，极大地简化了客户端维护。
- **更换地区**：不可以。静态代理在下单付款时就已经独占锁定了机房或宽带所属国家与城市，不支持跨国或跨城市变更。如果你的业务经常需要调整所在地区，请在购买时选择「自定义独享代理」。

### 我的静态代理 Exit IP 为什么变了？是不是被平台偷偷换掉了？
平台绝对不会无故更换用户的独享出口。静态代理承诺提供专享固定出口，但在极少数情况下可能发生变化：
- **触发了线路健康容灾**：平台具备全天候线路健康监测系统。如果底层宽带节点发生断电、运营商机房割接或物理故障导致出口长时间失活，为了保证你的业务不中断，系统会自动将出口平滑切换为同地区的可用健康 IP；
- **用户主动操作**：团队成员在控制台点击了「更换 IP」。
切换后的出口依然为你专属独占，不会与他人共用。

### 自定义代理购买后显示「未分配」是什么意思？
自定义代理是按「端口配额」交付的。刚完成付款时，端口尚未指定地理出口，因此状态为未分配。
你只需在控制台「已购」列表中点击该端口行的 **分配地区** 按钮，选择期望的国家、州省或城市并保存，系统便会立即为你挂载该地区的出口线路并生成专属接入地址。

### 自定义代理换区与自动轮换有什么规则？
- **更换地区**：你可以在端口有效期内随时点击重新选择地区。需要注意的是，首次分配时若选择了「标准网络」或「高级网络」，后续换区只能在同一网络等级的资源库内选择。
- **定时自动轮换 IP**：自定义代理支持开启自动轮换。为了保证网络平稳，轮换间隔时间必须设置为 **60 的整数倍秒数（最少为 300 秒，即 5 分钟）**。你也可以在列表中随时点击手动更换 IP。

### 静态与自定义代理有流量或并发限制吗？
**没有任何流量、并发或带宽限制**。
静态独享与自定义代理均按「IP 数量/端口数 × 租用时间」计费。在服务有效期内，你可以不受限制地传输流量，也不设并发连接数阈值，适合大吞吐量与长连接业务。

### 静态与自定义代理到期后会发生什么？
如果服务到期前未完成续费，系统会在到期时刻立即停止代理转发，并在保留缓冲期后彻底释放该固定端口与底层出口资源。已释放的端口或特定出口 IP 将无法重新找回。如果需要长期保留，建议在控制台开启「自动续费」。

## 提取方式与工具配置

### 在控制台有哪些提取代理 IP 的方式？
JoyProxy 提取页面提供三种提取渠道：
1. **Web 提取**：在页面上可视化筛选国家、城市、协议和会话类型，实时生成直连链接，支持一键复制或导出为 CSV/JSON/TXT；
2. **API 提取**：适合写进自动化程序中批量拉取代理列表，支持 CRLF 换行文本与 JSON 格式输出；
3. **AI 提取**：在 Cursor、VS Code、Claude Desktop 或 OpenClaw 中使用自然语言调取代理端点。

### 代理 API 提取接口支持一次提取多少条？调用频率有什么限制？
通过 API 提取代理 IP 时，`count` 参数的有效取值范围为 **1 到 200**（单次最多返回 200 条代理）。
由于动态代理的网关地址与凭据长期有效（只要账户内仍有流量额度即可持续使用），你不需要高频死循环轮询提取接口。如果调用过于频繁触发了速率保护，接口将返回 `429 Too Many Requests`，适当调大调用间隔即可恢复。详细参数请参阅控制台 <a href="https://www.joyproxy.com/admin-openapi.html" target="_blank" rel="noopener noreferrer">OpenAPI 中心</a> 或 <a href="../best-practices/developer/build-proxy-list.md" target="_blank" rel="noopener noreferrer">程序化提取指南</a>。

### 静态或自定义更换 IP 能否通过 API 自动化执行？
目前不可以。静态更换出口 IP、自定义更换地区以及手动换 IP，均需要在控制台「已购」页面人工点击确认完成。API 提取接口仅负责读取当前已经配置就绪的接入域名与端口，不会自动触发底层换 IP 流程。

### 如何在指纹浏览器（如 AdsPower、Hubstudio、Octobrowser 等）中配置？
以静态独享线路为例：
1. 打开指纹浏览器，新建或编辑浏览器环境；
2. 代理类型选择 `HTTP` 或 `SOCKS5`；
3. 将 JoyProxy 控制台「已购」中显示的 **Entry Point** 拆分填入：域名填在代理主机栏，冒号后的数字填在端口栏；
4. 填写该网络下「账密与白名单」中设置的代理账号与密码（若使用的是静态独享线路且已绑定本机公网 IP 到白名单，账密可免密留空；动态代理网关必须填写账密）；
5. 点击「测试连接」，检测通过且出口 IP 符合预期后即可保存启动。

### 可以把 JoyProxy 代理添加到 Clash、v2rayN 或 Shadowrocket 客户端吗？
可以。JoyProxy 提供标准的 HTTP、HTTPS 与 SOCKS5 代理协议。只要第三方客户端支持标准 HTTP 或 SOCKS5 代理协议类型（带有用户名密码认证或白名单鉴权），均可按照提取到的 `host:port` 与账密填入作为常规代理节点使用。
