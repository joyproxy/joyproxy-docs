# 账单与交易记录

控制台提供了完善的财务流水查询与对账凭据下载中心，帮助企业财务与个人开发者核对每一笔充值与套餐消费明细。

你可以通过以下任一入口直达账单界面：
- 在左侧菜单进入 **我的账户**，切换到顶部的 **账单** 页签；
- 在 **控制台概览** 页顶部直接点击 **账户余额** 数值；
- 在浏览器中直接打开 <a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">独立账单页面</a>。

---

## 核心视图分区

账单页顶层只有两个页签：**余额变动** 与 **订单**。旧版文档中的「流量使用（动态代理小时用量）」页签已从账单页移除（控制台文案资源里仍保留相关键名，但页面上不再展示）。动态代理的按小时/按日用量请在对应代理网络控制台（如 **住宅代理**）的 **用量** 页查看，而不是在账单页。

### 1. 余额变动（资金与充值账本）

记录与账户钱包余额相关的流水，是企业报销与财务审计的核心视图：

- **类别（与控制台一致）**：**充值**；用余额购买套餐时的 **余额消费**；自动续费时的 **余额续费**；**管理员赠送** / **管理员扣款**；**退款**；**欢迎额度** / **欢迎额度收回**；以及其它 **入账** / **扣款** 行。
- **充值方式**：常见包括 PayPal、银行卡（Evonet）、微信支付、UPI（印度）、USDT 链上充值等，入账后类别显示为 **充值**。
- **PDF 账单（重要）**：操作列 **账单** 仅对 **充值** 行显示 **PDF** 按钮，可生成含订单号、支付参考号、金额与 JoyProxy 抬头的正式凭证。**余额消费**、**余额续费**、退款、管理员调整、欢迎额度等行 **不提供** PDF 下载。
- **批量导出**：设定 **时间范围** → **应用筛选** → **批量下载账单 (ZIP)** 只会打包当前列表中 **带 PDF 按钮** 的记录（在余额变动页即主要为所选时间内的充值）。

### 2. 订单（产品购买历史）

展示 JoyProxy 产品订单档案，可用 **网络** 与 **类型**（动态 / 静态 / 自定义 / 网页抓取 API）筛选：

- 涵盖住宅、移动、商业、数据中心等网络下的动态流量包、静态线路、自定义端口、网页抓取 Credits 等；
- 列示日期、产品、类型、金额与说明。

**PDF 账单（重要）**：仅当该笔订单通过 **外部支付**（PayPal、Evonet 银行卡、微信支付、UPI 等）完成 **直接购买或续费** 时，操作列才会出现 **PDF**。**使用账户余额支付** 的购买/续费在 **订单** 页 **不显示** PDF（对应扣款会出现在 **余额变动** 的 **余额消费** / **余额续费** 中，同样无 PDF）。

## 账单管理与代理控制台的职责分工

- **查看生效中的资源**：端口状态、更换出口 IP、自动续费、剩余 GB、按小时流量曲线等，请在对应代理控制台的 **已购** 与 **用量** 页操作。
- **处理财务与资金**：导出报销凭证、核实充值到账、查询月度总消费，请在本文介绍的账单页处理。

## 常见财务问题指引

- **USDT 充值未实时入账？**  
  若通过区块链转账后关闭了窗口，请进入 **我的账户** → **资料**，使用 **认领 USDT** 功能自动扫描链上记录即可即刻补齐入账。
- **单笔消费金额有疑问？**  
  请记录下具体的订单号与发生时间，通过左侧菜单进入 **帮助中心** 提交技术 <a href="tickets.md" target="_blank" rel="noopener noreferrer">支持工单</a>，财务与技术团队会为你调取底层日志协助核对。
- **需要企业抬头专用发票？**  
  如需开具开票抬头包含特定企业名称与税号的商业发票，可通过右下角 <a href="live-chat.md" target="_blank" rel="noopener noreferrer">实时聊天</a> 联系在线财务客服，提供抬头税号与接收邮箱即可安排开具。
