# 账单与交易记录

在控制台的账单中心，你可以查询全部充值流水、订单消费明细并下载对账凭证。

访问入口：
- 导航栏进入 **我的账户**，切换至 **账单**；
- 在概览页直接点击 **账户余额** 数值；
- 直接访问 <a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">账单页面</a>。

---

## 页面结构

账单页面分为两个标签页：**余额变动** 与 **订单**。按小时或按天的代理流量消耗请前往具体代理服务（如住宅代理）的 **用量** 页面查看，账单页不包含流量用量报表。

### 1. 余额变动

记录账户钱包余额的所有出入账变动明细，涵盖以下来源：
- **充值入账**：通过 PayPal、信用卡 / 借记卡、Apple Pay、Google Pay、微信支付、UPI 或 USDT 等外部渠道充值到余额的记录。
- **余额消费**：使用账户余额直接购买代理套餐或产品自动续费产生的余额扣减。
- **账务调整**：退款返还、管理员赠送或扣款、欢迎额度发放与过期收回等。

### 2. 订单

汇总你在 JoyProxy 购买的所有产品订单，支持按网络类型（住宅、移动、商业、数据中心）及产品形态（动态、静态、自定义、网页抓取 API）进行筛选，显示订单对应的产品、规格时长、金额以及支付渠道。

## PDF 账单下载说明

系统支持生成并导出符合商业报销规范的正式 PDF 账单，但仅对实际发生资金支付的交易提供：

- **支持下载 PDF 的交易**：
  - **充值到余额**：在「余额变动」列表中，所有充值记录的操作列均提供 **PDF** 下载按钮；
  - **直接购买与续费**：在「订单」列表中，通过外部渠道（PayPal、信用卡、Apple Pay、Google Pay、微信支付、UPI 等）直接完成支付的订单，操作列提供 **PDF** 下载按钮。
- **不支持下载 PDF 的交易**：
  - **余额支付**：使用账户余额购买或续费的订单，不提供账单下载（充值到余额时已生成对应资金凭据）；
  - 余额变动中的余额扣减、退款、赠送及额度调整记录不提供账单下载。
- **批量导出**：选择时间范围后点击 **批量下载账单 (ZIP)**，系统仅会将所选区间内具备账单的资金交易打包下载。

## 常见问题

- **USDT 充值未到账**：若转账完成后关闭了充值页面，可进入 **我的账户** → **资料**，点击 **认领 USDT** 触发链上扫描即可入账。
- **账单金额疑问**：如对某笔扣费有疑问，可提供订单号或流水时间，通过左侧菜单提交 <a href="tickets.md" target="_blank" rel="noopener noreferrer">支持工单</a> 进行核对。
- **企业开票需求**：若需要开具包含指定企业名称与税号的专用账单，请通过 <a href="live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a> 联系我们协助开具。
