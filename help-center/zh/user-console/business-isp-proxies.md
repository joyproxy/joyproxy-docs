# 商业代理与 ISP 代理

> **产品升级提示**：原商业代理 / 商业 ISP 入口已整合升级为现售产品线。动态流量请选择 **[住宅代理](../getting-started/residential/)** / **[移动代理](../getting-started/mobile/)**；静态固定专线请选择 **[ISP（静态住宅）代理](../getting-started/isp/)**。


原先的「商业 / ISP」已拆成两条产品线，请分别进入对应控制台：

- [商业代理控制台](business-proxies.md) — 动态代理（按 GB），[打开控制台](https://www.joyproxy.com/admin-proxy-business.html)
- [ISP 代理控制台](isp-proxies.md) — 静态独享与自定义独享，[打开控制台](https://www.joyproxy.com/admin-proxy-isp.html)
