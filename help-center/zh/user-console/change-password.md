# 修改密码

定期更换复杂密码是保障代理资产与账单安全的基础措施。你可以直接在控制台中修改登录密码。

<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">打开修改密码页面</a>

---

## 操作步骤

1. 登录控制台，在左侧导航栏点击 **我的账户**。
2. 确认当前位于 **资料** 页签。
3. 找到 **修改密码** 卡片，按顺序填写以下表单：
   - **目前密码**：输入你当前正在使用的有效登录密码；
   - **新密码**：输入你要设定的新密码（长度至少 6 位，推荐包含大小写字母与特殊字符）；
   - **确认密码**：再次输入完全相同的新密码以防止误输入。
4. 点击表单下方的 **保存更改** 按钮提交。

保存成功后，界面顶部会弹出绿色的 **密码已更新！** 提示，即刻生效。

---

## 常见问题与注意事项

- **忘记目前密码怎么办？**  
  如果已经彻底忘记了当前登录密码，不要在修改密码表单中盲目尝试，请退出登录并前往 <a href="forgot-password.md" target="_blank" rel="noopener noreferrer">找回密码流程</a>，通过绑定的注册邮箱直接重设。
- **修改密码对已有自动化脚本的影响**：  
  所有通过 OpenAPI、提取链接（API URL）或抓取接口发起的调用均依托各类专属 Token 进行认证鉴权，**修改网页端登录密码完全不会中断现有的代理提取或抓取任务**。
- **第三方授权账号**：  
  如果你的账号自始至终仅通过 Google 或 GitHub 快捷授权登录，且从未单独设置过登录密码，请先使用忘记密码功能设置一次初始密码后再进行修改。
