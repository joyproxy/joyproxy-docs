# 注销账户

根据国际通用的数据隐私合规要求，JoyProxy 为用户提供完全自主的账户永久停用与注销能力。

注销操作入口位于：**我的账户** → **安全与 API** → **注销账户**。

---

## 注销前的严正风险提示（不可逆）

**注销账户是一项不可恢复的终态操作。在点击注销前，请务必仔细阅读以下条款：**

1. **已购资源即刻失效**：账户注销完成后，你名下正在运行的全部代理服务（包括尚未用完的动态流量包、生效中的静态独享与自定义专属端口、网页抓取 API 积分等）将立即终止下线，无法继续使用，也无法在后续恢复。
2. **账户剩余余额作废**：账户钱包内的剩余可用现金余额将随账户一同注销作废，无法申请退款、提现、折现、转移至其他账号或合并。
3. **历史数据与凭据清除**：账户注销后你将无法再次登录控制台，历史订单记录与 PDF 凭据将不再对外提供查询。如有财税报销需求，**必须在注销前** 前往 <a href="invoices.md" target="_blank" rel="noopener noreferrer">账单中心</a> 提前将所需 PDF 凭证下载并本地保存。
4. **移除生产环境依赖**：若你的企业生产环境正通过该账号的 Token 进行自动化爬取或业务转发，请提前切换至备用账号，避免注销导致生产业务瘫痪。

---

## 自助注销三步安全确认

为了防止用户误触造成重大财产损失，系统设置了严格的三道安全确认流程：

1. 进入 **我的账户** → **安全与 API**，滚动到底部点击 **注销我的账户** 红色按钮唤出注销向导弹窗。
2. 依次阅读并逐项点击 **我已了解，继续** 完成确认：
   - **第一步：确认已购产品作废**；
   - **第二步：确认账户余额作废不可退款**；
   - **第三步：最终确权**。
3. 在最后一步点击 **确认注销账户**。系统会在后端注销所有会话、释放所有关联资产并即刻将当前浏览器安全登出。

---

## 特殊账号或无法注销的情况

如果界面提示 **此类账户不能在此注销，请联系客服**，通常是因为你的账号属于企业直签大客户、名下有未结清的后付费账单或处于风控保护状态。此时请通过侧栏的 **帮助中心** 联系 <a href="live-chat.md" target="_blank" rel="noopener noreferrer">在线技术支持</a> 或提交工单，由专属客户经理协助你完成商务清算与线下注销。
