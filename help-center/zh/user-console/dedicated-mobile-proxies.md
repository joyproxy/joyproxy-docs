# 真机独享 4G/5G 代理控制台

在左侧导航栏 **代理服务 → 真机 4G/5G 代理**（`/admin-proxy-mobile-dedicated.html`）可一站式完成真机独享 4G/5G 代理的预订购买与端口资产管理：

- **预订 / 购买 Tab**：按国家或 `5G Only` 筛选 17 国 31 个独享 4G/5G 运营商，选择 **2 / 7 / 14 / 30 天** 租期与数量，点击 **「立即预订 · 24小时内开通」** 下单（*注：一经开通交付不支持退款*）。
- **我的代理 Tab**：顶部看板实时展示「预订待开通 / 运行中 / 即将到期 / 已过期」数量；列表支持行内备注编辑、一键复制 HTTP/SOCKS5/指纹浏览器配置、按需一键切换 IP、复制专属切换 API、续费及一键提工单。
- **总览与账单联动**：购买与续费记录会同步展示在 **总览** 的 6 个月产品消费趋势图与资产卡片，以及 **我的账户 → 账单与交易记录** 中。
