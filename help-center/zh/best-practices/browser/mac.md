# Mac 操作系统代理配置指南

macOS 操作系统提供了网络代理配置能力。在 macOS 系统设置中配置代理后，Safari 浏览器以及大部分系统网络请求均会自动通过指定的代理节点进行转发。

---

## 前置条件：配置 IP 白名单（推荐用于静态/自定义代理）

macOS 原生代理设置界面在配置账密时可能受部分应用兼容性影响。对于**静态独享或自定义代理**，推荐优先配置 IP 白名单免密认证：
1. 登录 JoyProxy 控制台，在目标代理网络的控制面板中选择 **账密与白名单**；
2. 点击 **将当前 IP 加入白名单**，录入当前 Mac 所在网络环境的公网 IP 地址；
3. 若使用的是动态代理或未配置白名单，可在 macOS 代理配置面板中勾选「代理服务器需要密码」并填入代理长用户名与密码。

---

## macOS Sonoma / Ventura 系统配置步骤

1. 点击屏幕左上角的 **苹果菜单（） → 系统设置**；
2. 在左侧侧边栏选择 **网络**；
3. 在右侧点击当前处于活动状态的网络连接（如 **Wi-Fi** 或 **以太网**）；
4. 点击网络名称旁边的 **详细信息...** 按钮；
5. 在弹出的属性设置面板中，切换至 **代理** 标签页；
6. 启用对应的代理协议：
   - **HTTP / HTTPS 协议**：打开 **网页代理（HTTP）** 与 **安全网页代理（HTTPS）** 开关；
   - **SOCKS5 协议**：打开 **SOCKS 代理** 开关；
7. 填入服务器参数：
   - **服务器**：填入控制台提供的接入域名（例如 `us-ca.edge.joyproxy.com`，切勿填写 Dedicated Exit IP）；
   - **端口**：填入对应的端口号；
   - （若未加白名单）勾选「代理服务器需要密码」，并填入代理用户名与密码；
8. 点击 **好**，并在主界面点击 **应用** 保存生效。

---

## 验证与恢复

- **验证状态**：打开终端（Terminal）执行 `curl https://ipinfo.io`，检查返回的 JSON 数据中的 IP 与地理属地；
- **恢复连接**：重新进入上述代理配置面板，关闭已启用的代理开关并应用即可恢复本地直连。
