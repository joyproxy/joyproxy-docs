# Ticket system

Submit a support ticket when you need a documented thread—for billing investigations, integration debugging, or issues that outlive a chat session.

## Create a ticket

1. Sign in → [Support](https://www.joyproxy.com/admin-support.html).
2. Open **My Tickets** (or **Submit ticket**).
3. Enter a clear **subject** (for example “Static US line auth failure”).
4. Choose **priority** if the form offers it.
5. Describe steps to reproduce, expected vs actual behavior, and timestamps (UTC helps).
6. Attach redacted screenshots or logs—remove passwords and full tokens.
7. Submit and watch for email or in-console replies.

## Status and follow-up

- Reply in the ticket thread instead of opening duplicates.
- Reference order IDs from [My Proxies](https://www.joyproxy.com/admin-my-orders.html) when traffic looks wrong.
- For urgent production outages, start [Live chat](live-chat.md) **and** file a ticket so engineers have context.

## Billing tickets

Link to [Transactions](https://www.joyproxy.com/admin-transactions.html) entries and state whether the issue is PayPal, balance, or scraping credits.

Legal or privacy requests may reference [Terms](https://www.joyproxy.com/terms.html) and [Privacy](https://www.joyproxy.com/privacy.html).
