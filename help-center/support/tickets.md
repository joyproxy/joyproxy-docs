# 工单系统

需要留痕记录时——账单核对、集成排错、或一次聊天说不清的问题——请提交工单。

## 创建工单

1. 登录 → <a href="https://www.joyproxy.com/admin-support.html" target="_blank" rel="noopener noreferrer">支持</a>。
2. 打开 **My Tickets**（或 **Submit ticket**）。
3. 写清**主题**（例如「静态美国线路认证失败」）。
4. 表单有**优先级**时按实际情况选择。
5. 写复现步骤、预期与实际结果，尽量带时间戳（UTC 更好）。
6. 附件用打码截图或日志，去掉密码和完整 Token。
7. 提交后留意邮件或控制台回复。

## 状态与跟进

- 在同一工单线程里回复，不要重复开单。
- 流量异常时附上 <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">My Proxies</a> 的订单 ID。
- 生产紧急故障可同时开<a href="live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>**并**提交工单，方便工程师对齐上下文。
