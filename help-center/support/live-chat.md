# 在线客服

实时联系 JoyProxy 支持，咨询购买、集成与账户问题。

## 从控制台进入

1. 登录后打开<a href="https://www.joyproxy.com/admin-support.html" target="_blank" rel="noopener noreferrer">支持</a>。
2. 切到 **Live Chat** 页签。
3. 说明你的目标（产品类型、目标地域、报错信息）。
4. 留在页面等客服接入，排队时间因时段而异。

## 从官网进入

在 <a href="https://www.joyproxy.com/" target="_blank" rel="noopener noreferrer">joyproxy.com</a> 点**聊天气泡**，或先打开 <a href="https://www.joyproxy.com/products/ai-customer-service.html" target="_blank" rel="noopener noreferrer">AI Assistant 产品页</a> 获取自动回答。

## 怎样更快解决

建议提供：

- 账户邮箱（不要发密码）
- 订单 ID 或大致购买时间
- 端点类型（轮换网关 vs 静态主机）
- 已打码的错误截图

账单争议请附上<a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">交易</a>里的交易 ID。
