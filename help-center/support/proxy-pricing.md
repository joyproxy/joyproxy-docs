## 计费模式（摘要）

| 模式 | 怎么付 |
| --- | --- |
| 轮换（住宅、移动、商业） | 流量包（GB）+ 有效期 |
| 静态 | 按 IP 与时长（日/周/月/年） |
| 定制 | 按端口与时长 |
| 网页抓取 API | 积分包；成功抓取才扣 |

轮换流量在使用时从套餐里扣。静态与定制在购买周期内有效，不按每日流量另算。
