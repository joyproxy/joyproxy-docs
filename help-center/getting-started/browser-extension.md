# Browser extension

The official **JoyProxy** extension applies a proxy to **this Chromium browser only** (Chrome, Edge, Brave, and others). A JoyProxy account is optional but lets you sync purchased lines.

## Install

1. Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/joyproxy/ogilogpkhgojddkmkogloikpfkkldjng).
2. Pin the extension on the toolbar.

## Basic use

1. Open the popup or side panel.
2. Paste a proxy string or sign in on joyproxy.com to load your lines.
3. Run a connectivity test and confirm exit IP / region.
4. Click **Apply** — system-wide proxy settings are unchanged.

See the [Browser Extension product page](https://www.joyproxy.com/products/browser-extension.html) for scope, allow lists, and advanced options.
