# Restricted targets

Use JoyProxy from a network **outside mainland China**, and send traffic to destinations the catalog covers. [Terms & Conditions](https://www.joyproxy.com/terms.html) also list uses that are not allowed.

## Mainland China

Live FAQ:

- JoyProxy does not sell mainland-China proxy IPs. Those routes are not in the purchase catalog.
- Networks **in** mainland China cannot reach the proxies.
- Proxy exits cannot reach **sites in mainland China**.

Run tests (cURL, [Proxy Tester](../software/proxy-tester.md), browsers) from outside mainland China, and aim at non-mainland destinations. Country, state, and city menus show what is in stock that day — see [Location targeting](location-targeting.md) and [Proxy locations](../../support/proxy-locations.md).

## If a website returns 403

After a successful IP check through the same endpoint, **403** on the real URL is usually the **website** (or its WAF), not a missing proxy password. See [Response codes](response-codes.md).

If you believe a specific destination is blocked on the JoyProxy side, [live chat](../../support/live-chat.md) or open a [ticket](../../support/tickets.md) with the URL (no live passwords).
