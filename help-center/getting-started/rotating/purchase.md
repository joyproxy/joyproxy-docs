# 选择网络并购买流量

轮换按 **GB** 计费。流量没用完、且订单还在有效期内，套餐就一直能用。买大一点的包，单价通常更低。

**住宅、移动、商业 / ISP 各有一套价格。** 付款前到 <a href="https://www.joyproxy.com/pricing.html" target="_blank" rel="noopener noreferrer">定价</a> 对比一下。

## 选哪种网络

| 网络 | 适合做什么 | 产品 |
| --- | --- | --- |
| **住宅** | 家庭宽带风格出口，国家/城市选项最全 | <a href="https://www.joyproxy.com/products/proxy-residential.html" target="_blank" rel="noopener noreferrer">住宅</a> |
| **移动** | 运营商（4G/5G）出口，应用或移动广告场景 | <a href="https://www.joyproxy.com/products/proxy-mobile.html" target="_blank" rel="noopener noreferrer">移动</a> |
| **商业 / ISP** | 目标站更认 ISP / 商业 ASN 时 | <a href="https://www.joyproxy.com/products/proxy-business.html" target="_blank" rel="noopener noreferrer">商业 / ISP</a> |

一个账户可以同时买多种网络。每条订单在 <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">我的代理（My Proxies）</a> 里单独显示。

## 在控制台购买

| 步骤 | 操作 |
| --- | --- |
| 1 | 登录，打开 <a href="https://www.joyproxy.com/admin-purchase.html?tab=short-term" target="_blank" rel="noopener noreferrer">购买 → 轮换</a> |
| 2 | 选**网络类型**：住宅、移动或商业 / ISP |
| 3 | 选**流量套餐**（试用可买几 GB；正式爬虫按真实用量加大） |
| 4 | 结账：卡、Apple Pay、Google Pay、PayPal、微信支付、UPI、USDT（TRC20）或账户余额 |
| 5 | 在 <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">我的代理</a> 等订单变成生效状态 |

> **提示**
>
> 结账有选项的话，首个符合条件的套餐可以用 **$5 注册赠金**。

## 付完款之后

- 网络控制台的 **Usage** 会显示剩余 GB。详情：<a href="usage-and-orders.md" target="_blank" rel="noopener noreferrer">用量与订单</a>。
- 有流量时端点生成一直能用；多生成几条用户名**不用**再买套餐。
- GB 快没了就回 <a href="https://www.joyproxy.com/admin-purchase.html?tab=short-term" target="_blank" rel="noopener noreferrer">购买 → 轮换</a> 续购，或开 <a href="auto-buy-traffic.md" target="_blank" rel="noopener noreferrer">自动购买流量</a>。
