# 受限目标与合规说明

为了维护健康合规的网络生态，JoyProxy 对部分特定网络与目标站点实行严格的合规拦截限制。

## 中国大陆网络限制

1. **不提供中国大陆境内出口 IP**。
2. **中国大陆本地网络环境中无法直接连接** JoyProxy 代理网关。
3. **代理出口 IP 禁止访问中国大陆境内网站**（包含以 `.cn` 结尾或服务器部署在大陆境内的站点）。

## 高风险禁止站点类别

- **银行与金融机构**：网上银行、支付网关、证券交易平台。
- **政府与公共机构**：政务门户系统、公共部门统一认证系统。
- **邮件与通讯系统**：网页邮箱批量登录或 SPAM 发包。
