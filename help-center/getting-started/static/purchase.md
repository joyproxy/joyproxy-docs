# 购买独享线路（Purchase Proxies）

静态独享代理按 IP 线路数量和套餐时长计费。购买成功后，每条线路在有效期内 100% 由你独享。

## 操作步骤

1. 登录 JoyProxy 控制台，进入左侧菜单 **<a href="https://www.joyproxy.com/admin-purchase.html" target="_blank" rel="noopener noreferrer">购买代理</a>** 页面。
2. 选择所需的网络类型：
   - **住宅代理**
   - **商业 / ISP 代理**
   - **数据中心代理**
3. 切换到 **静态独享代理** 标签页。
4. 选择时长套餐：
   - **日套餐**
   - **周套餐**
   - **月套餐**
   - **季套餐**
   - **年套餐**（包年享最高折扣）
5. 在 **选择 IP 地区** 区域：
   - 选择目标国家/地区（如美国、日本等）。
   - 设置该地区需要的 IP 数量。
6. 选择支付渠道完成付款：
   - **账户余额**
   - **PayPal**
   - **信用卡 / 借记卡**
   - **Apple Pay** / **Google Pay**
   - **微信支付**
   - **UPI**
   - **USDT（TRC20）**
7. 支付成功后，线路将即时分配开通。

下一步：进入 **<a href="view-lines.md" target="_blank" rel="noopener noreferrer">查看已购线路</a>** 确认已分配的端点。
