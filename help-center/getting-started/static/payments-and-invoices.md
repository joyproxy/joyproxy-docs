# 查询支付记录与下载凭证

1. 进入控制台 **<a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">交易记录</a>** 页面。
2. 查看订单流水明细（购买、续费、充值）。
3. 点击订单右侧的 **PDF** 即可即时下载 PDF 格式官方付款凭证。
4. 如需开具公司抬头发票，可联系 **<a href="../../user-console/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>**。
