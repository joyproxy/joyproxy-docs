# 查询支付记录与下载凭证（Payments & Invoices）

1. 进入控制台 **<a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">交易与订单（Transactions）</a>** 页面。
2. 查看订单流水明细（Purchase、Renew、Recharge）。
3. 点击订单右侧的 **下载收据（Download Receipt）** 即可即时下载 PDF 格式官方付款凭证。
4. 如需开具公司抬头发票，可联系 **<a href="../../user-console/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服（Live Chat）</a>**。
