# 查询支付记录与下载凭证（Payments & Invoices）

所有的网页抓取 API 积分包购买明细均可以在控制台中查验并即时导出官方凭证。

---

## 操作指南

1. 登录 JoyProxy 控制台，进入 **<a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">交易与订单（Transactions）</a>** 页面。
2. 在交易列表中找到购买抓取积分包的订单记录（类型显示为 `Web Scraping Pack`）。
3. 点击订单右侧的 **下载收据（Download Receipt）** 按钮。
4. 系统将自动下载 PDF 格式的官方付款收据凭证。

---
