# 查看用量与抓取日志

在控制台中，你可以实时监控网页抓取 API 的剩余积分、当前并发使用率以及详细的抓取历史请求日志。

---

## 用量看板管理

1. 登录 JoyProxy 控制台，点击左侧菜单 **<a href="https://www.joyproxy.com/admin-web-unblocker.html" target="_blank" rel="noopener noreferrer">网页抓取 API</a>**。
2. 切换到 **使用明细** 页签（或查看概览顶栏）。
3. 界面展示关键指标：
   - **可用积分**：当前账户中可用的总积分数。
   - **已用积分**：累计已消耗的抓取积分。
   - **当前并发**：显示「当前 / 上限」（如 `5 / 20`），实时反应此刻正在进行中的请求数与允许的并发槽位。
   - **成功率统计**：近 24 小时抓取请求的成功率。

---

## 实时抓取日志查询

在页面下方的表格中，记录了近期的每一笔抓取请求明细：

| 字段名称 | 说明 |
| --- | --- |
| **请求时间** | 发起抓取的时间戳。 |
| **目标 URL** | 被抓取的网页完整地址。 |
| **请求参数** | 是否开启了 `render`、`super` 或指定了 `geoCode`。 |
| **HTTP 状态码** | 目标响应状态码（如 `200`、`404` 等）。 |
| **扣除积分** | 本次请求实际扣除的积分（若失败显示 `0`）。 |
| **耗时** | 从发起请求到返回结果的总耗时（毫秒）。 |

可通过筛选框按时间范围、状态码或关键词快速定位排查问题请求。
