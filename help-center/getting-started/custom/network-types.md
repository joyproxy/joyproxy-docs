## 详细特性说明

### 1. 自定义独享住宅代理（Custom Residential Proxies）
- **真实家宽信任**：目标网站（如 Amazon、Facebook、Google）将其识别为普通家庭用户的住宅宽带，风控阻拦率极低。
- **按端口配置**：每个端口均可独立设定国家、省/州及城市，并支持按端口开启自动轮换。

### 2. 自定义独享商业 / ISP 代理（Custom Business / ISP Proxies）
- **商业 ISP 专线**：由顶级电信运营商（如 AT&T、Verizon、Comcast 等）提供的商业办公专线 IP，兼具住宅 IP 的高信任度与机房 IP 的高速稳定。
- **适合高吞吐业务**：适合需要频繁传输较大数据量、同时又要求高信任度 IP 的企业级对接。

### 3. 自定义独享数据中心代理（Custom Datacenter Proxies）
- **极致性价比与高并发**：IP 部署在云端机房，具备极低的网络延迟和极高的吞吐能力。
- **灵活多端口**：适合一次性批量订购 50-200 个端口进行大规模并行自动化抓取。
