# 分配地区

每个定制端口可以只定国家，或定国家 + 省，或定到具体城市。**同一订单**里的不同端口可以配**不同**地区。

## 操作步骤

| 步骤 | 操作 |
| --- | --- |
| 1 | 打开 <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">我的代理（My Proxies）</a> → **Custom Proxies** |
| 2 | 勾选一个或多个可用端口 |
| 3 | 点 **Assign region** |
| 4 | 选 **Country** → 可选 **Region / Province** → 可选 **City** |
| 5 | 确认。每个端口保留自己的地区设置 |

多市场测试可以这样用：一个端口跑美国站，另一个跑英国站，同一账户即可。

改地区只能在本页操作（不能用提取 API）。改完地域后，仍用该端口在 <a href="https://www.joyproxy.com/admin-ip-extraction-center.html" target="_blank" rel="noopener noreferrer">端点生成（Endpoints）</a> 拿到的 **host:port** 连接。

开定时轮换前应先完成分配地区，见 <a href="rotation.md" target="_blank" rel="noopener noreferrer">设置轮换</a>。
