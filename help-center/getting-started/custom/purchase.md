# Buy Custom ports

Custom is billed **per port** for a validity period (similar to Static, with extra geo controls). **Residential, Business / ISP, and Datacenter each have their own price.** Compare on <a href="https://www.joyproxy.com/pricing.html" target="_blank" rel="noopener noreferrer">Pricing</a>.

1. Open <a href="https://www.joyproxy.com/admin-purchase.html?tab=custom-ip" target="_blank" rel="noopener noreferrer">Purchase → Custom</a>.
2. Select **Residential**, **Business / ISP**, or **Datacenter**.
3. Choose a validity plan (price is per port).
4. Set **number of ports** and pay in checkout: card, Apple Pay, Google Pay, PayPal, WeChat Pay, UPI, USDT (TRC20), or account balance.
5. Find units under <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">My Proxies → Custom</a>.

You assign cities **after** payment—no need to lock one country at checkout the way Static does.

Enable <a href="auto-renew.md" target="_blank" rel="noopener noreferrer">Auto-renew</a> so ports extend from account balance.
