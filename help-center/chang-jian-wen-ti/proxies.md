# 代理使用与端点配置

本章详细说明如何正确配置与使用动态、静态及自定义代理，解释核心参数含义，帮助您规避常见配置误区。

## 动态代理使用指南

### 购买了动态流量后，该如何开始使用？
动态代理的使用非常简便，只需以下三步：
1. **创建认证凭证**：登录控制台，进入对应网络类型（如「住宅代理」）页面，切换到顶部的「白名单与用户」标签页，创建一个专用的用户名与密码（例如用户名前缀 `user1`，设置好密码）。
2. **生成代理端点**：切换到控制台的「代理提取」标签页，在「网页生成器」中选择您的订单、协议（HTTP 或 SOCKS5）、目标国家/城市以及会话模式（轮换或黏性保持），然后点击生成。
3. **填入客户端**：将生成的连接信息配置到您的软件中：
   - **代理主机（Host）**：固定为 `gate.joyproxy.com`
   - **代理端口（Port）**：固定为 `9001`
   - **用户名（Username）**：完整复制生成出来的整长串文本（切勿手动修改或删减）
   - **密码（Password）**：填写您在第一步中自己设置的代理密码

### 为什么所有动态代理连接的都是同一个 gate.joyproxy.com:9001？
这是云端动态网关的标准化架构。`gate.joyproxy.com:9001` 是 JoyProxy 全球动态分发集群的统一智能入口。
当您的客户端带着特定用户名连接该网关时，网关服务会毫秒级解析用户名中携带的参数（例如包含的目标国家、城市以及会话 ID），并在庞大的云端池中实时调度最匹配的真实住宅/移动宽带节点作为出口转发您的请求。这种架构不仅保证了高吞吐与高可用，还省去了爬虫频繁维护庞大代理列表的麻烦。

### 动态生成的用户名为什么那么长？能否自己改短？
**绝对不能自行删减或更改**。动态代理的用户名并不是普通的纯字母账号，而是高度编码的指令字符串，格式通常类似：
`user1-zone-resi-region-us-city-los_angeles-session-ab12cd-sessTime-30`
其中每一段都代表明确的路由规则：
- `user1`：您的代理主账号
- `region-us` / `city-...`：目标出境地理位置
- `session-...`：黏性会话标识
- `sessTime-30`：会话保持时间（分钟）

如果手动截断或修改该字符串，网关将无法识别您的路由需求，会导致鉴权失败（407 错误）或将流量错误路由至随机国家。

### 轮换模式（Rotating）与黏性会话（Sticky）该如何选择？
- **轮换会话（Rotating）**：每次发起新的 HTTP 请求，出口 IP 都会自动更换。适合大规模抓取网页、高频采集数据，能最大程度分散单个 IP 的请求频率。
- **黏性会话（Sticky）**：在指定时间内（支持 1~60 分钟自定义）尽可能保持使用同一个公网出口 IP。当时间到期或原宽带离线时，系统会自动平滑切换到同地区的新 IP。非常适合模拟真人浏览、电商网站多步骤登录加购或社交平台操作。

## 静态与自定义代理使用指南

### Entry Point（域名+端口）与 Exit IP（出口 IP）有什么区别？
这是新手最容易混淆的概念：
- **Entry Point（接入端点）**：格式形如 `us-ca.edge.joyproxy.com:10001`。这是您在客户端、爬虫或浏览器扩展中**唯一需要且必须填入的代理主机与端口**。
- **Dedicated Exit IP（专属出口 IP）**：形如 `198.51.100.24`。这是该线路实际对公网展示的真实 IP 地址，仅供您核对出口属地与外部环境，**绝对不能把 Exit IP 当作代理主机填入客户端**，否则会导致连接被拒。
> **控制台提示**：在控制台已购列表中，您可以通过表头的「隐藏出口 IP / 显示出口 IP」开关来避免混淆。

### 静态独享代理可以更换 IP 或地区吗？
- **更换出口 IP**：可以。在控制台「我的代理」列表中找到对应的静态线路，在操作列点击 **New IP（换新出口）**，系统会在同地区为您免费分配一个新的专属出口 IP。更换后，您的连接域名和端口保持不变，极大地简化了客户端维护。
- **更换地区**：不可以。静态代理在下单付款时就已经独占锁定了机房或宽带所属国家与城市，不支持跨国或跨城市变更。如果您的业务经常需要调整所在地区，请在购买时选择「自定义代理」。

### 自定义代理购买后显示「Unassigned（未分配）」是什么意思？
自定义代理是按「端口配额」交付的。刚完成付款时，端口尚未指定地理出口，因此状态为未分配。
您只需在控制台「我的代理」列表中点击该端口行的 **Assign（分配）** 按钮，选择期望的国家、州省或城市并保存，系统便会立即为您挂载该地区的出口线路。

### 自定义代理换区与自动轮换有什么规则？
- **更换地区**：您可以在端口有效期内随时点击 Edit 重新选择地区。需要注意的是，首次分配时若选择了「标准网络（Standard）」或「高级网络（Premium）」，后续换区只能在同一网络等级的资源库内选择。
- **定时自动轮换 IP**：自定义代理支持开启自动轮换。为了保证网络平稳，轮换间隔时间必须设置为 **60 的整数倍秒数（最少为 300 秒，即 5 分钟）**。您也可以在列表中随时点击手动更换 IP。

### 静态与自定义代理有流量或并发限制吗？
**没有任何流量、并发或带宽限制**。
静态独享与自定义代理均按「IP 数量/端口数 × 租用时间」计费。在服务有效期内，您可以不受限制地传输流量，也不设并发连接数阈值，适合大吞吐量与长连接业务。

## 常用工具与集成指引

### 如何在指纹浏览器（如 AdsPower、Hubstudio 等）中配置？
以静态独享线路为例：
1. 打开指纹浏览器，新建或编辑浏览器环境；
2. 代理类型选择 `HTTP` 或 `SOCKS5`；
3. 将 JoyProxy 控制台「我的代理」中显示的 **Entry Point** 拆分填入：域名填在代理主机栏，冒号后的数字填在端口栏；
4. 填写该网络下「白名单与用户」中设置的代理账号与密码（若已绑定本机公网 IP 到白名单，可免密填留空）；
5. 点击「测试连接」，检测通过且出口 IP 符合预期后即可保存启动。

### 代理提取接口（API）支持一次提取多少条？调用频率有什么限制？
通过 API 提取代理端点时，`count` 参数的有效取值范围为 **1 到 200**（单次最多返回 200 条端点）。
由于动态端点的网关地址与密码长期有效（只要账户内仍有流量额度即可持续使用），您不需要高频死循环轮询提取接口。如果调用过于频繁触发了速率保护，接口将返回 `429 Too Many Requests`，适当调大调用间隔即可恢复。
