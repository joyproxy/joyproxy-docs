# 常见问题速查

JoyProxy 为全球用户提供住宅、移动、商业/ISP、数据中心四大网络代理，以及全托管的网页抓取 API 与多款免费开源客户端工具。

为了帮你在产品选型、代理提取、软件配置、计费支付或代码集成中快速找到答案，我们梳理了以下七大常见问题分类。你可以根据当前业务需要直接点击查阅。

## 专题分类导航

### 1. <a href="products.md" target="_blank" rel="noopener noreferrer">产品与网络选型</a>
了解 JoyProxy 的核心产品矩阵，对比四大网络（住宅、移动、商业/ISP、数据中心）的适用场景，弄清动态轮换、静态独享与自定义多端口的形态差异，了解中国大陆地域与网络访问限制，以及新用户 $5 礼金规则。

### 2. <a href="proxies.md" target="_blank" rel="noopener noreferrer">代理提取与使用</a>
掌握动态代理的 Web 提取、API 提取与 AI 提取方式，理解统一网关 `gate.joyproxy.com:9001` 的长用户名机制，搞清静态独享线路中接入地址（Entry Point）与出口 IP（Exit IP）的本质区别，学会自主更换出口 IP、自定义端口多地区调配及指纹浏览器配置。

### 3. <a href="scraping-api.md" target="_blank" rel="noopener noreferrer">网页抓取 API 常见问题</a>
了解全托管 Web Scraping API 的核心优势，掌握「仅对成功请求扣费」的计费原则、不同模式（标准、JS 渲染、住宅 Super 出口）的积分消耗标准，以及接口调用鉴权与黏性会话配置。

### 4. <a href="software.md" target="_blank" rel="noopener noreferrer">客户端与开源工具</a>
获取 Chrome/Edge 浏览器扩展、Windows 连通性测试工具（Proxy Tester）、Android 客户端（Proxy Client）及自建网关（Proxy Server）的使用指南，了解开源工具的独立性与第三方节点兼容能力。

### 5. <a href="security.md" target="_blank" rel="noopener noreferrer">认证授权与账户安全</a>
理清四类专用 Token（主用户 Token、代理提取 API Token、网页抓取 Token、AI Token）的权限分工与应急轮换方法，掌握 IP 白名单与代理账密设置规则，了解邮箱激活与账号日常安全防范。

### 6. <a href="billing.md" target="_blank" rel="noopener noreferrer">购买、计费与财务账单</a>
查看各产品计费标准与阶梯折扣，了解流量无到期日的机制，掌握 PayPal、信用卡、微信支付与 USDT-TRC20 的充值及满赠规则，熟悉 Invoices 发票凭证下载及 7 天退款保障政策。

### 7. <a href="troubleshooting.md" target="_blank" rel="noopener noreferrer">常见报错与连接排查</a>
快速排查 407（代理鉴权失败）、401（未授权）、429（请求过于频繁）以及目标网站连接超时等典型报错，核对出口地理属地，掌握工单与客服的高效求助途径。
