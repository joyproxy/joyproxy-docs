# 常见报错与连接排查

当您在配置代理、调用接口或抓取网页遇到网络阻断时，请参考本章的诊断指南逐步排查定位。

## 典型 HTTP 报错代码排查

### 407 代理鉴权失败（Proxy Authentication Required）
这是最常见的配置错误，表明代理网关拒绝了您的连接请求。请按以下顺序检查：
1. **密码是否填写正确**：确认您填写的密码是控制台「白名单与用户」中为该网络创建的代理凭证密码，而不是您登录 JoyProxy 网站的账号登录密码。
2. **用户名是否被截断**：如果是动态代理，确认是否完整复制了 Endpoints 生成器返回的整长串用户名字符串。任何少拷一个字母或自行删减国家/会话标记的操作都会导致 407。
3. **白名单模式检查**：如果您计划免密使用，检查您当前的出口公网 IP 是否已经成功录入对应网络的「IP 白名单」中；请注意动态代理目前必须使用用户名密码鉴权。
4. **账户额度检查**：检查您的动态流量包是否已耗尽，或者静态/自定义线路是否已经过期未续费。

### 401 未经授权（Unauthorized）
通常出现在调用 RESTful API（如 `/v2/extract` 或 `/v2/fetch`）时：
1. **Token 混淆**：确认请求头中携带的 Token 类型是否正确。提取端点需要使用「代理提取 API Token」，抓取接口需要使用「Scraping API Token」，不能使用「主用户 Token（Master Token）」调用公网采集。
2. **请求头格式规范**：标准的 HTTP 头必须形如 `Authorization: Bearer <Your_Token>`（注意 Bearer 与 Token 之间有一个半角空格）。
3. **Token 是否已被轮换**：如果您此前在后台点击过 Rotate Token，旧 Token 会瞬间作废，请更新为最新的凭证。

### 429 请求过于频繁（Too Many Requests）
- **API 接口限频**：短时间内对提取接口或登录接口发起过高频率的死循环请求。请在代码中增加合理的重试间隔（退避重试，建议间隔 1~2 秒以上）。
- **抓取并发超限**：Web Scraping API 瞬时正在处理的请求数超过了您当前套餐的允许并发数（例如 Micro 套餐最大并发为 5），调低客户端工作协程数或升级至更高并发套餐即可解决。

### 502 / 504 目标连接超时或网关错误（Bad Gateway / Gateway Timeout）
- **目标站点不可达**：说明代理节点本身已成功建连，但在尝试访问目标网站时被对方服务器阻断、拒连或目标站正在宕机。
- **中国大陆目标限制**：确认目标网站是否位于中国大陆境内。JoyProxy 的所有境外代理节点出于合规原因均无法建立指向中国大陆域名的网络连接。
- **单节点偶发故障**：如果是静态独享线路出现 502，可在控制台「我的代理」中点击 **New IP**，免费重新分配该地区的健康出口。

## 连通性与地理属地疑难排查

### 代理配置好后，为什么浏览器或程序完全无法上网？
请按照以下清单快速诊断：
1. **确认本地网络环境**：请确保您当前测试的环境位于中国大陆以外（如境外 VPS、海外办公室网络）。从中国大陆境内直连代理网关会被阻断。
2. **检查端口与协议匹配**：如果您选择的是 HTTP 代理模式，软件中不要勾选 SOCKS5；如果是静态独享线路，必须填写形如 `us-ca.edge.joyproxy.com:10001` 的 Entry Point 接入端点，**绝对不能填写 Dedicated Exit IP**。
3. **测试底层端口通畅**：在终端中使用命令测试握手：
   `curl -x http://用户名:密码@gate.joyproxy.com:9001 https://ipinfo.io`
   若能返回公网 JSON 数据，说明代理链路本身完全正常，问题出在特定应用程序（如浏览器扩展或爬虫参数）的配置层。

### 检测到的出口 IP 属地与我购买/选择的地区不一致？
有时您指定了美国洛杉矶，但通过某些 IP 库查询却显示在其它城市：
- **全球 IP 数据库同步差异**：国际上存在多个主流商用 IP 地理数据库（如 MaxMind GeoIP2、IP2Location、DB-IP 等），不同数据库的更新周期存在数天到数周的延迟。
- **平台权威判定标准**：JoyProxy 严格以权威商用 IP 库（MaxMind / IPinfo 最新版本）为标准进行网络划分与路由交付。某些免费第三方查询网站的离线库可能滞后，建议以多个主流权威 IP 查询站的结果为准。

## 高效获取人工支持

如果您在对照上述排查手册后仍无法解决故障，请通过以下途径联系我们以获得最快协助：

1. **官网右下角实时客服（Live Chat）**：
   - 适合：售前咨询、即时连通性疑问、邮箱激活码未收到。
   - 提示：直接说明您的注册邮箱、正在使用的网络类型（如「住宅动态」）以及报错截图，客服人员能更快协助定位。
2. **控制台服务工单（Tickets）**：
   - 适合：财务对账、账单退款、复杂技术排障、企业定制合同。
   - 提交工单时，**强烈建议附带以下关键调试信息**：
     - 涉及的订单编号（Order ID）；
     - 报错信息完整截图或终端输出文本（如 curl 返回的具体状态码）；
     - 您尝试访问的目标站点域名（Target URL）；
     - 您在客户端使用的代理配置摘要（注意对密码脱敏）。
