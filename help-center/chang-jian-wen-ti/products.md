# 产品选型与服务介绍

本章汇总了 JoyProxy 平台定位、网络类型特性对比、产品形态差异及售前常见选型疑问，助您快速评估最适合您业务的技术方案。

## 核心业务与平台概览

### JoyProxy 究竟提供哪些服务？
JoyProxy 是一家专注于全球网络代理与数据采集基础设施的服务商，主要提供以下四类核心产品与服务：
1. **四大网络云端代理 IP**：覆盖全球 200+ 国家和地区、25,000+ 城市的住宅代理、移动代理、商业/ISP 代理与数据中心代理。形态包含按流量计费的动态轮换（Rotating）、独占固定线路的静态独享（Static）以及支持单端口换区的自定义代理（Custom）。
2. **AI 网页抓取服务（Web Scraping API）**：无需自行维护代理池与无头浏览器的托管式数据采集 API，内置智能绕过反爬机制与动态渲染，仅对 HTTP 2xx 成功响应扣除积分。
3. **免费开源软件矩阵**：提供免 Root 分流的 Android 客户端、批量连通性测试桌面端 Proxy Tester、轻量级网关 Proxy Server 以及即开即用的 Chromium 浏览器扩展。
4. **AI 生态扩展**：提供面向开发者和大模型的 OpenClaw Skill、AI MCP 插件与全天候客服能力。

### 四大网络类型（住宅、移动、商业、数据中心）有什么区别？如何选择？
不同业务场景对代理 IP 的网络属性要求各不相同：
- **住宅代理（Residential）**：出口 IP 来源于真实的家庭宽带网络，信誉度极高，目标网站风控感知最自然。非常适合大规模电商数据采集、社交媒体运营、多账号管理以及需要精确定位到特定城市的多语言验证业务。
- **移动代理（Mobile）**：出口 IP 来源于真实移动运营商的 4G/5G 蜂窝基站网络。移动基站天然具备成千上万真实手机共用同一 IP 的特点，目标平台对其容忍度最高。非常适合移动端 App 抓取、移动广告展示合规检测及短视频自动化业务。
- **商业/ISP 代理（Business / ISP）**：出口由正规企业级商业宽带或固定 ISP 专线托管，兼备数据中心的高速带宽与真实宽带的优质 ASN 标签。极适合需要长期稳定身份的企业 B2B 门户访问、供应商接口调用、海外金融风控核验等场景。
- **数据中心代理（Datacenter）**：出口位于云厂商机房。网络带宽充足、延迟极低、单位成本最低，且支持极高的并发量。适合目标网站风控策略较宽松的大规模批量请求、搜索引擎索引监测及高吞吐量数据同步。

### 动态（Rotating）、静态（Static）与自定义（Custom）形态有什么区别？
为了适配不同的采集与系统架构，代理产品分为以下三种形态：

| 产品形态 | 计费模式 | 线路属性 | 更换 IP 机制 | 典型适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **动态代理（Rotating）** | 按实际消耗 GB 计费，流量无到期日 | 每次请求或固定会话轮换共享 IP 池 | 每次请求自动换，或保持 1~60 分钟长效会话 | 爬虫抓取、高并发采集、批量验活 |
| **静态独享（Static）** | 按 IP 数量 × 购买周期计费，不限流量/并发 | 有效期内专属独占一条固定线路（Entry Point 固定） | 地区锁定；支持在控制台免费申请换新出口 IP（New IP） | 社交平台养号、固定店铺运营、长期身份维护 |
| **自定义代理（Custom）** | 按端口数量 × 购买周期计费，不限流量/并发 | 按端口交付（购买后需在后台 Assign 地区后激活） | 允许在同网络内随时换国家/城市，并支持定时或手动轮换 | 需固定通道端口但需要多地区灵活切换的自动化系统 |

> **提示**：移动网络由于网络天然特性，目前仅提供按流量计费的动态模式；数据中心网络提供静态与自定义形态，不提供按流量计费的动态轮换。

## 选型与功能疑问

### 什么是商业/ISP 动态代理？它和普通住宅动态有什么不同？
商业/ISP 动态代理（Rotating Business）结合了商业专线与动态轮换机制。它的出口 IP 带有企业级 Commercial ISP 的 ASN 属性，同时支持按会话时长或单次请求自动轮换 IP，按消耗的 GB 流量计费。
对于需要频繁变换 IP 采集数据，但目标系统（如某些海外 B2B 采购门户、财税合规网站）排斥普通家庭宽带 ASN 的业务，商业/ISP 动态代理是最佳平衡点。

### 网页抓取 API 与代理 IP 有何本质区别？
- **代理 IP**：给您提供的是代理服务器的连接地址（`host:port`）。您需要自己在客户端或代码中处理网络协议、身份认证、请求头指纹、Cookie 保持、验证码识别及失败重试逻辑。
- **网页抓取 API**：属于全托管数据采集接口。您只需提交目标网址（URL），服务端通过 AI 算法全自动调度最合适的代理出口、处理 Cloudflare/Akamai 等防护系统、执行 JavaScript 脚本渲染，并直接将干净的 HTML 或结构化 JSON 返回给您。
- **选型建议**：如果您的核心诉求是「拿到特定网页的内容」且希望省去维护代理池和爬虫架构的精力，优先选用 Web Scraping API；如果您需要底层控制 TCP/SOCKS 链路、运行特定桌面软件或直接登录国外网页，请选择代理 IP。

### 覆盖多少国家和地区？可以精确定位到城市吗？
JoyProxy 的代理网络目前覆盖全球 200 多个国家与地区，拥有超过 25,000 个城市节点。
在生成动态代理端点或购买静态/自定义代理时，您可以精确指定目标国家（ISO 二字代码）、省份/州（State）以及具体城市（City）。各网络类型的具体可用地区与城市清单，请以控制台购买页与提取中心当时的实时数据为准。

### 支持哪些网络协议？
平台云端代理节点完整支持 **HTTP**、**HTTPS** 与 **SOCKS5**（支持 TCP/UDP 转发）协议。在生成代理端点或编写配置文件时，您可以根据需要自由选择。常见的浏览器与网页爬虫一般使用 HTTP/HTTPS；需要更底层套接字转发或特定协议支持时建议使用 SOCKS5。

## 合规政策与体验咨询

### 是否可以从中国大陆网络环境直接连接代理？
**不可以**。出于网络合规与国际专线链路要求：
1. 位于中国大陆境内的网络无法直接连接 JoyProxy 的代理服务器（连接会被阻断或提示地区不支持）；
2. JoyProxy 的所有代理出口节点均无法访问中国大陆境内的网站与网络服务。
请务必在中国大陆以外的境外服务器、海外 VPS 或合规出海网络环境下配置和使用本服务，并仅用于合规出海业务。

### 能否购买中国大陆境内的代理 IP？
**不能**。JoyProxy 的全球地区节点列表中不包含中国大陆境内的任何 IP 资源。
