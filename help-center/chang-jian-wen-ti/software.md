# 客户端与开源工具

JoyProxy 秉承开放原则，为开发者提供了涵盖浏览器、桌面端、移动端及服务端的全套开源免费工具。本章介绍各工具的定位与使用注意事项。

## 工具矩阵概览

### JoyProxy 提供了哪些开源软件？是否收费？
**所有软件与客户端工具完全免费且开源**，不收取任何软件许可费用：
1. **JoyProxy 浏览器扩展（Chrome / Edge Extension）**：基于 Chromium 平台，支持在浏览器工具栏一键配置、测试与切换代理，账号免登也可使用。
2. **代理连通性检测工具（Proxy Tester）**：专为 Windows 平台打造的专业检测工具，支持 HTTP 与 SOCKS5 代理的出口连通性、时延测速与批量验证。
3. **Android 客户端（Proxy Client）**：基于现代网络内核打造的 Android 手机客户端，免 Root 环境支持按应用分流。
4. **代理服务端网关（Proxy Server）**：支持在 Linux 与 Windows 物理机或云服务器上快速搭建属于您自己的 HTTP/SOCKS5 网关中继。

> **说明**：工具软件本身免费，您既可以配合 JoyProxy 的付费云端代理使用，也可以搭配您自己的第三方代理节点使用。

## 浏览器扩展使用说明

### 浏览器扩展怎么安装？
您可以在 Chrome 网上应用店（Chrome Web Store）或 Microsoft Edge 插件中心搜索 **JoyProxy**，点击添加到浏览器即可完成安装。

### 扩展会改变我整台电脑的系统代理吗？
**不会**。JoyProxy 浏览器扩展使用的是浏览器的专属网络代理 API（Chrome Proxy API）。它的所有代理规则**只对当前浏览器生效**，绝对不会修改 Windows 或 macOS 操作系统的底层系统网络设置，不会影响您电脑上同时运行的微信、钉钉、邮件客户端或其他应用程序。

### 如何通过扩展快速使用静态线路？
1. 登录 JoyProxy 控制台，在「我的代理」中找到您的静态线路，记下 Entry Point（域名与端口）以及认证账密；
2. 点击浏览器工具栏的 JoyProxy 扩展图标；
3. 选择 **Static（静态）** 标签，填写线路域名与端口（若已登录账号，可直接在下拉列表中同步点选）；
4. 点击 **Test and apply（测试并应用）**，测试通过后扩展顶部会点亮出口状态，此时该浏览器的所有标签页都将通过该专线访问；
5. 工作结束后，只需点击扩展右上角的 **Direct（直连模式）**，即可一键恢复本地直连。

### 扩展是否可以搭配其他商家的代理使用？
**完全可以**。扩展设计了独立的「Address（地址簿）」与第三方提取功能。您可以粘贴任意第三方服务商提供的 `host:port:user:pass` 端点，也可以配置第三方 API 提取链接。扩展同样会在应用前为您验证连通性与真实出口 IP。

## Proxy Tester 桌面工具

### Proxy Tester 主要用来做什么？
Proxy Tester 是一款免安装或轻量级安装的 Windows 实用工具，主要用于：
- **批量连通性验证**：一次性导入成百上千条代理列表，多线程快速筛除失效节点；
- **真实出口地理核验**：自动检测各节点对外呈现的公网 IP、国家、省份、城市及 ASN 归属；
- **协议握手测速**：精准测量 HTTP、HTTPS 及 SOCKS5（含 TCP 与 UDP）的建连延迟与响应时间；
- **便捷测试**：同样支持测试任意第三方商家的代理节点，是爬虫运维与跨境电商环境排查的高效助手。

## Android 客户端与 Proxy Server

### Android 客户端（Proxy Client）有什么亮点？
- **免 Root 权限**：基于系统 VpnService 特性，普通手机无需获取 Root 权限即可稳定运行；
- **精准按应用分流（Per-App Routing）**：您可以单独指定某些特定海外应用（如 TikTok、Twitter、海外银行 App）走代理流量，而让国内常用应用（如微信、高德地图）保持直连，避免产生多余的代理流量消耗。

### Proxy Server 网关适合什么场景？
如果您在内网拥有多台没有公网访问权限的内网爬虫服务器，或者希望将多路代理出口整合成一个统一内网 IP 对内提供服务，您可以在一台 Linux/Windows 跳板机上部署开源 Proxy Server，作为企业内网专用的代理中继桥梁。
