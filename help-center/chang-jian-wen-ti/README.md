# 常见问题速查

JoyProxy 为全球用户提供四大代理网络（住宅、移动、商业/ISP、数据中心）、AI 驱动的网页抓取 API 以及多款开源客户端工具。

为了帮您更快解决在产品选型、代理配置、计费支付或代码集成中遇到的问题，我们将用户常见疑问整理归纳为以下七个专题分类。您可以根据当前业务阶段点击对应章节查看详细解答。

## 专题分类导航

### 1. <a href="products.md" target="_blank" rel="noopener noreferrer">产品选型与服务介绍</a>
了解 JoyProxy 的核心产品矩阵，对比四大网络类型（住宅、移动、商业/ISP、数据中心）的适用场景，分清动态轮换、静态独享与自定义多端口的形态差异，了解中国大陆地域与访问合规限制以及新用户体验金政策。

### 2. <a href="proxies.md" target="_blank" rel="noopener noreferrer">代理使用与端点配置</a>
掌握动态共享网关 `gate.joyproxy.com:9001` 的工作原理与长用户名格式，理解静态独享线路中连接域名（Entry Point）与出口 IP（Exit IP）的本质区别，学会自助更换出口 IP、自定义端口多地区调配及主流软件配置方法。

### 3. <a href="scraping-api.md" target="_blank" rel="noopener noreferrer">网页抓取 API 常见问题</a>
了解托管式 Web Scraping API 的优势，弄懂「仅对成功请求扣费」的计费规则、不同渲染模式（标准、JS 动态渲染、Super 住宅出口）的 Credits 消耗标准，掌握接口调用鉴权与黏性会话配置。

### 4. <a href="software.md" target="_blank" rel="noopener noreferrer">客户端与开源工具</a>
获取 Chrome/Edge 浏览器扩展、Windows 连通性检测工具（Proxy Tester）、Android 客户端（Proxy Client）及自建网关（Proxy Server）的使用指南，了解各开源工具的独立性与第三方节点兼容能力。

### 5. <a href="security.md" target="_blank" rel="noopener noreferrer">账户安全与认证授权</a>
理清四类专用 Token（主用户 Token、代理提取 API Token、网页抓取 Token、AI Token）的权限分工与应急轮换方法，掌握 IP 白名单与用户名密码的配置规则，了解账号安全防范与找回流程。

### 6. <a href="billing.md" target="_blank" rel="noopener noreferrer">购买、计费、充值与退款</a>
查看各产品计费标准与批量阶梯折扣，了解流量无到期日的机制，掌握 PayPal、信用卡、微信支付与 USDT-TRC20 的充值及满赠规则，熟悉发票凭证下载及 7 天退款保障政策。

### 7. <a href="troubleshooting.md" target="_blank" rel="noopener noreferrer">常见报错与连接排查</a>
快速排查 `407 Proxy Authentication Required`（认证失败）、`401 Unauthorized`、`429 Too Many Requests` 以及目标网站连接超时等典型报错，核对出口地理属地，掌握工单与客服的高效求助途径。
