# Assign Region for Custom Proxies

Each custom port can target country-only, country + province, or an exact city.

- Open [My Proxies](https://www.joyproxy.com/admin-my-orders.html) → **Custom Proxies** tab
- Select one or more active units (checkboxes)
- Click **Assign region**
- Choose **Country** → optional **Region / Province** → optional **City**
- Confirm — each port keeps its own geo assignment independently

**💡 Tip**You can assign different regions to different ports in the same order (e.g. US store + UK store on separate ports).
