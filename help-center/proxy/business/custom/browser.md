# Browser Proxy

Route browser traffic through JoyProxy — recommended: official extension; alternative: Windows system proxy.

## Recommended: JoyProxy Browser Extension

- Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/joyproxy/ogilogpkhgojddkmkogloikpfkkldjng) (compatible with Edge and other Chromium browsers)
- See the [Browser Extension product page](https://www.joyproxy.com/products/browser-extension.html) for screenshots and features
- Paste your own proxy or sign in on joyproxy.com to load purchased lines
- Test exit IP, then apply — affects this browser only, not system proxy

> **💡 Tip**No JoyProxy account needed for your own proxies. Sign in only for website-purchased lines.

## Alternative: Windows system proxy

### Microsoft Edge (Windows)

- Settings → System → **Open your computer's proxy settings**
- Enable **Use a proxy server**
- Address = host; Port = port from the generator
- Enter proxy username/password if prompted

### Google Chrome

Chrome on Windows uses system proxy. Configure via Windows settings above.

## Verify

Visit an IP-check site to confirm egress matches your assigned region.
