# Mobile Devices

Configure proxy on iOS or Android (Wi-Fi level).

## iOS

- Settings → Wi-Fi → (i) next to your network
- Configure Proxy → Manual
- Server = host; Port = port
- Authentication if your app requires credentials

## Android

- Wi-Fi → long-press network → Modify → Advanced → Proxy → Manual
- Hostname = host; Port = port

Mobile HTTP proxy may not support all apps; use credential-aware proxy apps if needed.
