# Purchase Custom Residential

Custom residential orders are priced **per port** × validity. Region and rotation are configured after purchase. Select **Residential** + **Custom**.

- Open [Purchase → Custom](https://www.joyproxy.com/admin-purchase.html?tab=custom-ip)
- Confirm network type is **Residential**
- Choose a validity plan (price per port)
- Set number of ports → pay with balance or PayPal

**🧩 After purchase**Assign each port’s region and optional rotation in [My Proxies → Custom](https://www.joyproxy.com/admin-my-orders.html). Business/Datacenter custom lines follow the same steps with a different network type.
