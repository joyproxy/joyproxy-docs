# AI MCP

Connect JoyProxy as an MCP server in Cursor, VS Code, or Claude Desktop.

- See [AI MCP product page](https://www.joyproxy.com/products/ai-mcp.html) for MCP JSON template
- Copy MCP config and paste your AI Access Token from [AI endpoint generator](https://www.joyproxy.com/admin-ip-extraction-center.html?panel=ai)
- Restart your IDE MCP client and use tool-based endpoint generation prompts
