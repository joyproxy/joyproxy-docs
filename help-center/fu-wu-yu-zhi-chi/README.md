# 帮助中心控制台

在 JoyProxy 控制台中，可通过左侧菜单 **帮助中心**（`sidebar.helpCenter`）获取全方位的技术支持与咨询服务。

**访问入口：** <a href="https://www.joyproxy.com/admin-support.html" target="_blank" rel="noopener noreferrer">admin-support.html</a>

---

## 包含模块

控制台统一整合了两种服务方式，适应不同场景需求：

### 1. 提交工单（Submit Ticket）

用于需要留痕、复杂故障排查、账单核对或大批量商务定制等场景。每个工单均具备专属工单号与处理状态，支持上传错误日志与截图附件。

- **快速入口：** 左侧菜单 **帮助中心** → **提交工单**
- **详细指南：** <a href="tickets.md" target="_blank" rel="noopener noreferrer">工单系统</a>

### 2. 实时聊天（Live Chat）

用于突发故障咨询、购买前选型建议、紧急解惑等高时效性需求。在浏览器内直接与在线工程师沟通。

- **快速入口：** 左侧菜单 **帮助中心** → **实时聊天**（或点击控制台全站右下角的快捷客服图标）
- **详细指南：** <a href="live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>
