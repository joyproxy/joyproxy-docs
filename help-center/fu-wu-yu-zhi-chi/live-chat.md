# 实时聊天

紧急问题或选购咨询，可直接与在线客服对话。

---

## 在控制台打开

1. **帮助中心** → **实时聊天**（或 <a href="https://www.joyproxy.com/admin-support.html?tab=chat" target="_blank" rel="noopener noreferrer">打开聊天页</a>）。
2. 点 **开始实时聊天**。
3. 在窗口中发送文字、截图或代码片段。

## 右下角气泡

控制台任意页或官网首页右下角的聊天气泡，可随时唤起小窗。

---

## 建议提供的信息

- 注册 **邮箱**（勿发密码）
- 产品类型（住宅 / 移动 / 静态 / 抓取 API 等）与订单号
- 报错截图或脱敏后的命令输出
- 账单问题：充值单号、USDT 哈希或 PayPal 交易号
