# 在线客服

实时联系 JoyProxy 支持，获取购买建议、集成问题与账户协助。

## 从控制台进入

1. 登录并打开[支持](https://www.joyproxy.com/admin-support.html)。
2. 切换到 **Live Chat** 页签。
3. 说明您的目标（产品类型、目标地域、错误信息）。
4. 留在页面直至客服接入——排队时间因时段而异。

## 从官网进入

在 [joyproxy.com](https://www.joyproxy.com/) 营销页使用**聊天气泡**，或先访问 [AI Assistant 产品页](https://www.joyproxy.com/products/ai-customer-service.html) 获取即时自动回答。

## 更快获得帮助

请提供：

* 账户邮箱（切勿提供密码）
* 订单 ID 或大致购买时间
* 端点类型（轮换网关 vs 静态主机）
* 已打码的错误截图

账单争议请附上[交易](https://www.joyproxy.com/admin-transactions.html)中的交易 ID。
