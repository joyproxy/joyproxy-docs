# iOS 与 iPadOS 设备代理配置教程

在 Apple iOS 与 iPadOS 设备上，可以在已连接的 Wi-Fi 网络设置中配置手动 HTTP 代理，或借助支持标准协议的网络工具进行代理调度。

---

## 方法一：使用 iOS 系统原生 Wi-Fi 代理配置

适合在 Wi-Fi 网络下快速配置 HTTP 代理：

1. **前置白名单设置**：如果使用的是静态独享或自定义代理，建议先在 JoyProxy 控制台「账密与白名单」中添加当前网络的公网 IP，以实现免密通行；使用动态代理网关时则必须配置账密；
2. 打开 iPhone / iPad 的 **设置 → 无线局域网（Wi-Fi）**；
3. 点击当前连接 Wi-Fi 旁边的 **感叹号图标 ⓘ**；
4. 滚动至底部，点击 **配置代理**；
5. 将模式切换为 **手动**；
6. 填入参数：
   - **服务器**：填入接入域名（如 `us-ca.edge.joyproxy.com`）；
   - **端口**：填入对应的端口号；
   - （若未加白名单）开启「鉴定」开关，输入代理用户名与密码；
7. 点击右上角 **存储**。

---

## 方法二：使用标准网络代理工具（移动蜂窝网络通用）

若需要在移动蜂窝网络（4G/5G）下配置代理，或进行规则分流，可以使用支持标准 HTTP/SOCKS5 协议的第三方工具：
1. 在工具中添加 `HTTP` 或 `SOCKS5` 节点；
2. 填入接入域名、端口与代理凭据；
3. 开启连接并选择规则分流模式。
