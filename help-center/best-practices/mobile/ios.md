# 苹果手机与 iPad 怎么设置代理 IP

苹果公司的 iOS 和 iPadOS 操作系统支持在已连接的 Wi-Fi 网络下配置手动 HTTP 代理，也支持借助网络工具配置更为精准的规则分流代理。本文为你介绍两种最常用的配置方式。

---

## 方法一：利用 iOS 原生 Wi-Fi 代理设置（无需安装任何软件）

这是苹果系统自带的原生功能，设置简单，适合不需要复杂分流的轻度使用。

### 1. 准备工作：
由于 iOS 原生 Wi-Fi 代理的账密验证在某些 iOS 版本中偶发弹窗不及时，最稳妥的方式是：
- 登录 JoyProxy 控制台，进入「用户与白名单」；
- 点击 **将当前 IP 加入白名单**（确保手机所连 Wi-Fi 宽带的公网 IP 已加白，实现免密直连）。

### 2. iPhone / iPad 具体设置步骤：
1. 打开手机的 **设置（Settings）**，进入 **无线局域网（Wi-Fi）**；
2. 找到当前已经连接的 Wi-Fi，点击右侧的 **蓝色感叹号图标 ⓘ**；
3. 滑动屏幕到最底部，找到 **HTTP 代理（HTTP PROXY）** 一栏，点击 **配置代理（Configure Proxy）**；
4. 默认是「关闭」，勾选切换为 **手动（Manual）**；
5. 填入参数：
   - **服务器（Server）**：填入 JoyProxy 控制台的 Entry Point 域名（例如 `us-ca.edge.joyproxy.com`）；
   - **端口（Port）**：填入对应的端口数字；
   - **认证（Authentication）**：如果前面已经添加了 IP 白名单，保持关闭即可；如果未加白名单，打开该开关，填入你在后台设置的代理用户名与密码；
6. 点击右上角的 **存储（Save）**。

### 3. 验证与还原：
- 打开 Safari 浏览器，访问 `https://ipinfo.io` 检查出口国家与城市；
- 不用时，重新回到上述页面，将配置代理改回 **关闭（Off）** 并存储即可。

---

## 方法二：使用 iOS 规则分流工具（如 Shadowrocket 等，高级推荐）

如果你需要让苹果手机在移动蜂窝网络（4G/5G）下也能用代理，或者希望实现**国内流量直连、海外应用走代理**的分流体验，可以使用支持标准 HTTP/SOCKS5 代理的第三方网络工具（例如在海外 App Store 下载的 Shadowrocket 小火箭）：

1. 打开网络工具，点击右上角 **添加节点（+）**；
2. **类型（Type）**：选择 `HTTP` 或 `Socks5`；
3. **服务器（Server）**：填写控制台的 Entry Point（接入域名）；
4. **端口（Port）**：填写对应的端口数字；
5. **用户名 / 密码**：完整填入你在控制台设置的代理账号与密码；
6. 保存后在列表中选中该节点，开启主连接开关；
7. 全局路由选择 **配置（Config / 分流）** 模式，即可畅享海外应用走专线、国内软件走本地直连的高速体验。
