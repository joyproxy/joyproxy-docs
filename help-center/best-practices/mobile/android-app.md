# 安卓手机怎么用官方 App 让指定软件走代理

在安卓手机上使用代理时，很多用户最大的顾虑是：**手机挂上海外代理后，微信、高德地图、外卖等国内 App 也会跟着走代理，不仅浪费珍贵的代理流量，还会导致国内 App 频繁异地登录报警或无法定位**。

针对这个痛点，JoyProxy 官方推出了免费开源的 **JoyProxy Android 客户端**，自带 **按应用分流（Per-App Routing）** 功能，可以精准做到：**只让特定海外 App 走海外代理，国内所有应用完全保持本地直连**。

---

## 第一步：下载与安装客户端

1. 打开安卓手机自带的浏览器；
2. 访问 JoyProxy 官网软件下载中心：<a href="https://www.joyproxy.com/products/software.html" target="_blank" rel="noopener noreferrer">JoyProxy 软件下载</a>；
3. 下载 **Proxy Client (Android)** 的 APK 安装包并完成安装；
4. 客户端基于系统官方的底层网络特性运行，**手机完全不需要获取 Root 权限**，安全纯净。

---

## 第二步：配置代理连接信息

1. 打开 JoyProxy 客户端，点击右上角或底部的 **添加配置（Add Profile）**；
2. 根据你在控制台购买的产品选择配置类型：
   - **如果你使用的是静态独享线路**：
     - 类型选择：`HTTP` 或 `SOCKS5`；
     - 服务器地址（Server）：填入在控制台「我的代理」中看到的 **Entry Point 域名**（例如 `us-ca.edge.joyproxy.com`）；
     - 端口（Port）：填入对应的端口号；
     - 身份验证：勾选启用，输入在控制台「用户与白名单」里创建的代理用户名与密码；
   - **如果你使用的是动态代理**：
     - 服务器填 `gate.joyproxy.com`，端口填 `9001`；
     - 用户名填入提取器生成的整长串用户名，填入代理密码；
3. 点击右上角保存配置。

---

## 第三步：开启「按应用分流」（核心功能）

这是避免多余流量浪费的关键设置：

1. 在客户端主界面，进入 **分流设置（Routing / Per-App Proxy）**；
2. 将分流模式切换为 **仅代理选中的应用（Proxy only selected apps）**；
3. 此时界面会列出手机中安装的所有 App 列表；
4. 勾选你真正需要走代理的海外软件，例如：
   - Instagram、TikTok、X（Twitter）、YouTube、海外银行应用或跨境电商卖家端 App；
5. 其余所有的日常软件（微信、支付宝、银行客户端等）全部保持不勾选。

---

## 第四步：启动连接与验证

1. 回到客户端首页，选中刚刚创建的配置，点击圆形的 **启动按钮（Connect）**；
2. 首次启动时，安卓系统会弹出一个系统的「网络连接请求」权限提示框，点击 **允许 / 确定**；
3. 连接成功后，顶部通知栏会常驻一个安全钥匙图标；
4. **验证分流效果**：
   - 打开勾选的海外 App，能够流畅加载海外页面；
   - 打开手机浏览器访问百度或高德地图，显示的依然是你本地所在的真实城市与 IP，国内流量完全不消耗代理流量。
