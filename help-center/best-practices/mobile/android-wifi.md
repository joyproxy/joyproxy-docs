# 安卓手机连 Wi-Fi 怎么手动填代理

如果你不想在安卓手机上安装任何第三方客户端软件，只要手机连上了无线无线网（Wi-Fi），你可以直接利用安卓系统自带的 Wi-Fi 高级设置，手动填入代理 IP。

> **适用场景说明**：手动 Wi-Fi 代理设置适合轻度临时浏览、在办公室或家里固定 Wi-Fi 下测试网页。这种方式会让连在该 Wi-Fi 下的整台手机所有流量都尝试走代理，无法单独按 App 分流。

---

## 第一步：准备好代理白名单（关键）

安卓系统原生的 Wi-Fi 代理设置界面只支持填写「代理主机名」和「代理端口」，**绝大多数安卓手机不支持在 Wi-Fi 界面里输入用户名和密码**。

因此，在手机上配置前，建议采用以下两种方式之一：
- **方案 A（最推荐）**：使用 **静态独享代理**，并将你当前 Wi-Fi 的宽带公网 IP 在 JoyProxy 控制台的「用户与白名单」中**加入 IP 白名单**，这样手机连接时即可全自动免密认证；
- **方案 B**：如果使用动态代理，需要在手机浏览器打开网页时，在弹出的系统对话框中手动输入代理用户名和密码。

---

## 第二步：进入安卓手机 Wi-Fi 高级设置

不同品牌的安卓手机（小米 MIUI/澎湃OS、华为鸿蒙、vivo、OPPO、三星）界面文案略有不同，但大体逻辑一致：

1. 打开手机 **系统设置**，点击 **WLAN / Wi-Fi / 无线网络**；
2. 找到你当前已经成功连接的那个 Wi-Fi 名称；
3. 调整该 Wi-Fi 的属性：
   - 有的机型是长按该 Wi-Fi 名称，选择 **修改网络**；
   - 有的机型是点击 Wi-Fi 名称右侧的小箭头（`>`）或 **感叹号图标（i）** 进入详细属性；
4. 在属性页面中找到 **高级选项（Advanced options）** 或 **代理（Proxy）** 栏目；
5. 默认状态是「无（None）」，点击下拉菜单，切换为 **手动（Manual）**。

---

## 第三步：填入 JoyProxy 代理参数

在展开的手动代理表单中：
1. **代理主机名（Proxy hostname）**：
   - 填写 JoyProxy 控制台给出的域名，例如 `us-ca.edge.joyproxy.com`（动态代理填 `gate.joyproxy.com`）；
   - **切记不要输入 `http://`，也不要带冒号**；
2. **代理端口（Proxy port）**：
   - 填写对应的端口数字，例如 `10001`（动态代理填 `9001`）；
3. **绕过代理的主机（Bypass proxy for）**：
   - 默认通常有 `localhost, 127.0.0.1`，保持默认即可；
4. 点击右上角或底部的 **保存（Save）** 按钮。

---

## 第四步：测试是否生效与断开方法

- **验证是否生效**：打开手机上的 Chrome 或手机自带浏览器，访问 `https://ipinfo.io`，查看显示的公网 IP 是否已经成功切换为你购买的海外代理出口；
- **如何关闭代理**：当不用代理时，必须回到这个 Wi-Fi 设置界面，将「代理」重新改回 **无（None）** 并保存，否则离开该 Wi-Fi 或代理到期后，手机可能会出现连不上网的提示。
