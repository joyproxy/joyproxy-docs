# Android 无线网络（Wi-Fi）代理配置教程

若无需安装客户端软件，可以在连接无线网络（Wi-Fi）时，直接利用 Android 系统原生的 Wi-Fi 高级设置配置手动 HTTP 代理。

> **适用场景**：适合在固定 Wi-Fi 环境下对当前设备的全局 HTTP 流量进行代理配置。

---

## 前置条件：开启 IP 白名单免密认证（适用于静态/自定义代理）

Android 原生 Wi-Fi 代理设置界面通常仅支持输入服务器主机名与端口号，无法直接配置代理用户名与密码。

因此，使用**静态独享或自定义代理**时建议配置 IP 白名单：
- 登录 JoyProxy 控制台，在「账密与白名单」页面中，**将当前 Wi-Fi 所使用网络的公网 IP 录入白名单**；
- 录入后，设备连接静态或自定义代理时无需输入密码即可握手通过。
- *提示：如果连接动态代理网关（`gate.joyproxy.com:9001`），由于必须使用长账密鉴权，建议使用官方 Android 客户端或支持账密配置的第三方工具。*

---

## 配置步骤

1. 打开 Android 设备的 **系统设置 → WLAN / Wi-Fi**；
2. 点击当前已连接的 Wi-Fi 名称旁边的 **设置图标** 或 **高级属性**；
3. 找到 **代理（Proxy）** 栏目，将选项由「无」修改为 **手动（Manual）**；
4. 填入参数：
   - **代理主机名（Proxy hostname）**：填入 JoyProxy 接入域名（如 `us-ca.edge.joyproxy.com`）；
   - **代理端口（Proxy port）**：填入对应的端口数字（如 `10001`）；
5. 点击 **保存**。

---

## 验证与恢复

- **验证**：打开浏览器访问 `https://ipinfo.io` 检查出口 IP；
- **恢复**：回到该 Wi-Fi 属性界面，将代理重新修改为 **无（None）** 并保存即可切回直连网络。
