# Android 模拟器代理与环境配置指南

在 Android 模拟器（如雷电模拟器、MuMu 模拟器等）中配置代理，可以为自动化测试或应用调试提供与真实移动设备完全一致的网络出口环境。

---

## 配置前建议

- **网络类型选择**：进行移动应用测试时，推荐使用 **4G/5G 移动代理（Rotating Mobile Proxies）** 或 **静态住宅代理**，这两类代理符合真实移动终端网络特征；
- **免密白名单**：建议将运行模拟器的电脑公网 IP 加入 JoyProxy 控制台白名单，免去在模拟器中手动输入长账密的步骤。

---

## 雷电模拟器配置步骤

1. 打开雷电模拟器，进入 **系统应用 → 设置**；
2. 点击 **网络和互联网 → WLAN**；
3. 长按默认连接的虚拟 Wi-Fi 名称，点击 **修改网络**；
4. 展开高级选项，将代理设置为 **手动**；
5. **代理主机名**填入接入域名（如 `us-ca.edge.joyproxy.com`），**代理端口**填入端口号；
6. 点击 **保存**。

---

## 位置与网络一致性排查

当目标应用同时检测网络 IP 与设备 GPS 位置时：
1. 确认代理节点所在的城市属地（如美国洛杉矶）；
2. 打开模拟器的 **虚拟定位** 工具，将 GPS 定位设置在相同城市；
3. 保证网络出口 IP 属地与系统 GPS 经纬度保持一致。
