# AdsPower 指纹浏览器代理配置指南

AdsPower 是一款主流的防关联指纹浏览器。本文介绍如何在 AdsPower 中配置 JoyProxy 静态独享代理或动态代理。

---

## 步骤一：获取 JoyProxy 代理连接参数

登录 JoyProxy 控制台：
- **静态独享代理**：进入「已购」页面，复制目标的 **Entry Point 接入域名**（如 `us-ca.edge.joyproxy.com:10001`）与凭据；
- **动态代理**：进入「提取」页面，生成代理信息（主机为 `gate.joyproxy.com`，端口为 `9001`，复制长用户名与密码）。

---

## 步骤二：在 AdsPower 中新建环境

1. 打开 AdsPower 客户端，点击 **新建浏览器**；
2. 填写环境名称并选择对应的操作系统与内核版本；
3. 找到 **代理配置** 板块。

---

## 步骤三：填入代理参数

1. **代理类型（Proxy Type）**：选择 `HTTP` 或 `SOCKS5`；
2. **代理主机（Proxy Host）**：填入接入域名（如 `us-ca.edge.joyproxy.com`，切勿填写 Dedicated Exit IP）；
3. **代理端口（Proxy Port）**：填入端口号；
4. **代理账号 / 密码**：填入对应网络的代理账密（若使用的是静态独享线路且当前公网 IP 已加白名单，账密可留空；动态代理必须填写长用户名与密码）；
5. 点击 **检查代理（Check Proxy）** 按钮测试连接；
6. 测试成功后，页面将展示测得的出口 IP、国家与城市属地；
7. 确保高级设置中的 **时区** 与 **WebRTC** 设置为「基于 IP 匹配」；
8. 点击 **确定** 保存并启动环境。
