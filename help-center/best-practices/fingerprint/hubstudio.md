# Hubstudio 指纹浏览器代理配置指南

Hubstudio 是一款支持团队协作的指纹浏览器。本文指导如何在 Hubstudio 环境中配置 JoyProxy 静态独享代理。

---

## 配置步骤

1. 打开 Hubstudio 客户端，进入 **环境管理 → 新建环境**；
2. 输入环境名称；
3. 在 **代理设置** 模块中：
   - **代理类型**：选择自定义代理；
   - **协议**：选择 `HTTP` 或 `Socks5`；
   - **IP / 域名**：填入接入域名（如 `us-ca.edge.joyproxy.com`）；
   - **端口**：填入对应的端口号（如 `10001`）；
   - **代理账号与密码**：填入凭据（若已加 IP 白名单可留空）；
4. 点击 **测试连接** 按钮，确认握手成功；
5. 保留 WebRTC 和时区基于代理 IP 自动匹配的默认设置；
6. 点击 **完成创建** 并启动环境。
