# Hubstudio 指纹浏览器手把手配代理教程

Hubstudio 是一款广受好评的无感知指纹浏览器，特别适合需要团队协同、多人共同管理店铺和社媒矩阵的跨境团队。

本教程指导你如何将 JoyProxy 静态独享代理快速配置到 Hubstudio 中。

---

## 第一步：准备好静态独享线路信息

1. 登录 JoyProxy 控制台，进入「我的代理」页面；
2. 找到你要绑定的静态线路，获取两项核心信息：
   - **Entry Point 接入端点**：形如 `us-ca.edge.joyproxy.com:10001`；
   - **认证凭证**：确认该网络已创建代理账密（或将公司/团队的公网 IP 录入「用户与白名单」）。

---

## 第二步：在 Hubstudio 中新建环境

1. 登录 Hubstudio 桌面客户端；
2. 在左侧菜单点击 **环境管理**；
3. 点击页面顶部的 **新建环境** 按钮；
4. 填写基础属性：
   - **环境名称**：建议命名为具体的业务标识，如 `Shopify-US-01`；
   - **标签 / 分组**：选择所属的项目组。

---

## 第三步：配置代理连接

在环境设置页面中找到 **代理设置** 模块：

1. **代理类型**：点击下拉列表，选择 **自定义代理**；
2. **协议选择**：根据提取需求选择 `HTTP` 或 `Socks5`；
3. **连接地址拆分输入**：
   - **IP / 域名**：填入接入域名 `us-ca.edge.joyproxy.com`；
   - **端口**：填入端口数字 `10001`；
   - **代理账号**：填入代理用户名（免密白名单模式可不填）；
   - **代理密码**：填入在「用户与白名单」中设置的代理密码；
4. 点击右侧的 **测试连接（Test）** 按钮；
5. 看到提示「连接成功」并显示出国家与城市属地后，即表示参数完全正确。

---

## 第四步：保存并启动

1. 在底部高级设置中，确保 **WebRTC** 和 **时区** 保持默认的「基于代理 IP 自动匹配」；
2. 点击页面右下角的 **完成创建**；
3. 在环境列表中点击 **打开**，即可在弹出的独立浏览器容器中开始安全作业。
