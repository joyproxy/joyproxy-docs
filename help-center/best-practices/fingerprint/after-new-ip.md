# 更换出口 IP 后浏览器环境更新指南

使用静态独享代理时，若在控制台使用了 **更换 IP（Refresh IP / New IP）** 功能，系统会在同一地区为你重新分配一个新的专属出口 IP。

由于 JoyProxy 采用接入域名（Entry Point）与出口 IP 分离的架构，**你在指纹浏览器中配置的域名、端口和账号密码 100% 保持不变，无需重新创建浏览器环境**。

---

## 平滑更新四步流程

1. **关闭当前浏览器窗口**：在指纹浏览器中先关闭正在运行的浏览器环境；
2. **在控制台执行更换 IP**：登录 JoyProxy 控制台，在「已购」页面找到该线路，点击 **更换 IP（Refresh IP）**；
3. **在指纹浏览器中测试连接**：返回指纹浏览器，找到对应环境，直接点击 **检查代理 / 测试连接**。软件会自动握手并更新测得的最新出口 IP 与时区信息；
4. **重新启动环境**：打开浏览器环境，原有的 Cookie、书签与环境数据均完好保留，网络已更新为新分配的出口 IP。
