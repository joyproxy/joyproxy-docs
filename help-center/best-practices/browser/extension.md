# 使用官方浏览器扩展管理与切换代理

JoyProxy 官方浏览器扩展（Browser Extension）是轻量、高效的代理管理工具。使用扩展插件配置代理时，**代理规则仅作用于当前浏览器窗口，完全不会修改操作系统的底层网络设置，亦不影响电脑上运行的其他应用程序**。

---

## 步骤一：安装浏览器扩展

扩展基于标准 Chromium 架构开发，支持主流浏览器环境：
1. **安装渠道**：
   - **Chrome 浏览器**：访问 Chrome 网上应用店搜索 **JoyProxy** 并添加；
   - **Edge 浏览器**：访问 Edge 扩展商店搜索 **JoyProxy** 并添加；
   - 直达安装：<a href="https://chromewebstore.google.com/detail/joyproxy/ogilogpkhgojddkmkogloikpfkkldjng" target="_blank" rel="noopener noreferrer">Chrome Web Store 扩展页面</a>
2. **固定扩展**：安装后点击浏览器右上角的「扩展程序」小图标，将 JoyProxy 扩展固定至工具栏。

---

## 步骤二：配置静态独享代理

1. **获取代理参数**：
   - 登录 JoyProxy 控制台，在「已购」列表中复制目标的 **Entry Point 接入域名与端口**（例如 `us-ca.edge.joyproxy.com:10001`）；
   - 确认代理账密或白名单状态；
2. **填入扩展**：
   - 点击工具栏的 JoyProxy 扩展图标；
   - 在扩展界面中切换至 **Static（静态）** 标签页；
   - 填入主机名、端口号与凭据（若在扩展中登录了控制台账号，系统会自动同步已购线路列表供直接点选）；
3. **测试并应用**：
   - 点击 **测试并应用**；
   - 扩展会自动完成连通性握手测试，通过后显示绿色的出口公网 IP 与属地；
4. **正常访问**：此时在该浏览器标签页中发起的所有网络请求均通过指定代理节点转发。

---

## 步骤三：配置动态代理

1. 在扩展中切换至 **Rotating（动态）** 标签页；
2. 选择目标国家与会话模式（每次换 IP 或长效保持）；
3. 填入提取生成的长用户名与代理密码；
4. 点击应用，扩展将按设定规则自动调度节点。

---

## 步骤四：断开与恢复直连

当无需使用代理时，点击扩展弹窗右上角的 **直连模式** 按钮，浏览器将立即切回本地网络。
