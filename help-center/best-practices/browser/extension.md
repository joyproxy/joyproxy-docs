# 用官方浏览器插件一键开关和切换线路

如果你日常频繁需要切换不同地区的代理、测试新购买的静态线路、或者希望代理**仅在当前浏览器中生效、完全不影响整台电脑的系统网络**，使用 JoyProxy 官方浏览器扩展（Browser Extension）是最轻量、最高效的方式。

---

## 第一步：下载与安装扩展

JoyProxy 官方扩展基于现代 Chromium 架构开发，全面支持各类主流浏览器：
1. **在线安装**：
   - **Chrome 浏览器**：打开 Chrome 网上应用店，搜索 **JoyProxy**，点击「添加至 Chrome」；
   - **Edge 浏览器**：访问 Edge 扩展商店，搜索 **JoyProxy** 并安装；
   - 官方直达：<a href="https://chromewebstore.google.com/detail/joyproxy/ogilogpkhgojddkmkogloikpfkkldjng" target="_blank" rel="noopener noreferrer">Chrome Web Store 安装链接</a>
2. **固定到工具栏**：安装完成后，点击浏览器右上角的「拼图小图标（扩展管理）」，找到 JoyProxy，点击旁边的**图钉图标**，将其固定在浏览器顶部工具栏以便随时点击。

---

## 第二步：使用静态独享代理（只需四步）

以最常用的静态独享线路为例：

1. **获取线路信息**：
   - 打开控制台，在「代理 → 住宅代理（或商业/机房）→ 我的代理」中，找到你购买的静态线路；
   - 记下该行的 **Entry Point**（域名+端口，例如 `us-ca.edge.joyproxy.com:10001`）以及在「用户与白名单」中设置的账密；
2. **打开扩展并登录（可选）**：
   - 点击浏览器工具栏的 JoyProxy 图标；
   - 如果你在扩展中登录了 JoyProxy 官网账号，扩展会自动同步你名下所有处于有效期的线路列表；
   - 如果不登录，也可以在扩展的 **Address（地址簿）** 中直接手动粘贴 `host:port:user:pass`；
3. **选线与测试**：
   - 切换到 **Static（静态）** 标签页，在下拉列表中选中目标线路；
   - 点击 **Test and apply（测试并应用）** 按钮；
   - 扩展会自动向底层发起握手测速，测试成功后，扩展顶部会变成绿色，并展示该浏览器对外呈现的真实出口公网 IP；
4. **验证浏览**：直接在该浏览器中打开任意网页，所有流量均已安全走该固定专线。

---

## 第三步：使用动态轮换代理

如果你购买的是按流量计费的动态代理：
1. 在扩展中切换到 **Rotating（动态）** 标签页；
2. 选择目标国家（如美国 US、日本 JP 等）以及会话模式（轮换或长效会话）；
3. 填入你的代理账号与密码，点击应用；
4. 后续每次打开新网页或按会话周期，扩展都会自动为你调度该地区的最新健康 IP。

---

## 第四步：一键断开与恢复直连

工作完成后，你不需要卸载扩展或反复修改系统网络：
只需点击扩展弹窗右上角的 **Direct（直连模式 / 清除代理）** 按钮，该浏览器会瞬间恢复本地直连状态。

---

## 扩展核心优势总结

- **隔离性极高**：使用的是浏览器专用的 Proxy API，**只接管该浏览器窗口**，不碰操作系统底层设置，即使代理断开也不会导致电脑其它聊天软件掉线；
- **自带测活机制**：先测通、再应用，有效避免因为手误输错端口导致浏览器页面打不开；
- **支持第三方代理**：扩展不仅能配合 JoyProxy 线路使用，还可以在「Address」面板中粘贴任意第三方标准的代理地址进行测试与切换。
