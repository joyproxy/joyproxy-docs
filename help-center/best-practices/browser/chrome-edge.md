# Chrome 与 Edge 浏览器配置代理指南

Google Chrome 与 Microsoft Edge 均基于 Chromium 内核构建。默认情况下，两款浏览器直接调用 Windows 或 macOS 操作系统的网络代理设置。

为了在 Chrome 或 Edge 中独立使用代理网络，通常有两种主流实现方式：**使用官方浏览器扩展插件（仅对当前浏览器生效，推荐）**，或者**通过命令行启动参数配置独立代理**。

---

## 方法一：使用 JoyProxy 官方扩展（推荐，独立作用于浏览器）

如果你希望代理仅作用于当前浏览器，而不影响操作系统中的其他网络应用程序，建议安装 JoyProxy 官方浏览器扩展。

1. **安装扩展**：在 Chrome 网上应用店（Chrome Web Store）或 Edge 扩展商店中搜索并安装 **JoyProxy** 扩展；
2. **获取代理连接凭证**：
   - **静态独享线路**：登录 JoyProxy 控制台，在「我的代理」列表中复制目标的 **Entry Point 接入域名**（例如 `us-ca.edge.joyproxy.com:10001`）与代理账密；
   - **动态代理**：在控制台「提取」页面生成代理地址，复制系统生成的长用户名与密码；
3. **配置并启用**：
   - 点击浏览器工具栏的 JoyProxy 扩展图标；
   - 选择对应的网络类型（Static 或 Rotating），填入主机名、端口号与凭据（若已在扩展中登录控制台账号，可直接点选已购线路）；
   - 点击 **Test and apply（测试并应用）**；
4. **验证与切换**：测试成功后，扩展顶部会高亮显示当前的出口 IP 与地区。如需恢复本地网络，点击扩展右上角 **Direct（直连模式）** 即可。

---

## 方法二：通过命令行启动参数配置独立代理

若不希望安装扩展，也可通过给浏览器快捷方式添加启动参数，为浏览器指定独立的代理服务器。

### Windows 系统配置步骤：
1. 在桌面上找到 Chrome 或 Edge 的快捷方式，右键选择 **属性**；
2. 切换到 **快捷方式** 选项卡，找到 **目标（Target）** 输入框；
3. 在现有路径末尾**敲一个空格**，然后追加以下启动参数（以静态独享线路为例）：
   ```text
   --proxy-server="http://us-ca.edge.joyproxy.com:10001"
   ```
4. 点击 **应用** 并保存；
5. **身份鉴权**：由于命令行参数无法直接包含密码，建议在 JoyProxy 控制台「用户与白名单」中，**将当前电脑的公网 IP 录入 IP 白名单**实现免密连接。若未添加白名单，首次打开网页时浏览器会弹出一个原生的 HTTP 认证框，输入代理用户名与密码即可。

---

## 注意事项

- **系统代理与浏览器代理的区别**：在 Chrome 菜单中点击「打开计算机的代理设置」，会直接跳转至操作系统的全局网络设置。在此处修改代理会导致整台电脑的所有网络流量均通过代理转发。因此，实现单浏览器隔离请优先选择方法一。
