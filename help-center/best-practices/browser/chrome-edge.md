# 电脑用 Chrome / Edge 怎么挂代理上网

Google Chrome 和 Microsoft Edge 都基于同样的 Chromium 内核。默认情况下，这两个浏览器本身不提供单独设置代理的独立窗口，它们使用的是 Windows 或 Mac 操作系统的系统代理。

如果你想让 Chrome 或 Edge 走代理访问外网，主要有两种最常用、最稳定的方法：**直接修改系统代理（全局生效）**，或者**使用官方扩展插件（仅浏览器生效，强烈推荐）**。

---

## 方法一：使用官方扩展插件（最推荐，不影响电脑其它软件）

如果你只想让当前浏览器走代理，不想影响电脑上的微信、钉钉、邮件客户端或其它国内软件，最推荐使用 JoyProxy 官方浏览器扩展。

1. **安装扩展**：在 Chrome 网上应用店（Chrome Web Store）或 Edge 插件中心搜索并安装 **JoyProxy** 扩展；
2. **复制代理连接信息**：
   - 如果你买的是**静态独享线路**：在控制台「我的代理」中复制 **Entry Point**（例如 `us-ca.edge.joyproxy.com:10001`）以及代理账密；
   - 如果你买的是**动态流量包**：在控制台「提取」页面生成代理地址，记下长用户名和密码；
3. **填入扩展并启用**：
   - 点击浏览器右上角的 JoyProxy 扩展图标；
   - 切换到对应的模式（Static 或 Rotating），填入主机、端口和账密（若已在扩展中登录 JoyProxy 账号，可直接点选已购线路）；
   - 点击 **Test and apply（测试并应用）**；
4. **验证与关闭**：测试通过后，扩展顶部会显示绿色的出口 IP。用完之后，只需在扩展右上角点击 **Direct（直连）**，浏览器就会立即恢复本地网络。

---

## 方法二：通过浏览器快捷方式启动参数设置独立代理

如果你不想安装任何浏览器扩展，又希望 Chrome 或 Edge 拥有完全独立的代理设置，可以通过启动命令行参数来实现。

### Windows 电脑设置步骤：
1. 在桌面上找到 Chrome 或 Edge 的快捷方式，鼠标右键点击，选择 **属性**；
2. 在弹出的窗口中，找到 **目标（Target）** 输入框；
3. 在原有的路径末尾先**敲一个空格**，然后粘贴以下参数（以静态独享线路为例）：
   ```text
   --proxy-server="http://us-ca.edge.joyproxy.com:10001"
   ```
4. 点击 **确定** 保存。
5. **重要前置**：由于命令行启动参数无法直接在启动时传递密码，建议你先在 JoyProxy 控制台的「用户与白名单」中，**将你当前的公网 IP 加入白名单**实现免密连接。
6. 双击这个修改后的快捷方式启动浏览器，浏览器打开的所有网页都会自动走该代理线路。

## 常见疑问与注意事项

- **为什么我在 Chrome 菜单里点「打开代理设置」，它跳到了 Windows 系统设置？**  
  这是 Chrome 和 Edge 的原生机制。点击该按钮会直接调用操作系统的网络设置。如果你在系统里修改了代理，电脑上的所有联网软件都会受到影响。因此单独针对浏览器使用时，建议使用方法一的官方扩展。
- **动态代理能用方法二的快捷方式参数吗？**  
  动态代理也可以填 `--proxy-server="http://gate.joyproxy.com:9001"`，但由于动态代理目前必须通过用户名和密码鉴权，启动后打开第一个网页时，浏览器会弹出一个原生的提示框，要求你输入「用户名」和「密码」。将提取中心返回的长用户名复制填入用户名框，输入代理密码即可。
