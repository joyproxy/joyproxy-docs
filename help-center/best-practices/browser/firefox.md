# Firefox 火狐浏览器代理配置指南

Mozilla Firefox（火狐浏览器）内置了独立的网络代理管理模块。与 Chrome 不同，Firefox 支持在浏览器内部直接配置 HTTP、HTTPS 或 SOCKS5 代理，**无需安装第三方插件，也不会影响操作系统的全局网络配置**。

---

## 配置步骤说明

### 第一步：获取代理连接参数
登录 JoyProxy 控制台，获取你所提取的代理连接信息：
- **静态独享代理**：在「我的代理」页面获取目标的 **Entry Point（如 `us-ca.edge.joyproxy.com:10001`）** 以及代理凭据；
- **动态代理**：在「提取」页面生成代理地址，获取系统生成的长用户名以及在「用户与白名单」中设置的密码。

---

### 第二步：进入 Firefox 网络设置面板
1. 打开 Firefox 浏览器，点击右上角的 **菜单图标（三条横线）**，选择 **设置（Settings）**；
2. 在左侧导航栏保持在 **常规（General）** 选项卡，向下滚动至底部；
3. 找到 **网络设置（Network Settings）** 区域，点击右侧的 **设置...（Settings...）** 按钮。

---

### 第三步：配置手动代理参数
在弹出的「连接设置」对话框中：
1. 选择 **手动配置代理（Manual proxy configuration）**；
2. 根据你所使用的代理协议填入参数：
   - **使用 HTTP / HTTPS 协议**：
     - 在 **HTTP 代理（HTTP Proxy）** 输入框中填入主机名（如静态代理填 `us-ca.edge.joyproxy.com`，动态网关填 `gate.joyproxy.com`）；
     - 在 **端口（Port）** 输入框中填入端口号（如 `10001` 或 `9001`）；
     - 勾选 **也将此代理用于 HTTPS（Also use this proxy for HTTPS）**；
   - **使用 SOCKS5 协议**：
     - 在 **SOCKS 主机（SOCKS Host）** 中填入主机名与端口，选择 **SOCKS v5**；
     - 建议勾选底部的 **使用 SOCKS v5 代理 DNS 查询（Proxy DNS when using SOCKS v5）**，以实现域名解析防护。
3. 点击 **确定（OK）** 保存设置。

---

### 第四步：身份鉴权与验证
1. 打开新的标签页，访问 IP 检测页面（例如 `https://ipinfo.io`）；
2. 浏览器将弹出原生的代理身份验证窗口；
3. 输入你的代理凭据（动态代理请粘贴完整的长用户名），点击登录；
4. 页面成功加载并显示目标代理节点的出口 IP 与属地，即表示代理配置成功。如需恢复本地网络，将连接设置切回 **不使用代理（No proxy）** 即可。
