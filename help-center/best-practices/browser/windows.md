# Windows 电脑怎么设置全局代理网络

当你需要让 Windows 10 或 Windows 11 电脑上的大多数桌面程序（如各类海外聊天工具、应用软件或开发客户端）统一走代理上网时，可以直接在 Windows 操作系统的系统设置中配置全局代理。

> **重要提示**：在 Windows 系统设置中配置代理后，电脑上**所有未单独配置代理的联网软件都会尝试通过该代理出口访问网络**。如果你使用的代理按流量计费（动态代理），请留意后台正在自动更新的软件或云盘同步可能产生的流量消耗。

---

## 准备工作：设置 IP 白名单（强烈建议）

Windows 系统自带的代理设置面板仅支持输入「IP/域名」与「端口」，**原生不支持直接保存用户名和密码**。
因此，为了在 Windows 系统中顺畅使用代理，最推荐的方式是在连接前启用 **IP 白名单免密认证**：

1. 登录 JoyProxy 控制台，进入对应代理网络页面，点击顶部的 **用户与白名单**；
2. 找到「IP 白名单」卡片，点击 **将当前 IP 加入白名单**（系统会自动侦测并录入你当前电脑的公网 IP）；
3. 保存后，白名单会在 1 分钟内全局生效。此后这台电脑直连静态独享或自定义独享代理时均可免输账密。

## Windows 11 设置步骤

1. 点击电脑任务栏的 **开始菜单**，打开 **设置**（或按快捷键 `Win + I`）；
2. 在左侧菜单栏点击 **网络和 Internet（Network & internet）**；
3. 在右侧列表中找到并点击 **代理（Proxy）**；
4. 在「手动设置代理（Manual proxy setup）」这一行，点击右侧的 **设置（Set up）** 按钮；
5. 在弹出的窗口中：
   - 将开关切换为 **开（On）**；
   - **代理 IP 地址（Proxy IP address）**：填写你在 JoyProxy「我的代理」中看到的 **Entry Point 域名**（例如 `us-ca.edge.joyproxy.com`，注意不要带端口，也不要填 Exit IP）；
   - **端口（Port）**：填写对应的端口数字（例如 `10001`）；
   - （可选）在下方的「请勿将代理服务器用于下列开头的地址」输入框中，保留系统默认的 `localhost;127.0.0.1`，确保本地局域网不受影响；
6. 点击 **保存（Save）**，设置立即生效。

## Windows 10 设置步骤

1. 点击 **开始菜单 → 设置 → 网络和 Internet**；
2. 在左侧菜单栏点击最下方的 **代理**；
3. 往下拉找到 **手动设置代理** 区域；
4. 将 **使用代理服务器** 下方的开关打开；
5. 在 **地址** 栏填入接入域名，在 **端口** 栏填入端口号；
6. 勾选「请勿将代理服务器用于本地 (Intranet) 地址」；
7. 点击底部的 **保存** 按钮。

## 怎么验证与停用系统代理？

- **验证是否生效**：打开任意浏览器访问 `https://api.ipify.org`，若页面显示的 IP 与控制台该线路的专属出口 IP（Dedicated Exit IP）完全一致，说明系统代理已成功接管流量；
- **随时关闭代理**：回到刚才的「代理」设置窗口，把「使用代理服务器」的开关切回 **关（Off）** 并保存即可瞬间恢复本地网络。
