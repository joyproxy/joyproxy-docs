# Windows 操作系统代理配置指南

当你需要让 Windows 10 或 Windows 11 操作系统中的大部分桌面应用程序统一通过代理网络连接时，可以在操作系统的系统设置中配置全局代理。

---

## 前置条件：配置 IP 白名单（推荐）

Windows 操作系统的原生代理配置界面仅支持输入「服务器主机名」与「端口号」，**无法直接配置代理用户名与密码**。

为了在操作系统层顺畅使用代理，推荐提前开启 **IP 白名单免密鉴权**：
1. 登录 JoyProxy 控制台，进入目标网络的控制面板，点击 **用户与白名单**；
2. 在「IP 白名单」模块中，点击 **将当前 IP 加入白名单**（系统将自动识别并录入当前网络的公网 IPv4 地址）；
3. 保存后，白名单会在 1 分钟内全局生效，当前网络环境连接静态或自定义代理时均可免密通行。

---

## Windows 11 配置步骤

1. 点击 **开始菜单 → 设置**（或按快捷键 `Win + I`）；
2. 在左侧菜单选择 **网络和 Internet（Network & internet）**；
3. 点击右侧列表中的 **代理（Proxy）** 选项；
4. 在「手动设置代理（Manual proxy setup）」选项旁，点击 **设置（Set up）**；
5. 在弹出的对话框中：
   - 将开关切换为 **开（On）**；
   - **代理 IP 地址（Proxy IP address）**：填入 JoyProxy 控制台显示的 **Entry Point 接入域名**（例如 `us-ca.edge.joyproxy.com`，注意勿带端口，切勿填写 Exit IP）；
   - **端口（Port）**：填入对应的端口数字（例如 `10001`）；
   - 保留默认的本地绕过规则（`localhost;127.0.0.1`）；
6. 点击 **保存（Save）** 即可生效。

---

## Windows 10 配置步骤

1. 点击 **开始菜单 → 设置 → 网络和 Internet**；
2. 在左侧导航栏点击 **代理**；
3. 向下滚动至 **手动设置代理** 区域；
4. 打开 **使用代理服务器** 开关；
5. 在地址栏填入 Entry Point 接入域名，在端口栏填入端口号；
6. 点击 **保存**。

---

## 验证与停用方式

- **验证连接**：打开浏览器访问 `https://api.ipify.org`，核对显示的公网 IP 是否已切换为目标代理节点的出口 IP；
- **停用代理**：回到上述设置面板，将「使用代理服务器」开关切回 **关（Off）** 保存即可恢复本地网络连接。
