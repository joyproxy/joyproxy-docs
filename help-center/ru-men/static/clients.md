# Windows、Chrome 与手机

专用 `host:port` 适合填进系统或浏览器的代理表单。

## 仅浏览器

[JoyProxy 浏览器扩展](../software/browser-extension.md) — 粘贴 `http://USER:PASS@HOST:PORT`，测试后应用。其它程序仍走直连。

## Windows 上的 Chrome / Edge（系统代理）

Chrome 跟随 Windows 设置。见 [Windows 11 系统代理](../../zui-jia-shi-jian/windows-11-system-proxy.md)、[Chrome 静态代理](../../zui-jia-shi-jian/chrome-static-proxy.md)。

> **安全**
>
> 系统代理会影响所有兼容应用。测完记得关闭。

## iOS / Android Wi‑Fi

[移动设备](../../zui-jia-shi-jian/mobile-static-proxy.md) — Wi‑Fi 里填手动代理，或用 [Android 客户端](../software/android-client.md) 做按应用分流。

## 第三方工具

Host、port 来自端点生成；认证用白名单或账号密码。工具对照表：[第三方软件](../../zui-jia-shi-jian/third-party-static-proxies.md)。
