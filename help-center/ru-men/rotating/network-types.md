# 网络类型与选型指南

JoyProxy 提供多种不同网络类型的代理 IP。由于各类网络的 IP 来源、信任度与成本存在差异，在购买动态代理前，你可以根据具体的业务场景进行选型。

---

## 四种网络类型的核心区别

| 网络类型 | IP 来源与底层架构 | 信任度与防封能力 | 适合做什么（典型场景） |
| --- | --- | --- | --- |
| **住宅代理** (Residential) | 真实家庭宽带网络（如 Comcast、AT&T、Verizon 等），IP 由真实 ISP 分配给终端家庭用户。 | **极高信任度**。目标服务器将其识别为普通家庭访客，极难触发验证码（CAPTCHA）或 IP 拦截。 | 网页数据采集、电商比价与竞品分析、社媒账号运营、演唱会/限量商品抢购。 |
| **移动代理** (Mobile) | 移动运营商（如 Verizon、Vodafone 等）4G/5G 蜂窝基站分配给手机的 IP。 | **最高防封率（天然免封）**。采用 CGNAT 架构，成千上万真实手机共用同一 IP，目标网站绝不敢轻易封禁。 | 移动 App 测试与抓取、移动广告验证与反欺诈校验、高风控场景重试。 |
| **商业 / ISP 代理** (Business / ISP) | 部署在企业专线/机房，但直接向实体运营商申请了商业宽带/ISP 资质接入。 | **高信任度 + 低延迟**。既具备住宅 IP 的高信任度（不被 ASN 识别为机房），又具备专线的高速度与稳定性。 | B2B 门户与企业系统对接、高价值长效商务账号运营、大文件传输与持续同步。 |
| **数据中心代理** (Datacenter) | 由 AWS、谷歌云等数据中心机房直接提供。 | **吞吐量大、成本极低**，但隐蔽性较低（IP 容易被识别为机房 ASN）。 | 大规模无风控公开数据抓取、搜索引擎批量监测、性能与压力测试。 |

---

## 动态代理支持的网络

动态代理（按 GB 流量计费，统一连接网关 `gate.joyproxy.com:9001`）涵盖以下三种网络类型：

1. **动态住宅代理 (Rotating Residential)**
   - **特点**：全球 200+ 国家海量家庭 IP 池，按流量计费，性价比极高。
   - **适用**：绝大多数通用网页爬虫、数据抓取与日常自动化任务。

2. **动态移动代理 (Rotating Mobile)**
   - **特点**：真机 4G/5G 移动蜂窝 IP，高并发下依然保持极高通过率。
   - **适用**：针对风控极严的目标网站、移动端 App 接口或广告展示校验。

3. **动态商业 / ISP 代理 (Rotating Business / ISP)**
   - **特点**：运营商商业 ISP 线路，兼具机房级传输速率与住宅级 IP 信任度。
   - **适用**：企业级系统对接、B2B 数据采集与要求兼顾速度与隐蔽性的场景。

> **注**：数据中心代理目前主要提供[静态独享](../static/README.md)与[自定义独享](../custom/README.md)形态。

---

## 选型决策流程

1. **风控极严 / 移动端专属** ➔ 优先选择 **动态移动代理**。
2. **通用爬虫 / 电商比价 / 海量并发** ➔ 优先选择 **动态住宅代理**（性价比最高）。
3. **企业对接 / 需要兼顾高速度与高信任** ➔ 优先选择 **动态商业 / ISP 代理**。
