# 响应码与常见报错

在连接动态代理时，如果遇到异常状态码，可按以下指南快速排查：

## 1. 407 Proxy Authentication Required

代理认证失败。
- **排查方法**：
  1. 检查密码是否正确（需填入「用户与白名单」里设定的代理密码，而非官网登录密码）。
  2. 检查代理用户名是否为 [提取](extract-ip.md) 页面生成的完整长字符串，请勿自行截断。

## 2. 403 Forbidden

目标网站拒绝访问。
- **排查方法**：
  1. 如果测试 `https://api.ipify.org` 能返回出口 IP，说明代理网关正常，此报错由目标网站防爬机制（如 WAF）触发。
  2. 确认请求的目标站点是否属于[受限目标](restricted-targets.md)（如金融、政务或中国大陆境内网站）。

## 3. 502 Bad Gateway / 504 Gateway Timeout

代理网关连接超时或无响应。
- **排查方法**：
  1. 确认连接的主机为 `gate.joyproxy.com`，端口为 `9001`。
  2. 检查本地网络防火墙规则，尝试切换 HTTP / SOCKS5 协议重试。
