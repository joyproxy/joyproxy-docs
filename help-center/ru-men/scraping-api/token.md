# 获取 Token

**Scraping API Token** 只用于网页抓取 API，不是代理提取 Token、主用户 Token 或 AI Access Token。

1. 打开 [API Center](https://www.joyproxy.com/admin-web-unblocker.html?view=playground)。
2. 复制 **Scraping API Token**。
3. 放进环境变量保管。若怀疑泄露，在 API Center 轮换。

| Token              | 典型用途                                                                           |
| ------------------ | ------------------------------------------------------------------------------ |
| Scraping API Token | 托管抓取、积分与用量接口                                                                   |
| 提取 **API URL**     | 代理端点生成 — 从 [端点生成](https://www.joyproxy.com/admin-ip-extraction-center.html) 复制 |
| 主用户 Token          | 订单与余额 API                                                                      |
| AI Access Token    | OpenClaw / MCP                                                                 |

试调与请求形态：[OpenAPI 中心](../../zui-jia-shi-jian/openapi-center.md)。
