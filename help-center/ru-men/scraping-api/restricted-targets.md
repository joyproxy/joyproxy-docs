# 受限目标与合规说明（Restricted Targets）

为了维护健康的云端网络环境与合规合意的使用规范，JoyProxy 网页抓取 API 对部分目标与域名实行严格的拦截策略。

---

## 中国大陆网络与域名限制

1. **不提供中国大陆境内代理节点与抓取出口**。
2. **禁止抓取中国大陆境内部署的网站与域名**（包括 `.cn` 结尾的域名或服务器在大陆境内的站点）。
3. **中国大陆本地网络环境中无法直接调用网页抓取 API 接口**。

---

## 高风险禁止抓取目标分类

网页抓取 API 会自动识别并拒绝处理对以下高风险领域的抓取请求：

- **金融与支付网关**：网上银行登录页、信用卡支付接口、证券交易平台。
- **政府与公共机构**：政府政务大厅、公共安全与身份认证网关。
- **私人隐私与通讯系统**：个人网页邮箱、社交平台私信接口、SPAM 批量发帖。

详细规约请参阅 **[JoyProxy 服务条款](https://www.joyproxy.com/terms.html)**。
