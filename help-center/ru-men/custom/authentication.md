# 设置代理账密与白名单（Authentication）

自定义端口支持 Username/Password 认证或 IP 白名单免密认证：

1. 打开 **[用户与白名单（Users & Whitelist）](https://www.joyproxy.com/admin-authorization.html)** 页面。
2. **Username/Password 模式**：设置代理 Username 与 Password，在连接端口 `us-ca.edge.joyproxy.com:20001` 时填入。
3. **IP Whitelist 模式**：在 IP 白名单中添加你服务器的公网 IPv4，添加后即可免密直连。
