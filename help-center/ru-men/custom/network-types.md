# 网络类型与选型指南（Network Types）

自定义独享代理按端口包时计费，提供三类不同的网络：

| 网络类型 | 属性与特点 | 典型适用场景 |
| --- | --- | --- |
| **自定义住宅代理（Custom Residential Proxies）** | 住宅 IP 信任度，支持按端口切国家与定时换 IP | 多国家复杂数据抓取、跨国社媒多账号运营 |
| **自定义商业 / ISP 代理（Custom Business / ISP Proxies）** | 运营商商业专线，兼具高速率与高信任度 | 跨境企业系统对接、多地区 B2B 自动化 |
| **自定义数据中心代理（Custom Datacenter Proxies）** | 机房高速线路，支持按端口灵活配置 | 多地区高并发自动化测试、接口中转 |
