# 提取代理 IP（Extract IP）

1. 打开 **[提取（Endpoint Generator）](https://www.joyproxy.com/admin-ip-extraction-center.html)** 页面。
2. 切换到 **自定义代理（Custom Proxies）** 页签。
3. 筛选所需的端口订单，选择协议（HTTP / SOCKS5）与展示格式。
4. 点击 **复制地址列表（Copy Host List）** 或导出文本。

> 💡 **OpenAPI 中心引流**  
> 如需在自动化程序中通过 API 程序化查询与配置自定义端口，请参阅 **[OpenAPI 中心](../../best-practices/openapi-center.md)**。
