# 查看与管理端口（View Ports）

在 **[我的代理（My Proxies）](https://www.joyproxy.com/admin-my-orders.html)** 页面中，你可以统一管理所有已购的自定义端口。

## 页面展现

- **端口 ID 与 Host:Port 地址**
- **当前分配的国家/地区**
- **定时轮换状态与频率**
- **到期时间与自动续费开关**

在这个页面，你可以随时点击 **[分配地区](assign-region.md)** 更改国家，或点击 **[设置轮换与更换 IP](rotation-and-refresh.md)** 管理 IP 轮换逻辑。
