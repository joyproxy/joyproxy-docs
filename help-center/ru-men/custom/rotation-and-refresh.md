# 设置定时轮换与手动更换 IP（Rotation & Refresh）

自定义端口支持灵活的 IP 变更策略：

## 1. 设置定时自动轮换（Set Rotation）

1. 在 **[我的代理（My Proxies）](https://www.joyproxy.com/admin-my-orders.html)** 页面找到对应端口。
2. 点击 **设置轮换（Set Rotation）** 按钮。
3. 选择轮换频率（如每 5 分钟、10 分钟、30 分钟、1 小时自动更换一次 IP）。
4. 保存后，该端口会自动按设定的时间间隔定时替换出口 IP。

## 2. 手动更换 IP（New IP / Refresh IP）

如果你需要立即更换出口 IP，无需等待定时器：
1. 点击端口旁边的 **更换 IP（New IP / Refresh IP）** 按钮。
2. 系统会立即为该端口分配一个新的出口 IP。
