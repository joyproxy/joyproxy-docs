## 浏览在线 FAQ

常见主题包括：

- **账户** — 注册、登录、赠金、安全
- **账单** — PayPal、余额、退款、发票

- **网页抓取 API** — 积分、Token、抓取参数
- **故障排查** — 认证错误、地域不符、连通性
