# Frequently asked questions

JoyProxy maintains an expanded FAQ on the main website with searchable categories. Use it for quick answers; use this documentation for step-by-step guides.

## Browse the live FAQ

**<a href="https://www.joyproxy.com/faq.html" target="_blank" rel="noopener noreferrer">joyproxy.com/faq.html</a>**

Topics typically include:

- **Account** — registration, login, credits, security
- **Billing** — PayPal, balance, refunds, invoices
- **Proxy products** — rotating vs static vs custom, traffic, endpoints
- **Web Scraping API** — credits, tokens, fetch parameters
- **Troubleshooting** — auth errors, geo mismatches, connectivity

The FAQ updates with the product—when in doubt, prefer the live page over older screenshots.
