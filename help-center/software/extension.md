# Browser Extension

Official Chromium extension — paste, test, and apply a proxy to this browser only. A JoyProxy account is optional.

## Install

- Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/joyproxy/ogilogpkhgojddkmkogloikpfkkldjng) (works on Edge, Brave, and other Chromium browsers)
- See the [Browser Extension product page](https://www.joyproxy.com/products/browser-extension.html) for screenshots and features
- Pin JoyProxy on the toolbar for quick access

## Quick workflow

- Open the popup or workbench side panel
- Paste a proxy or sign in on joyproxy.com to sync purchased lines
- Run a connectivity test and confirm exit IP / region
- Click **Apply** — only this browser uses the proxy; system settings stay unchanged

## Advanced (optional)

- Proxy scope: all sites or allow-list only
- User-Agent, WebRTC limit, cookie cleanup, fingerprint-related settings
- Saved profiles and list import
