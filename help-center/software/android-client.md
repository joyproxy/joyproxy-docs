# Proxy Client (Android)

Route mobile app traffic through HTTP/SOCKS5 without root.

- See the [Proxy Client product page](https://www.joyproxy.com/products/android-client.html)
- Download the signed APK from [GitHub Releases](https://github.com/joyproxy/joyproxy-client-android/releases/latest)
- Enter proxy host, port, and credentials (from JoyProxy endpoint generation or your own server)
- Choose **Global**, **Whitelist**, or **Blacklist** per-app routing
- Built on sing-box libbox; works with JoyProxy IP or any compatible proxy server

More client platforms are planned; Android is available now.
