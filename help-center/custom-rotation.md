# Set Custom Proxies Rotation Interval

Rotation refreshes the exit IP on a timer while keeping the same target region rules.

- In [My Proxies → Custom Proxies](https://www.joyproxy.com/admin-my-orders.html), select port(s)
- Click **Rotation**
- Choose a preset (Off, 1 min, 5 min, 15 min, 1 hour) or enter seconds (60-step increments)
- **Off** = fixed IP until you change it manually
- Click **Apply** — changes take effect on the next rotation cycle

**⚠️ Note**Rotation applies per allocation. Assign region first so rotated IPs stay within your chosen geo.
