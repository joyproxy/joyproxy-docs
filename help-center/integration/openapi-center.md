# OpenAPI Center

The [OpenAPI Center](https://www.joyproxy.com/admin-openapi.html) documents JoyProxy HTTP APIs for orders, extraction, and related operations.

- Import the spec into Postman, Insomnia, or your own client generator.
- Use the correct token type (API token vs Master User Token) per endpoint.
