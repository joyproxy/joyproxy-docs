# Proxy Tester

Desktop tool to check HTTP / SOCKS5 TCP / SOCKS5 UDP connectivity, outbound IP, geo, and batch-extracted endpoints.

- See the [Proxy Tester product page](https://www.joyproxy.com/products/tester.html)
- Download the Windows EXE from [GitHub Releases](https://github.com/joyproxy/joyproxy-tester/releases/latest)
- Paste a proxy address (optional username/password) and run a connectivity test
- Review outbound IP / country, or configure an extract API + regex for sequential batch testing

Open source (MIT). Source run requires Python 3.10+.
