# 电脑上的安卓模拟器怎么连代理

对于从事移动应用测试、海外短视频矩阵管理以及移动端数据采集的用户来说，雷电模拟器、MuMu 模拟器、夜神模拟器等电脑安卓模拟器是高频生产工具。

在模拟器中设置代理，可以把模拟器伪装成一台完全位于海外目标地区的真实手机终端。

---

## 最佳搭配方案建议

- **模拟海外真机环境**：强烈推荐使用 **4G/5G 移动代理（Rotating Mobile Proxies）** 或 **静态住宅代理**。这两类代理在目标 App 的风控引擎中属于真实个人蜂窝宽带，信誉极高；
- **认证方式选择**：建议先在 JoyProxy 控制台的「用户与白名单」中，**将你电脑当前的公网 IP 加入白名单**。因为在模拟器内输入极长的长用户名容易发生复制截断或字符编码错误，加白名单后即可免密直连。

---

## 雷电模拟器（LDPlayer）设置教程

1. 启动雷电模拟器，进入模拟器主界面，打开 **系统应用 → 设置（Settings）**；
2. 点击 **网络和互联网 → WLAN（Wi-Fi）**；
3. 会看到模拟器默认连接了一个虚拟 Wi-Fi（通常名为 `VirtWifi` 或类似名字）；
4. **长按** 该 Wi-Fi 名称，在弹出的菜单中点击 **修改网络（Modify network）**；
5. 勾选 **高级选项**，在「代理」下拉列表中选择 **手动**；
6. 填入代理参数：
   - **代理主机名**：填写 JoyProxy 提供的接入域名（例如静态代理填 `us-ca.edge.joyproxy.com`，动态代理填 `gate.joyproxy.com`）；
   - **代理端口**：填入对应的端口号；
7. 点击 **保存**。
8. 打开模拟器内置的浏览器，访问 `https://ipinfo.io` 确认出口地理属地。

## MuMu 模拟器设置教程

1. 启动 MuMu 模拟器，在桌面点击进入 **设置 → Wi-Fi**；
2. 鼠标长按已连接的默认 Wi-Fi，选择 **修改网络**；
3. 展开高级选项，将「代理」设置为 **手动**；
4. 填写代理服务器域名与端口，保存即可。

## 配合虚拟定位（GPS）同步防风控技巧

在模拟器里跑海外 App 时，光改 IP 往往不够，目标 App 还会读取系统的 GPS 经纬度：
1. 在 JoyProxy 控制台确认你分配的代理出口位于哪个城市（例如美国洛杉矶 Los Angeles）；
2. 打开模拟器右侧工具栏的 **虚拟定位 / 定位模拟** 功能；
3. 在地图搜索框输入相同城市（如 Los Angeles），将定位钉在该城市；
4. **效果**：此时模拟器的「网络 IP 属地」与「系统底层 GPS 定位」完全吻合，避免因 IP 在美国而 GPS 还在国内导致的账号异常风控。
