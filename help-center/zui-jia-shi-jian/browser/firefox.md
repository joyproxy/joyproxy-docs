# Firefox 火狐浏览器怎么单独设置代理

与 Chrome 和 Edge 不同，Mozilla Firefox（火狐浏览器）拥有完全独立的内部网络代理管理模块。这意味着你**无需借助任何插件，也无需改动整台电脑的系统设置**，就能在火狐浏览器内部为它单独配置 HTTP、HTTPS 或 SOCKS5 代理。

---

## 手把手配置步骤

### 第一步：获取代理连接信息
在开始配置前，请先准备好你在 JoyProxy 控制台提取到的代理信息：
- **静态独享代理**：进入对应网络的「我的代理」页面，找到线路并记下 **Entry Point（例如 `us-ca.edge.joyproxy.com:10001`）** 以及代理密码；
- **动态代理**：进入「提取」页面生成代理地址，记下长用户名，以及你在「用户与白名单」中创建的密码。

---

### 第二步：打开火狐代理设置面板
1. 打开 Firefox 火狐浏览器，点击右上角的 **三条横线菜单图标（设置菜单）**，选择 **设置（Settings）**；
2. 在左侧菜单中保持在 **常规（General）** 页面，一直往下拉滚动条到底部；
3. 找到 **网络设置（Network Settings）** 区域，点击右侧的 **设置...（Settings...）** 按钮。

---

### 第三步：填入手动代理参数
在弹出的「连接设置」窗口中：
1. 默认选项通常是「使用系统代理设置」，将其修改为勾选 **手动配置代理（Manual proxy configuration）**；
2. 根据你提取的协议类型选择填写：
   - **如果使用 HTTP / HTTPS 代理**：
     - 在 **HTTP 代理（HTTP Proxy）** 输入框中填写代理主机名（例如静态代理填 `us-ca.edge.joyproxy.com`，动态代理填 `gate.joyproxy.com`）；
     - 在右侧的 **端口（Port）** 输入框中填写对应的端口数字（例如 `10001` 或 `9001`）；
     - 勾选下方的 **也将此代理用于 HTTPS（Also use this proxy for HTTPS）**；
   - **如果使用 SOCKS5 代理**：
     - 保持上方的 HTTP 代理为空，直接在下方的 **SOCKS 主机（SOCKS Host）** 填入主机与端口，并勾选单选框 **SOCKS v5**；
     - 建议同时勾选底部的 **使用 SOCKS v5 代理 DNS 查询（Proxy DNS when using SOCKS v5）**，这样可以有效防止 DNS 污染与解析泄漏。
3. 点击窗口右下角的 **确定（OK）** 保存。

---

### 第四步：输入代理账密并验证
1. 打开火狐浏览器，新建一个标签页，输入查询出口 IP 的网址（如 `https://ipinfo.io`）；
2. 此时浏览器会自动弹出一个认证登录框，提示 **代理服务器需要用户名和密码**；
3. 在弹窗中输入凭证：
   - 用户名：填写你的代理用户名（动态代理必须完整粘贴提取器生成的长用户名）；
   - 密码：填写在「用户与白名单」中设置的代理密码；
   - （可选）勾选「记住密码」以便下次打开自动连接；
4. 点击登录后页面顺利加载，并显示出你所购买代理的地理位置和出口 IP，即表示火狐浏览器已成功单独挂载代理。

---

## 如何随时恢复火狐的本地直连？
当工作完成需要恢复本地网络时：
重新回到火狐的「网络设置」窗口，将选项改回 **不使用代理（No proxy）** 或 **使用系统代理设置**，点击确定即可立即切换回本地网络。
