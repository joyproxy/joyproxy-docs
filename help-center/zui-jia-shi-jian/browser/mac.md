# Mac 苹果电脑怎么在系统里设置代理

macOS 操作系统提供了非常完善的网络代理设置功能。在 Mac 系统中配置代理后，Safari、各类桌面应用以及系统级网络连接均可自动通过指定的代理线路访问外部网络。

---

## 准备工作：设置 IP 白名单

与 Windows 类似，为了避免每次打开应用时被弹窗索要用户名密码，最推荐的方式是先在 JoyProxy 控制台开通免密访问：

1. 登录 JoyProxy 控制台，进入你购买的网络控制台，点击 **用户与白名单**；
2. 找到「IP 白名单」，点击 **将当前 IP 加入白名单**，将你当前 Mac 所在网络的公网 IP 保存；
3. 如果你的网络无法使用固定公网 IP，也可以记下你在后台创建的代理用户名与密码，在 macOS 代理面板中手动勾选并保存密码。

---

## macOS Sonoma / Ventura（最新系统界面）设置步骤

1. 点击屏幕左上角的 **苹果图标（）**，打开 **系统设置（System Settings）**；
2. 在左侧菜单点击 **网络（Network）**；
3. 在右侧点击你当前正在使用的联网方式（如果你连的是无线网，点击 **Wi-Fi**；如果你插了网线，点击 **以太网**）；
4. 点击当前已连接网络名称旁边的 **详细信息...（Details...）** 按钮；
5. 在弹出的网络属性窗口左侧，切换到 **代理（Proxies）** 标签页；
6. 根据你提取的协议勾选对应的代理协议开关：
   - 常用模式：勾选 **网页代理（HTTP）** 以及 **安全网页代理（HTTPS）**；
   - 或者：勾选 **SOCKS 代理**；
7. 在右侧输入框中填入：
   - **服务器（Server）**：填写在 JoyProxy 控制台提取的域名（例如 `us-ca.edge.joyproxy.com`，切勿填错为 Exit IP）；
   - **端口（Port）**：填写对应的端口号；
   - **账密鉴权（若未加入白名单）**：勾选下方的「代理服务器需要密码」，并填入代理用户名与密码；
8. 点击右下角的 **好（OK）**，并在外层界面点击 **应用（Apply）** 保存生效。

---

## macOS Monterey 及更早系统设置步骤

1. 打开 **系统偏好设置 → 网络**；
2. 选中左侧的活动网络连接（Wi-Fi 或以太网），点击右下角的 **高级...（Advanced...）** 按钮；
3. 切换到顶部的 **代理（Proxies）** 标签；
4. 勾选「Web 代理 (HTTP)」与「安全 Web 代理 (HTTPS)」；
5. 填入服务器域名与端口，保存并点击主界面的「应用」。

---

## 怎么验证与恢复？

- **检查生效状态**：打开终端（Terminal）输入 `curl https://ipinfo.io`，或直接在 Safari 打开该网址，核对出口城市与 IP 是否符合预期；
- **恢复本地连接**：回到「代理」设置窗口，将勾选的「网页代理 (HTTP)」和「安全 Web 代理 (HTTPS)」复选框取消勾选，点击确定并应用即可恢复直连。
