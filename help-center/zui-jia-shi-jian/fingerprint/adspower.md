# AdsPower 指纹浏览器手把手配代理教程

AdsPower 是跨境出海领域最流行的多账号管理指纹浏览器之一。通过它与 JoyProxy 静态独享代理或动态代理配合，可以完美实现跨境店铺与多账号的彻底隔离防封。

本文带你用最直观的图文步骤完成在 AdsPower 中的代理配置。

---

## 第一步：在 JoyProxy 控制台获取代理信息

登录 JoyProxy 控制台：
1. **静态独享代理（推荐）**：
   - 进入「住宅代理（或商业/机房）→ 我的代理」；
   - 找到已购买的静态线路，查看 **Entry Point**（例如 `us-ca.edge.joyproxy.com:10001`）；
   - 记下域名、端口，以及在「用户与白名单」中设置的代理用户名与密码；
2. **动态代理**：
   - 在「提取」页面生成代理地址，主机为 `gate.joyproxy.com`，端口为 `9001`，复制完整的长用户名与代理密码。

---

## 第二步：在 AdsPower 中新建浏览器环境

1. 打开 AdsPower 客户端，点击左上角的 **新建浏览器（New Profile）** 按钮；
2. 在「基本配置」区域：
   - **名称**：为该环境起一个好记的名字（例如 `美国店铺-01`）；
   - **分组**：选择对应的项目分组；
   - **操作系统**：建议选择与目标环境一致的系统（如 Windows 或 macOS）；
   - **浏览器内核**：默认选择推荐的最新 SunBrowser 内核。

---

## 第三步：填写代理网络配置（关键步骤）

在右侧或下方的 **代理配置（Proxy Configuration）** 板块：

1. **代理类型（Proxy Type）**：在下拉菜单中选择 `HTTP` 或 `SOCKS5`；
2. **代理主机（Proxy Host）**：
   - 填写 JoyProxy 的域名，例如 `us-ca.edge.joyproxy.com`（切勿填写 Dedicated Exit IP）；
3. **代理端口（Proxy Port）**：
   - 填写对应的端口数字，例如 `10001`；
4. **代理账号（Proxy Username）**：
   - 如果已在控制台将本机 IP 加入白名单，此栏可留空；
   - 如果使用账密认证，填入代理账号（动态代理必须填入完整的长用户名）；
5. **代理密码（Proxy Password）**：
   - 填写在「用户与白名单」中设置的代理密码。

---

## 第四步：测试代理连接与高级指纹设置

1. 填写完毕后，点击下方的 **检查代理（Check Proxy）** 按钮；
2. 稍等 1~2 秒，AdsPower 会自动发起网络测试。检测通过后，界面会显示绿色的连接成功提示，并清晰展示出该代理当前的**公网 IP、国家、省份、城市及本地时区**；
3. **高级指纹设置（推荐默认开启）**：
   - **时区（Timezone）**：勾选「基于 IP 自动匹配」；
   - **WebRTC**：选择「替换（Replace）」并勾选基于 IP 自动设置；
   - **地理位置（Location）**：选择「基于 IP 匹配」。
4. 点击窗口右下角的 **确定（OK）** 完成保存。

---

## 第五步：启动环境并开展业务

在 AdsPower 环境列表中，找到刚刚建好的环境，点击右侧的 **打开（Open）** 按钮。
此时 AdsPower 会启动一个全新的独立浏览器窗口，首页会自动检测并显示你绑定的海外静态代理出口。现在你可以放心地在该窗口中登录店铺或社交媒体账号开展业务了。
