# 比特浏览器手把手配代理教程

比特浏览器（BitBrowser）是一款以性价比和高效批量管理著称的防关联指纹浏览器，支持批量导入环境与多开同步。

本文手把手演示如何在比特浏览器中完成单个环境配置与批量导入 JoyProxy 代理。

---

## 单个环境配置方法

1. 打开比特浏览器，点击左上角的 **新建窗口**；
2. 在「基本设置」中输入窗口名称和备注；
3. 找到 **代理设置** 区域：
   - **代理方式**：选择 `自定义`；
   - **代理类型**：选择 `HTTP` 或 `SOCKS5`；
   - **代理主机**：填入 JoyProxy 的 Entry Point 域名（如 `us-ca.edge.joyproxy.com`）；
   - **代理端口**：填入端口号；
   - **代理账号与密码**：填入对应网络的代理凭证；
4. 点击右侧的 **检测代理** 按钮；
5. 检测通过后会绿字展示代理出口的 IP、国家与邮编等信息；
6. 点击确定保存并打开窗口即可。

---

## 批量导入代理环境（适合多店铺矩阵）

如果你购买了 10 条、50 条甚至更多静态独享线路，使用比特浏览器的批量导入功能可以大幅节约时间：

1. 在比特浏览器「窗口管理」页面，点击顶部的 **批量导入**；
2. 点击下载官方提供的 **Excel 模板**；
3. 打开模板表格，按列填入数据：
   - 窗口名称（如 `店铺01`、`店铺02`）；
   - 代理类型：填 `HTTP` 或 `SOCKS5`；
   - 代理IP/域名：填入每条线路的 Entry Point 主机名；
   - 代理端口：填入对应端口；
   - 代理账号与密码：填入你的凭据；
4. 保存表格后上传至比特浏览器，点击一键导入并批量检测连通性；
5. 系统会自动为每条代理生成一个独立的指纹浏览器环境，省时高效。
