# 无操作退出时间

配置一段时间无任何操作后自动 **退出登录**，降低共享电脑或长期挂页风险。

---

## 设置位置

1. <a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">我的账户</a> → **安全与 API** 页签。
2. **无操作退出时间** 卡片。
3. 说明：**超过该时长没有任何操作（浏览页面、调用后台接口等）将自动退出登录；有活动时会续期。**
4. 下拉选项：

| 选项 |
| --- |
| **1 小时** |
| **3 小时** |
| **6 小时** |
| **12 小时** |
| **24 小时（默认）** |
| **1 天** / **3 天** / **5 天** / **7 天** |

5. 保存成功：**已保存，会话已更新。** 失败：**保存失败，请重试。**

---

## 说明

- 「无操作」指未浏览控制台、未触发已登录后台请求；有活动会续期。
- 自动退出后需重新登录（含 Google / GitHub）。
- 建议与 <a href="change-password.md" target="_blank" rel="noopener noreferrer">修改密码</a> 配合用于高敏感环境。
