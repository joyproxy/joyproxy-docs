# 无操作退出时间（会话超时）

在共享网络、多人员办公场所或借用他人设备时，如果离开电脑而没有退出控制台，账户内的可用余额和代理配置可能面临被他人误操作或冒用的风险。

为此，JoyProxy 控制台提供了可灵活配置的 **无操作退出时间（Session TTL）** 机制。

<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">前往安全设置页面</a>

---

## 配置步骤

1. 在控制台左侧菜单点击 **我的账户**。
2. 切换到顶部的 **安全与 API** 页签。
3. 找到 **无操作退出时间** 设置卡片。
4. 在下拉框中选择适合你工作习惯的空闲超时时长：
   - **1 小时** / **3 小时** / **6 小时** / **12 小时**：推荐高安全性要求或公共设备选用；
   - **24 小时（系统默认值）**：适合个人独享工作电脑，兼顾安全性与使用便利；
   - **1 天** / **3 天** / **5 天** / **7 天**：适合长期挂机监控或自动化管理大屏。
5. 选择后系统会自动保存，并在界面提示 **已保存，会话已更新。**

---

## 计时与重置机制

- **计时刷新逻辑**：系统以「无任何操作」作为判定条件。只要你在控制台中进行了页面点击、路由跳转、刷新数据或触发了后台异步接口，超时计时器就会自动从头重新计时。
- **超时登出效果**：当空闲时间完全超过设定阈值后，现有会话将安全失效。若后续再次点击页面，系统会平滑跳转到登录界面，重新输入密码或完成第三方授权后即可继续使用，不会丢失已生效的代理配置。
