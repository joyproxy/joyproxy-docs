# 注销账户

当您不再需要服务时，可申请永久关闭 JoyProxy 账户。

## 注销前

* 从[交易](invoices.md)与 [My Proxies](https://www.joyproxy.com/admin-my-orders.html) 导出所需记录。
* 按[服务条款](https://www.joyproxy.com/terms.html)取消或等待生效订单到期。
* 轮换并从 CI 中移除 API Token（[轮换 Token](rotate-token.md)）。

## 自助（若提供）

1. 打开[账户设置](https://www.joyproxy.com/admin-settings.html)。
2. 找到 **Delete account** 或 **Close account**。
3. 确认身份并知悉数据删除政策。
4. 完成 UI 中关于余额或未结订单的提示。

## 协助注销

若控制台无删除选项，请用注册邮箱通过[工单](../fu-wu-yu-zhi-chi/tickets.md)或[在线客服](../fu-wu-yu-zhi-chi/live-chat.md)联系[支持](https://www.joyproxy.com/admin-support.html)。

JoyProxy 按[隐私政策](https://www.joyproxy.com/privacy.html)处理注销。若可能，请在删除前解决账单争议。
