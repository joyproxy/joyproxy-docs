# 界面语言

控制台菜单与提示的语言可在 **我的账户** → **资料** 中切换，不影响代理用户名或 API 字段名。

---

## 步骤

1. 打开 <a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">我的账户</a> → **资料**。
2. 在 **语言** 区域选择语言（如简体中文、English 等）。
3. 说明文字为 **选择管理后台界面语言。**

侧栏底部的 **语言** 与此处设置一致。

---

## 说明

界面文案会随语言变化；**提取** 页生成的代理用户名须原样使用。需要人工协助见 <a href="../fu-wu-yu-zhi-chi/live-chat.md" target="_blank" rel="noopener noreferrer">实时聊天</a>。
