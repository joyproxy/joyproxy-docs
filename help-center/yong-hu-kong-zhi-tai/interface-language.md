# 界面语言

控制台界面语言在 **我的账户** → **资料** 中切换，不影响代理用户名、API 返回字段或本帮助中心文档语言。

---

## 更改语言

1. 打开 [我的账户](https://www.joyproxy.com/admin-settings.html)。
2. 在 **资料** Tab 找到 **语言**（`settingsPage.languageTitle`）。
3. 说明文字：**选择管理后台界面语言。**（`settingsPage.languageDesc`）
4. 在下拉框选择语言（如 **English**、**简体中文**、**繁體中文** 等，以列表为准）。
5. 保存后菜单、按钮与系统提示会随所选语言刷新。

---

## 会变化与不变化的内容

| 会变化 | 不变化 |
| --- | --- |
| 侧栏、页签、按钮、Toast 文案 | Endpoints 生成的代理用户名（须原样使用） |
| 部分邮件通知语言（若账户配置跟随） | 公网 API 请求/响应字段名 |

需要人工协助时可使用 [实时聊天](../support/live-chat.md)。
