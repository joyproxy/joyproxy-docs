# 账户注册

JoyProxy 提供灵活的账号注册与登录方式。新用户注册即可自动获得 **$5 体验余额**，无需绑定任何信用卡，可直接用于购买代理流量包或测试网页抓取服务。

<a href="https://www.joyproxy.com/register.html" target="_blank" rel="noopener noreferrer">前往官网注册页面</a>

---

## 推荐方式：第三方快捷授权（OAuth）

如果你已有 Google 或 GitHub 账号，推荐直接使用第三方授权登录。在注册页面上方点击对应图标：

- **使用 Google 继续**
- **使用 GitHub 继续**

授权完成后系统会自动创建并绑定你的 JoyProxy 账号，免去繁琐的密码记忆与后续邮箱验证环节，后续登录也只需一键授权。

---

## 邮箱密码注册

如果你更倾向于使用独立企业邮箱或个人邮箱注册：

1. 在注册页面的 **或使用电子邮件注册** 区域输入常用邮箱。
2. 设置登录密码（长度至少 8 位，建议包含大小写字母与数字组合）。
3. 根据页面提示完成 Cloudflare Turnstile 基础人机安全验证。
4. 点击 **创建账号** 提交。

提交后，系统会向该邮箱发送一封包含激活链接的验证邮件。点击邮件中的链接激活账号后，即可直接登录。详细激活说明可参考 <a href="email-activation.md" target="_blank" rel="noopener noreferrer">邮箱激活</a>。

---

## 注册后的第一步

1. **登录控制台**：在 <a href="login.md" target="_blank" rel="noopener noreferrer">登录页面</a> 登录后，默认会直接进入 <a href="overview.md" target="_blank" rel="noopener noreferrer">控制台总览</a>，在顶部看板可以查看到你的可用余额。
2. **挑选适合的代理网络**：在左侧导航栏的 **代理** 分组中，根据业务场景选择对应的产品（如适合电商采集的住宅代理、适合社媒运营的移动代理，或是适合高并发抓取的数据中心代理）。
3. **获取 API 密钥**：如果需要通过程序自动化管理订单或集成抓取服务，可以在 **我的账户** → **安全与 API** 页面查看你的专属密钥，详见 <a href="rotate-token.md" target="_blank" rel="noopener noreferrer">主用户与自动化 Token</a>。

如需了解各网络类型的详细资费标准，可随时查阅 <a href="https://www.joyproxy.com/pricing.html" target="_blank" rel="noopener noreferrer">JoyProxy 定价中心</a>。
