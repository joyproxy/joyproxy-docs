# 我的账户总览

页头说明：**管理资料、安全设置与账单。**

---

## 三个页签

| 页签 | 内容 |
| --- | --- |
| **资料** | 邮箱、修改密码、USDT 认领、界面语言 |
| **安全与 API** | 无操作退出、主用户 Token、注销账户 |
| **账单** | 余额与订单（与 <a href="invoices.md" target="_blank" rel="noopener noreferrer">账单与交易记录</a> 相同） |

## 资料

- **邮箱** 只读；**邮箱无法修改，如需变更请联系支持。**
- <a href="change-password.md" target="_blank" rel="noopener noreferrer">修改密码</a>
- **USDT（TRC20）**：若已转账但关闭了支付窗口，可 **认领 USDT**；需先在充值流程中生成收款地址，再 **复制地址** 转账。
