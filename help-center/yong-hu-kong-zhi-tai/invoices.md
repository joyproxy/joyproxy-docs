# 账单与交易记录

查看充值、消费、订单，并下载 PDF 账单。

---

## 从哪里打开

- **我的账户** → **账单**
- **概览** 点击 **账户余额**
- 独立 <a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">账单页</a>

---

## 三个子页签

| 页签 | 说明 |
| --- | --- |
| **余额变动** | 充值与账本流水，可下载 PDF |
| **订单** | 全部产品的购买与续费记录 |
| **流量使用** | 动态代理按小时用量 |

可用 **时间范围** 筛选，支持单条 **PDF** 与 **批量下载账单 (ZIP)**。余额区域说明：**充值及其他账本记录 — 可下载 PDF 账单用于 PayPal / 存档**。

---

## 常见记录类型

- **充值**（PayPal、银行卡、微信支付、账户余额等）
- **购买**、**续费**、**退款**
- **管理员赠送**、**管理员扣款**

动态代理从预付流量扣减；独享按订单周期；网页抓取按成功请求扣积分（失败不扣费）。

---

## 和代理控制台的区别

生效中的订单、剩余流量、端口到期请到各网络 **已购** / **用量** 查看；本页侧重资金流水与全站订单。

USDT 链上未到账时，到 **我的账户** → **资料** → **认领 USDT**。

扣费有疑问：<a href="../fu-wu-yu-zhi-chi/tickets.md" target="_blank" rel="noopener noreferrer">提交工单</a>，附上订单号与日期。
