# 发票

在控制台跟踪充值、套餐购买与消费。

## 交易

[交易](https://www.joyproxy.com/admin-transactions.html)列出：

* PayPal 或余额**充值**
* 代理套餐**付款**
* 网页抓取 API **积分购买**

做账时请使用 UI 提供的筛选或导出选项。

## 代理订单

[My Proxies](https://www.joyproxy.com/admin-my-orders.html)显示：

* **生效中**的轮换流量、静态分配、定制端口
* **已过期**历史，便于续费决策

| 产品类型     | 计费模式            |
| -------- | --------------- |
| 轮换       | 有效期内从已购 GB 扣减流量 |
| 静态 / 定制  | 按 IP 或端口购买的有效期  |
| 网页抓取 API | 每次成功抓取扣减积分      |
