# 控制台总览

登录后默认进入 **概览** 页：<a href="https://www.joyproxy.com/admin-overview.html" target="_blank" rel="noopener noreferrer">打开概览</a>

---

## 余额与充值

- 页头显示 **JoyProxy 控制台**、**欢迎**，以及四大产品线的简要说明。
- **账户余额** 旁提示 **点击余额查看账本 · 充值享阶梯赠送**。
- 点 **账户充值** 进入支付流程；充值赠送：**满 $100 +10%，满 $1,000 +20%，满 $10,000 +30%**（付款成功后计入余额）。

点击余额可进入 **我的账户** → **账单**，或 <a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">账单页</a>。详见 <a href="invoices.md" target="_blank" rel="noopener noreferrer">账单与交易记录</a>。

---

## 用量一览

**用量一览** 按产品线展示动态流量与独享库存，常见有 **总量 GB**、**已用 GB**、**剩余 GB**，以及网页抓取 **积分** 等。状态包括 **生效中**、**即将到期**、**已过期**。

各产品明细请到对应代理控制台的 **已购**、**用量** 查看。

## 侧栏菜单

1. **概览**
2. **代理**（住宅、移动、商业 / ISP、数据中心、网页抓取，带 **购买** 快捷入口）
3. **帮助中心**（**提交工单**、**实时聊天**）
4. **我的账户**
5. **退出登录**

可在页脚或 **我的账户** → **资料** 中切换界面 **语言**。
