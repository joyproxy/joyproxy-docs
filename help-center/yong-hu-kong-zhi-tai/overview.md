# 控制台总览

**概览**是登录后的默认主页：<a href="https://www.joyproxy.com/admin-overview.html" target="_blank" rel="noopener noreferrer">admin-overview.html</a>。侧栏第一项为 **概览**。

---

## 页头与余额

- **JoyProxy 控制台**
- 标题：**欢迎**
- 说明：**住宅 / 移动 / Business / 数据中心 — 统一管理入口。**
- **账户余额**：提示 **点击余额查看账本 · 充值享阶梯赠送**
- **账户充值**：打开 Payment Hub 为余额充值
- 赠送：**满 $100 +10%，满 $1,000 +20%，满 $10,000 +30%（付款成功后计入余额）。**

点击余额通常进入 **我的账户** → **账单**，或 <a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">admin-transactions.html</a>。详见 <a href="invoices.md" target="_blank" rel="noopener noreferrer">账单与交易记录</a>。

---

## 用量一览

区块 **用量一览**— **按四大产品线查看动态流量与独享库存。**

常见指标：

| 区域 | 关键词 | 含义 |
| --- | --- | --- |
| 动态代理 | **总量 GB** / **已用 GB** / **剩余 GB** | 住宅、移动、商业等预付流量 |
| 独享代理 | **独享代理**、**静态与定制** | 静态 + 自定义独享库存 |
| 网页抓取 | **网页抓取 API**、**积分** | Credits 余额 |

状态标签：**生效中**、**即将到期**、**已过期**；无套餐时 **暂无有效套餐** / **暂无独享 IP**。

各产品线订单明细请在对应 <a href="residential-proxies.md" target="_blank" rel="noopener noreferrer">代理控制台</a> 的 **已购**、**用量** 查看，不要依赖已下线的全站「动态代理流量明细」独立页。

## 侧栏结构（普通用户）

登录后左侧主导航通常包括：

1. **概览**
2. **代理**（可展开）
   - **住宅代理**、**移动代理**、**商业 / ISP**、**数据中心**、**网页抓取**（各带 **购买** 快捷图标）
3. **帮助中心**（可展开）
   - **提交工单**
   - **实时聊天**
4. **我的账户**
5. **退出登录**

页脚或顶栏还可切换 **语言**，与 **我的账户** → **资料** 内语言设置联动。
