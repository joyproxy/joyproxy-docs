# 邮箱激活

部分账号在首次登录前需点击邮件中的链接完成验证。

---

## 操作步骤

1. 注册或登录时若提示未激活，打开注册邮箱（含垃圾邮件文件夹）。
2. 点击邮件里的激活链接。
3. 浏览器会打开激活页：
   - 处理中显示 **正在激活账户…**
   - 成功显示 **账户已激活！**，再点 **登录**
   - 失败显示 **激活链接无效或已过期。**
4. 返回 <a href="login.md" target="_blank" rel="noopener noreferrer">登录</a>，用邮箱密码或 Google / GitHub 登录。

---

## 重发激活邮件

在 <a href="https://www.joyproxy.com/login.html" target="_blank" rel="noopener noreferrer">登录页</a> 点击 **重发激活邮件**，勿重复注册多个账号。
