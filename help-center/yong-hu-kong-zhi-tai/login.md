# 登录

登录后进入 JoyProxy 管理后台，默认打开 <a href="overview.md" target="_blank" rel="noopener noreferrer">控制台总览</a>。

<a href="https://www.joyproxy.com/login.html" target="_blank" rel="noopener noreferrer">登录</a>

---

## 邮箱与密码

| 元素 | 文案 |
| --- | --- |
| 标题 | **登录** |
| 副标题 | **欢迎回到 JoyProxy** |
| 字段 | **邮箱**、**密码** |
| 按钮 | **登录**（**登录中…**） |
| 忘记密码 | **忘记密码？** → <a href="forgot-password.md" target="_blank" rel="noopener noreferrer">找回密码</a> |
| 注册入口 | **还没有账号？** → **注册** |

---

## Google / GitHub

分隔线 **或** 下方：

- **使用 Google 继续**
- **使用 GitHub 继续**

完成后与邮箱登录一样进入 **概览**。

---

## 账户尚未激活

提示：**账户尚未激活。请查收邮件并点击激活链接。**

可点击 **重发激活邮件**（发送中：**发送中…**；成功：**新的激活链接已发送，请查收邮箱（含垃圾邮件文件夹）。**）。详见 <a href="email-activation.md" target="_blank" rel="noopener noreferrer">邮箱激活</a>。

---

## 登录后建议

- **我的账户** → **安全与 API** 设置 <a href="idle-sign-out.md" target="_blank" rel="noopener noreferrer">无操作退出时间</a>。
- 勿在工单或聊天中发送各类 <a href="rotate-token.md" target="_blank" rel="noopener noreferrer">Token</a>。
- 共用设备用完后点击侧栏 **退出登录**。
