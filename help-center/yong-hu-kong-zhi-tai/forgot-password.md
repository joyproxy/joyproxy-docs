# 找回密码

无法使用当前密码登录时，通过注册邮箱收取重置链接。

<a href="https://www.joyproxy.com/forgot-password.html" target="_blank" rel="noopener noreferrer">忘记密码页</a>（页眉文案 ：**重置密码** — **输入邮箱，我们将发送重置链接。**）

也可从 <a href="https://www.joyproxy.com/login.html" target="_blank" rel="noopener noreferrer">登录</a> 点击 **忘记密码？**进入。

---

## 步骤

1. 输入注册时使用的 **邮箱**。
2. 点击 **发送重置链接**。
3. 查收邮件（含垃圾邮件），按链接设置新密码。
4. 使用新密码 **登录**。

说明：若邮箱存在于系统中，会发送重置链接；JoyProxy 不会在聊天中索要密码。

密码长度：注册至少 **8 位**；在控制台 **我的账户** 内修改密码时表单校验为至少 **6 个字符**。

---

## 仍无法登录

- 确认邮箱与注册一致，链接未过期（过期请重新申请）。
- <a href="../fu-wu-yu-zhi-chi/live-chat.md" target="_blank" rel="noopener noreferrer">实时聊天</a> 或 <a href="../fu-wu-yu-zhi-chi/tickets.md" target="_blank" rel="noopener noreferrer">提交工单</a>（侧栏 **帮助中心**），用注册邮箱证明归属。
