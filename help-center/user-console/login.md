# 登录

登录 JoyProxy 控制台后可购买产品、生成端点、管理账单。

## 登录步骤

1. 打开<a href="https://www.joyproxy.com/login.html" target="_blank" rel="noopener noreferrer">登录页</a>。
2. 输入**邮箱**和**密码**。
3. 登录成功后进入<a href="overview.md" target="_blank" rel="noopener noreferrer">概览</a>。

## 会话与安全

- 共用设备时，定期通过<a href="change-password.md" target="_blank" rel="noopener noreferrer">修改密码</a>更新密码。
- 办公室电脑可设置<a href="idle-sign-out.md" target="_blank" rel="noopener noreferrer">空闲自动退出</a>，缩短无人操作后的会话时间。
- <a href="rotate-token.md" target="_blank" rel="noopener noreferrer">API Token</a> 放在密钥管理工具里，不要发到聊天或工单。
