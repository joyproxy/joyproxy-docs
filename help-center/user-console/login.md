# Login

Access the JoyProxy dashboard to buy products, generate endpoints, and manage billing.

## Sign in

1. Visit [Log in](https://www.joyproxy.com/login.html).
2. Enter your **email** and **password**.
3. After success you are redirected to the [Overview](overview.md) dashboard.

## Session and security

- Use [Change password](change-password.md) regularly on shared machines.
- Configure [Idle sign-out](idle-sign-out.md) for shorter timeouts on office PCs.
- Store [API tokens](rotate-token.md) in secret managers—not in chat or tickets.

## First login checklist

| Task | Link |
| --- | --- |
| Review balance and credits | [Overview](overview.md) |
| Copy API token for automation | [Account settings](https://www.joyproxy.com/admin-settings.html) |
| Buy first proxy or scraping pack | [Purchase](https://www.joyproxy.com/admin-purchase.html) |
