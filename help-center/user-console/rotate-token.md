# Rotate API token

JoyProxy exposes API tokens for automation (endpoint generation, orders, etc.). Rotate a token if it may have leaked.

1. Open [Account settings](https://www.joyproxy.com/admin-settings.html).
2. Locate **API token** / **Master token** (see product docs for which token each API needs).
3. Generate a new token and update your integrations.
4. Revoke or replace the old token.
