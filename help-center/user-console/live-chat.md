# 实时聊天（Live Chat）

实时聊天是 JoyProxy 为用户提供的即时在线客服通道。当你在选购套餐、首次配置代理遇到阻碍或需要快速确认服务状态时，可以通过实时聊天获得在线技术人员的快速响应。

---

## 服务入口

你可以通过以下两种方式随时发起即时对话：

1. **控制台独立聊天页**  
   在控制台左侧导航栏点击 **实时聊天**，或在浏览器中直接打开 <a href="https://www.joyproxy.com/admin-support.html?tab=chat" target="_blank" rel="noopener noreferrer">实时聊天窗口</a>。
2. **右下角悬浮气泡**  
   无论是在 JoyProxy 官网首页还是控制台任意功能页面，点击右下角的 **蓝色客服气泡**，即可展开即时对话小窗。

---

## 适合实时聊天的业务场景

- **售前选购咨询**：不确定业务场景（如指纹浏览器防关联、跨境电商多店铺管理、自动化爬虫）适合动态住宅还是静态独享；
- **快速配置指引**：在 Chrome、Firefox、AdsPower 或 Python/Scrapy 中配置代理遇到认证失败，需现场排查；
- **充值与套餐到账确认**：刚完成充值或购买，需在线人工快速确认状态；
- **紧急故障咨询**：出现突发网络异常，确认是否为特定节点维护或整体服务波动。

---

## 高效排查建议

为了提高沟通效率，发起聊天时建议主动准备并提供以下脱敏信息：

- 当前注册的 **账户邮箱**（无需提供密码）；
- 涉及的产品网络类型（住宅动态、静态独享、自定义端口、抓取 API）与 **订单编号**；
- 出现问题时的 **报错截图**，或脱敏后的终端测试命令与错误输出；
- 账单类咨询：充值单号、USDT 交易哈希（TXID）或 PayPal 交易号。

## 实时聊天与工单系统的选择

| 维度 | 实时聊天（Live Chat） | 工单系统（Tickets） |
| --- | --- | --- |
| **响应速度** | 即时 / 数分钟内响应 | 异步处理 / 按照优先级队列排序 |
| **适用场景** | 紧急咨询、配置辅导、快速排查 | 复杂代码调试、账单审计、大客户定制 |
| **日志与附件** | 支持发送小截图与文本片段 | 支持上传完整日志文件与大图 |
| **追踪与归档** | 适合单次快速沟通 | 适合跨天跟进与多部门联动处理 |

对于需要长时间调取后端历史日志分析或需开具公司特定抬头发票的事宜，建议在聊天后由客服协助转为 <a href="tickets.md" target="_blank" rel="noopener noreferrer">工单系统</a> 进一步跟踪。
