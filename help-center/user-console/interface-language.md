# 界面语言

将 JoyProxy **控制台 UI** 切换为首选语言。在发布本地化副本前，营销页与本文档可能仍显示英文。

## 更改语言

1. 打开<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">账户设置</a>。
2. 找到 **Language** 或 **Interface language**。
3. 选择语言（例如 English、中文、日本語，取决于下拉可用项）。
4. 保存——控制台将以所选语言重新加载。

## 会变化的内容

- 管理控制台中的菜单、按钮与系统消息
- 在已配置时，邮件模板可能跟随账户语言

## 不会变化的内容

- 生成的代理用户名与 API 载荷（请始终严格使用返回值）
- 本 GitBook / 文档仓库（英文 v1）

需要其他语言帮助？客服在线时<a href="../support/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>支持多语言。
