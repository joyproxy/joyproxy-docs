# 界面语言设置

JoyProxy 控制台支持全站多语言适配。你可以根据团队成员的操作习惯随时切换控制台的界面显示语言。

---

## 如何切换语言

控制台提供两种便捷的语言切换入口：

### 方式一：在「我的账户」中设置（永久保存）
1. 打开控制台左侧主导航的 **我的账户**。
2. 在 **资料** 页签中找到 **语言** 下拉选择框。
3. 从列表中选择你的偏好语言（如 **简体中文**、**English**、**繁體中文** 等）。
4. 选择后系统会自动保存用户偏好，并立即刷新整个管理界面的文案。

### 方式二：在左侧菜单底部切换（快捷入口）
在控制台左侧菜单的最底部（或者桌面端顶栏），常驻有 **语言** 快捷切换菜单，点击即可展开支持的语言列表完成即时切换。

---

## 语言切换的作用范围说明

为了避免开发者产生歧义，语言切换的适用边界如下：

- **受影响的内容**：左侧导航菜单、各网络控制台标签页、按钮名称、表单说明文字、操作成功/失败的 Toast 浮窗提示等。
- **不受影响的内容**：
  - **代理节点连接凭据**：在「提取」页生成的动态代理认证参数（例如包含 `country-us_session-xxxx` 的用户名字符串）属于底层代理协议的控制指令，**绝不会**被翻译；
  - **API 接口数据**：OpenAPI 及网页抓取 API 返回的 JSON 字段名均为标准的英文字段；
  - **帮助中心文档**：帮助中心内容目前以中文为主要阅读语言，与控制台界面的偏好设置互不干扰。
