# 界面语言

把 JoyProxy **控制台界面**切换成你习惯的语言。营销页和本仓库文档在本地化完成前可能仍是英文。

## 更改语言

1. 打开<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">账户设置</a>。
2. 找到 **Language** 或 **Interface language**。
3. 在下拉框选择语言（如 English、中文、日本語，以实际列表为准）。
4. 保存后控制台会按所选语言刷新。

## 会跟着变的

- 管理台菜单、按钮、系统提示
- 已配置时，部分邮件模板可能跟随账户语言

## 不会变的

- 生成的代理用户名与 API 返回字段（请严格按返回值使用）
- 本 GitBook / 文档仓库（当前为英文 v1）

需要其他语言协助？客服在线时可通过<a href="../support/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>沟通。
