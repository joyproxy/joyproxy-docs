# 账单与交易记录（Invoices）

控制台提供了完善的财务流水查询与对账凭据下载中心，帮助企业财务与个人开发者核对每一笔充值与套餐消费明细。

你可以通过以下任一入口直达账单界面：
- 在左侧菜单进入 **我的账户**，切换到顶部的 **账单** 页签；
- 在 **控制台概览** 页顶部直接点击 **账户余额** 数值；
- 在浏览器中直接打开 <a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">独立账单页面</a>。

---

## 核心视图分区

账单中心由三个互为补充的子页签组成：

### 1. 余额变动（资金与充值账本）
记录与你的账户钱包余额相关的所有资金往来，是企业报销与财务审计的核心视图：
- **记录类型**：包含 PayPal / 国际信用卡 / 微信支付等充值入账流水、购买代理套餐时的余额扣减、自动续费扣费、退款返还以及系统人工增减赠送等。
- **单笔 PDF 账单**：每笔充值记录的操作列中均提供 **PDF** 下载按钮，点击即可实时生成包含订单号、支付网关流水号、明细金额与 JoyProxy 公司凭据抬头的正式商业账单。
- **批量导出**：在上方设定 **时间范围** 后点击 **应用筛选**，点击 **批量下载账单 (ZIP)** 即可将所选周期内的所有财务 PDF 凭证一键打包下载。

### 2. 订单记录（产品购买历史）
展示你在 JoyProxy 采购的所有产品订单档案：
- 涵盖住宅动态流量包、移动蜂窝网络套餐、静态独享线路、自定义定制端口以及网页抓取 Credits 积分包；
- 详细记录下单时间、购买规格时长、支付金额与订单当前生效状态。

### 3. 流量使用（动态代理小时用量）
专门针对动态预付流量设计的逐小时消耗汇总报表：
- 支持按产品网络类型（如家庭住宅动态、移动蜂窝网络）进行分类筛选；
- 展示不同时段内的原始流量与计费流量消耗趋势，协助开发者定位突发抓取峰值或业务异常。

## 账单管理与代理控制台的职责分工

- **查看生效中的资源**：如要查看某条静态独享线路的端口状态、更换出口 IP、设定自动续费或查看流量包的剩余 GB 数，请前往对应代理网络的控制台（如 **住宅代理** 或 **商业 / ISP**）的「已购」与「用量」页面进行操作。
- **处理财务与资金**：若要导出报销凭证、核实充值是否到账、查询月度总消费，请在本文档介绍的账单中心进行处理。

## 常见财务问题指引

- **USDT 充值未实时入账？**  
  若通过区块链转账后关闭了窗口，请进入 **我的账户** → **资料**，使用 **认领 USDT** 功能自动扫描链上记录即可即刻补齐入账。
- **单笔消费金额有疑问？**  
  请记录下具体的订单号与发生时间，通过左侧菜单进入 **帮助中心** 提交技术 <a href="../support/tickets.md" target="_blank" rel="noopener noreferrer">支持工单</a>，财务与技术团队会为你调取底层日志协助核对。
- **需要企业抬头专用发票？**  
  如需开具开票抬头包含特定企业名称与税号的商业发票，可通过右下角 <a href="../support/live-chat.md" target="_blank" rel="noopener noreferrer">实时聊天</a> 联系在线财务客服，提供抬头税号与接收邮箱即可安排开具。
