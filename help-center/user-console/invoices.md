# 发票与账单记录

在控制台查看充值、套餐购买与消费记录。

## 交易

<a href="https://www.joyproxy.com/admin-transactions.html" target="_blank" rel="noopener noreferrer">交易</a> 包含：

- PayPal 或余额**充值**
- 代理套餐**付款**
- 网页抓取 API **积分购买**

做账时使用页面提供的筛选或导出功能。

## 代理订单

<a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">My Proxies</a> 显示：

- **生效中**的轮换流量、静态分配、定制端口
- **已过期**历史，便于决定是否续费

| 产品类型 | 计费方式 |
| --- | --- |
| 轮换 | 有效期内从已购 GB 中扣流量 |
| 静态 / 定制 | 按 IP 或端口购买的有效期 |
| 网页抓取 API | 每次成功抓取扣积分 |
