# 修改密码

在账户区域更新 JoyProxy 登录密码。

## 步骤

1. 登录后打开<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">账户设置</a>。
2. 找到 **Change password**（多在安全或资料区域）。
3. 输入**当前密码**。
4. 输入**新密码**（6 位以上）并再次确认。
5. 点击 **Save changes**。

## 保存之后

- 其他浏览器或设备需重新登录。
- 自动化里若误存了登录密码，请一并更新；提取类脚本优先用 Endpoints 的 **API URL**（见<a href="rotate-token.md" target="_blank" rel="noopener noreferrer">轮换 Token</a>）。

不记得当前密码？用<a href="forgot-password.md" target="_blank" rel="noopener noreferrer">忘记密码</a>，不要用本表单。
