# 工单系统（Tickets）

工单系统是 JoyProxy 控制台提供的高效异步技术与商务支持通道。当你在使用代理网络、API 集成或财务账单过程中遇到需要技术核查、沟通记录留存或跨部门处理的复杂问题时，均可通过提交工单获得专业支持。

你可以通过以下方式直接进入工单管理界面：
- 在控制台左侧导航栏点击 **支持（Support）**；
- 在浏览器中直接打开 <a href="https://www.joyproxy.com/admin-support.html#tickets" target="_blank" rel="noopener noreferrer">工单系统页面</a>。

---

## 适用于工单处理的场景

与实时聊天相比，工单系统更适合处理以下事务：
- **复杂技术故障排查**：需要调取底层节点请求日志、抓包分析或分析网络连通性异常；
- **财务与对账事宜**：涉及企业发票开具、充值争议核对、定制合同或后付费账单管理；
- **账号与安全变更**：主邮箱更换、大客户专属权限开通、企业名下子账号归属变更等；
- **定制业务申请**：高并发网页抓取 API 额度提升、特定国家/地区节点定制或专属白名单设置。

## 新建工单与关键信息填写

进入 **支持（Support）** 页面后，点击右上角的 **+ 新建工单（+ New Ticket）** 按钮，填写以下内容：

### 1. 工单主题（Subject *）
请使用简明扼要的标题，例如：
- `[静态独享] 订单 #1024 出口 IP 连通超时`
- `[账单] USDT 转账已确认但余额未更新`
- `[网页抓取] /v1/fetch 请求特定目标返回 502 排查`

### 2. 设定优先级（Priority）
- **低（Low）**：常规咨询、文档疑问或非紧急功能建议；
- **中（Medium，默认）**：部分业务请求受阻、存在替代方案或一般性账单疑问；
- **高（High）**：线上采集业务中断、大量代理节点连接失败或严重影响生产环境的故障。

### 3. 详细描述问题（Issue Description *）
为了让技术支持团队最快定位问题，请在描述中提供充分的排查细节：
- **代理问题**：受影响的产品线（如住宅动态/静态独享）、认证方式（账密认证或 IP 白名单）、目标访问域名、具体报错响应码或 cURL 输出、发生时间（建议带上时区）。
- **账单问题**：相关充值订单号、支付方式（如 PayPal / USDT-TRC20）、转账哈希（TXID）或支付时间。
- **抓取 API 问题**：请求 Endpoint、传入参数、返回的状态码与 Response 错误信息片段。

### 4. 附加图片（Attach Image，可选）
支持上传 PNG、JPG、GIF 等格式的截图，单个文件大小建议不超过 5MB。
> ⚠️ **安全须知**：截图或日志中请务必遮挡或脱敏你的主用户 Token、代理密码或完整 API 凭证，以防敏感凭证泄露。

填写完毕后，点击 **提交工单（Submit Ticket）** 即可生成专属工单编号（如 `#1042`）。

## 工单跟进与状态流转

提交工单后，可在 **我的工单（My tickets）** 列表中实时查看工单进展：

### 1. 常见工单状态说明
| 状态名称 | 含义说明与建议操作 |
| :--- | :--- |
| **待处理（Pending）** | 工单已成功进入技术支持队列，正在分配对应领域的工程师处理。 |
| **处理中（In Progress）** | 工程师已接入排查或正在向网络运营商调取底层连通性报告。 |
| **已回复（Answered）** | 技术支持已给出解决方案或需要你提供更多补充信息。 |
| **已关闭（Closed）** | 问题已彻底解决或经双方确认结束沟通。若后续同一问题再次发生，可在 7 天内追加回复重新激活。 |

### 2. 追加回复与沟通
点击工单列表右侧的 **查看（View）** 即可打开完整对话详情。在底部的输入框中可继续追加文字说明或补充最新报错截图。建议在同一工单线程内保持连续沟通，避免针对同一问题重复开辟多条新工单。
