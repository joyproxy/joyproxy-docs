# 工单系统（Tickets）

工单系统是 JoyProxy 控制台提供的高效异步支持通道。当你在使用代理网络、API 集成或财务账单过程中遇到需要技术核查、沟通记录留存或跨部门处理的复杂问题时，均可通过提交工单获得专业支持。

你可以通过以下方式直接进入工单管理界面：
- 在控制台左侧导航栏点击 **工单系统**；
- 在浏览器中直接打开 <a href="https://www.joyproxy.com/admin-support.html?tab=tickets" target="_blank" rel="noopener noreferrer">工单系统页面</a>。

---

## 适用于工单处理的场景

与实时聊天相比，工单系统更适合处理以下事务：
- **复杂技术故障排查**：需要调取底层节点请求日志、抓包分析或分析网络连通性异常；
- **财务与对账事宜**：涉及企业发票开具、充值争议核对、定制合同或后付费账单管理；
- **账号与安全变更**：主邮箱更换、大客户专属权限开通、企业名下子账号归属变更等；
- **定制业务申请**：高并发网页抓取 API 额度提升、特定国家/地区节点定制或专属白名单设置。

## 新建工单与关键信息填写

进入 **工单系统** 页面后，点击右上角的 **+ 新建工单** 按钮，填写以下内容：

### 1. 选择分类与主题
- **问题分类**：根据诉求选择「代理连通与提取」「网页抓取 API」「账单与充值」「账号与权限」或「商务定制」。
- **工单主题**：请使用简明扼要的标题，例如 `[静态独享] 订单 #1024 出口 IP 连通超时` 或 `[账单] USDT 转账已确认但余额未更新`。

### 2. 设定优先级
- **低**：常规咨询、文档疑问或非紧急功能建议；
- **中（默认）**：部分业务请求受阻、存在替代方案或一般性账单疑问；
- **高**：线上抓取业务中断、大量代理节点连接失败或严重影响生产环境的故障。

### 3. 详细描述排查信息
为了让技术支持团队最快定位问题，请在描述中提供以下信息：
- **代理问题**：受影响的产品线（如家庭住宅动态/静态独享）、提取格式（账密认证或 IP 白名单）、目标访问域名、具体报错响应码或 cURL 输出、发生时间（建议带上时区）。
- **账单问题**：相关充值订单号、支付方式（如 PayPal / USDT-TRC20）、转账哈希（TXID）或支付时间。
- **抓取 API 问题**：请求 Endpoint、传入参数、返回的状态码与 Response 错误信息片段。

### 4. 附件上传（可选）
- 支持上传 PNG、JPG 截图或 TXT、LOG、PDF、DOCX 等日志文件（单文件限制 5MB 内）。
- **安全提醒**：切勿在工单内容或附件中直接粘贴账号密码、主用户 Token 或完整的支付私钥。

## 工单跟进与生命周期

提交成功后，系统将自动生成唯一工单编号（如 `#1048`）。你可以随时在 **我的工单** 列表中查看处理进度：

### 状态说明
- **待处理（Open）**：工单已提交，技术支持工程师正在核查；
- **待回复（Pending Customer Reply）**：工程师已针对你的问题进行解答或提出了进一步核验要求，等待你补充信息；
- **已解决（Resolved）**：问题已处理完成，经确认后归档；
- **已关闭（Closed）**：工单超过规定时间无后续追加回复自动关闭，或由用户手动关闭。

### 追加沟通
如需补充日志或回复工程师，请在工单详情页底部的 **回复内容** 框中直接追加，尽量在同一工单内保持上下文连贯，避免针对同一问题重复创建新工单。
