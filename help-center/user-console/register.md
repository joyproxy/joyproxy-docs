# 注册

先注册账号，再在控制台买代理流量或抓取积分。

## 步骤

1. 打开<a href="https://www.joyproxy.com/register.html" target="_blank" rel="noopener noreferrer">注册页</a>。
2. 填写邮箱、密码及页面要求的其他信息。
3. 提交表单。
4. 若系统提示，首次购买前完成<a href="email-activation.md" target="_blank" rel="noopener noreferrer">邮箱激活</a>。
5. <a href="login.md" target="_blank" rel="noopener noreferrer">登录</a>，进入<a href="overview.md" target="_blank" rel="noopener noreferrer">控制台概览</a>。

## 注册后建议

| 下一步 | 说明 |
| --- | --- |
| <a href="https://www.joyproxy.com/admin-purchase.html" target="_blank" rel="noopener noreferrer">购买</a> | 住宅、移动、商业、数据中心或抓取积分 |
| <a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">账户设置</a> | Master User Token、语言、安全选项 |
| <a href="https://www.joyproxy.com/pricing.html" target="_blank" rel="noopener noreferrer">定价</a> | 下单前对比套餐 |

> **提示**
>
> 新账号可获 **$5 注册赠金**，用于首笔符合条件的订单；结账时若页面有赠金选项，可直接选用。

已有账号？<a href="login.md" target="_blank" rel="noopener noreferrer">登录</a>。邮箱有问题？看<a href="email-activation.md" target="_blank" rel="noopener noreferrer">邮箱激活</a>或<a href="forgot-password.md" target="_blank" rel="noopener noreferrer">忘记密码</a>。
