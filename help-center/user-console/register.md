# Register

Create a JoyProxy account to purchase proxy traffic, scraping credits, and software integrations from one dashboard.

## Steps

1. Open <a href="https://www.joyproxy.com/register.html" target="_blank" rel="noopener noreferrer">Sign up</a>.
2. Enter email, password, and any required profile fields.
3. Submit the form.
4. If prompted, complete <a href="email-activation.md" target="_blank" rel="noopener noreferrer">email activation</a> before your first purchase.
5. <a href="login.md" target="_blank" rel="noopener noreferrer">Log in</a> and land on the <a href="overview.md" target="_blank" rel="noopener noreferrer">dashboard overview</a>.

## After registration

| Next step | Why |
| --- | --- |
| <a href="https://www.joyproxy.com/admin-purchase.html" target="_blank" rel="noopener noreferrer">Purchase</a> | Buy Residential, Mobile, Business, Datacenter, or scraping credits |
| <a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">Account settings</a> | Master User Token, language, security options |
| <a href="https://www.joyproxy.com/pricing.html" target="_blank" rel="noopener noreferrer">Pricing</a> | Compare packs before checkout |

> **Tip**
>
> New accounts receive a **$5 sign-up credit** toward the first eligible order—apply it at checkout when the console offers it.
