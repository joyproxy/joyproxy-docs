# Register

Create a JoyProxy account to purchase proxy traffic, scraping credits, and software integrations from one dashboard.

## Steps

1. Open [Sign up](https://www.joyproxy.com/register.html).
2. Enter email, password, and any required profile fields.
3. Submit the form.
4. If prompted, complete [email activation](email-activation.md) before your first purchase.
5. [Log in](login.md) and land on the [dashboard overview](overview.md).

## After registration

| Next step | Why |
| --- | --- |
| [Purchase](https://www.joyproxy.com/admin-purchase.html) | Buy Residential, Mobile, Business, Datacenter, or scraping credits |
| [Account settings](https://www.joyproxy.com/admin-settings.html) | Copy API tokens, set language, security options |
| [Pricing](https://www.joyproxy.com/pricing.html) | Compare packs before checkout |

> **Tip**
>
> New accounts receive a **$5 sign-up credit** toward the first eligible order—apply it at checkout when the console offers it.

Already have an account? Use [Login](login.md). Trouble with email? See [Email activation](email-activation.md) or [Forgot password](forgot-password.md).
