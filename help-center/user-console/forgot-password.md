# 忘记密码

无法登录控制台时，可按下面流程重置密码。

## 自助重置

1. 打开<a href="https://www.joyproxy.com/login.html" target="_blank" rel="noopener noreferrer">登录页</a>。
2. 点击 **Forgot password**（或页面上同类文案）。
3. 输入注册时用的**邮箱**。
4. 打开邮件里的重置链接，设置新密码（页面会标明最短长度，一般不少于 6 位）。
5. 在所有使用 JoyProxy 的设备上用新密码登录。

> **安全**
>
> 重置链接会过期；失效后重新申请邮件即可。客服不会在聊天里要密码，只会确认你是否已完成重置。

## 还是进不去？

- 确认用的是注册邮箱。
- 通过你能证明归属的邮箱域名，联系<a href="../support/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>或<a href="../support/tickets.md" target="_blank" rel="noopener noreferrer">支持工单</a>。

重置完成后，记得更新脚本和 CI 里保存的旧密码。
