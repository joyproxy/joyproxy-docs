# 注销账户

当您不再需要服务时，可申请永久关闭 JoyProxy 账户。

## 注销前

- 从<a href="invoices.md" target="_blank" rel="noopener noreferrer">交易</a>与 <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">My Proxies</a> 导出所需记录。
- 按<a href="https://www.joyproxy.com/terms.html" target="_blank" rel="noopener noreferrer">服务条款</a>取消或等待生效订单到期。
- 轮换并从 CI 中移除 API Token（<a href="rotate-token.md" target="_blank" rel="noopener noreferrer">轮换 Token</a>）。

## 自助（若提供）

1. 打开<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">账户设置</a>。
2. 找到 **Delete account** 或 **Close account**。
3. 确认身份并知悉数据删除政策。
4. 完成 UI 中关于余额或未结订单的提示。

## 协助注销

若控制台无删除选项，请用注册邮箱通过<a href="../support/tickets.md" target="_blank" rel="noopener noreferrer">工单</a>或<a href="../support/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>联系<a href="https://www.joyproxy.com/admin-support.html" target="_blank" rel="noopener noreferrer">支持</a>。

JoyProxy 按<a href="https://www.joyproxy.com/privacy.html" target="_blank" rel="noopener noreferrer">隐私政策</a>处理注销。若可能，请在删除前解决账单争议。
