# 注销账户

不再使用服务时，可申请永久关闭 JoyProxy 账号。

## 注销前

- 从<a href="invoices.md" target="_blank" rel="noopener noreferrer">交易</a>与 <a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">My Proxies</a> 导出需要的记录。
- 按<a href="https://www.joyproxy.com/terms.html" target="_blank" rel="noopener noreferrer">服务条款</a>取消订单，或等生效订单到期。
- 轮换并从 CI 中移除 API Token（见<a href="rotate-token.md" target="_blank" rel="noopener noreferrer">轮换 Token</a>）。

## 自助（控制台有入口时）

1. 打开<a href="https://www.joyproxy.com/admin-settings.html" target="_blank" rel="noopener noreferrer">账户设置</a>。
2. 找到 **Delete account** 或 **Close account**。
3. 完成身份确认，并阅读数据删除说明。
4. 按页面提示处理余额或未结订单。

## 需要人工协助

控制台没有删除入口时，用注册邮箱通过<a href="../support/tickets.md" target="_blank" rel="noopener noreferrer">工单</a>或<a href="../support/live-chat.md" target="_blank" rel="noopener noreferrer">在线客服</a>联系<a href="https://www.joyproxy.com/admin-support.html" target="_blank" rel="noopener noreferrer">支持</a>。

JoyProxy 按<a href="https://www.joyproxy.com/privacy.html" target="_blank" rel="noopener noreferrer">隐私政策</a>处理注销。有账单争议时，建议先处理再申请删除。
