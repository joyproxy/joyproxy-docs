# Overview

**Overview** is the default workspace after you Log In. It brings together account funds, live usage, shortcuts into each proxy console, and official open-source tools so you can see how the account is running in one place.

<a href="https://www.joyproxy.com/admin-overview.html" target="_blank" rel="noopener noreferrer">Open Overview</a>

---

## Account funds and recharge

The top of Overview shows your core balance board:

- **Available Balance**: The USD amount you can spend on proxy plans, dedicated ports, or Web Scraping API Credits. Click the figure to open the ledger.
- **Recharge Account**: Opens Payment Hub. Supported methods include PayPal, Credit Card, WeChat Pay, UPI, and USDT (TRC20).
- **Recharge bonus tiers**: Larger single top-ups add extra balance automatically:
  - **$100** in one payment: extra **10%**;
  - **$1,000** in one payment: extra **20%**;
  - **$10,000** in one payment: extra **30%**.  
  The bonus is added to Available Balance as soon as payment succeeds.

## Usage snapshot

The center panel summarizes proxy resources so you do not have to open every order:

- **Rotating Proxies**: Prepaid traffic across Residential, Mobile, and Business / ISP, shown as **Total GB**, **Used GB**, and **Remaining GB**.
- **Dedicated Proxies**: Active Static Proxies and Custom Proxies counts, with **Expiring** and **Expired** markers.
- **Web Scraping API**: Remaining Credits and the concurrency limit.

> **Tip**: For per-order expiry, concrete IP addresses, or hourly traffic curves, open that network’s console.

## Open-source software and support

The bottom of Overview links to official companion tools:

- **Browser Extension**: Switch proxies and fingerprint settings in Chrome, Edge, and other Chromium browsers;
- **Proxy Tester**: Desktop batch checks for connectivity, exit geo, and latency over HTTP and SOCKS5;
- **Proxy Server / Client**: Self-hosted gateway plus Android Client for team clusters or mobile devices.

If something is unclear in daily use, open **Help Center** at the bottom of the left sidebar and start <a href="live-chat.md" target="_blank" rel="noopener noreferrer">Live Chat</a> or submit a <a href="tickets.md" target="_blank" rel="noopener noreferrer">Tickets</a> request.
