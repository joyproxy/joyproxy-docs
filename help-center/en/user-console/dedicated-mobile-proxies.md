# Dedicated Mobile Proxies Console

Open **Proxies → Dedicated Mobile** (`/admin-proxy-mobile-dedicated.html`) in the sidebar to reserve and manage your physical 4G/5G SIM ports:

- **Reserve / Buy**: Filter 17 countries & 31 carriers (including 5G-only filter), pick 2 / 7 / 14 / 30-day unlimited plans, and click **Reserve Now · Ready in 24h**.
- **My Proxies**: Track Pending, Active, Expiring, and Expired counts; copy HTTP/SOCKS5/AdsPower credentials, trigger one-click or API IP rotation, add custom notes, renew, or open support tickets.
- **Overview & Billing**: Usage tiles, 6-month spending breakdown, and transaction filters automatically include Dedicated Mobile Proxies.
