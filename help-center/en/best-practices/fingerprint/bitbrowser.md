# BitBrowser proxy setup and bulk import

BitBrowser supports a single profile and bulk import. This page shows how to attach JoyProxy proxies.

---

## Single profile

1. Open BitBrowser and click **New browser**;
2. In proxy settings, choose **Custom**;
3. Protocol: `HTTP` or `SOCKS5`;
4. Enter the Entry Point hostname (for example `us-ca.edge.joyproxy.com`), port, and Username/Password;
5. Click **Check proxy** to verify connectivity and exit IP;
6. Confirm and save.

---

## Bulk import

1. On the window list, click **Batch import**;
2. Download the Excel template;
3. Fill in window name, protocol, Entry Point hostname, port, and Username/Password;
4. Upload the file to import and run a batch check.
