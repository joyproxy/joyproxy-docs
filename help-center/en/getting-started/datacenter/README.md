# Datacenter Proxies (Static)

**Datacenter Proxies** deliver ultra-low latency, high throughput, and cost-efficient static IPs on enterprise hosting ASNs. Billed by IP count × duration with **unlimited traffic and concurrency**, each line provides a dedicated fixed `host:port` (such as `dc.joyproxy.com:port`) exclusively for your account.

---

## Key Specifications

| Feature | Details |
| :--- | :--- |
| **Product Mode** | Static Dedicated (per IP × duration, **unlimited traffic & concurrency**) |
| **IP Source** | Dedicated enterprise datacenter ASN IPs |
| **Reference Bandwidth** | ~20–300 Mbps per line |
| **Connection** | Fixed `host:port` (HTTP / HTTPS / SOCKS5), supports Username/Password or IP Whitelist |
| **Exit IP Refresh** | Region locked at checkout; free manual **Change IP** in the same region via console |
| **Pricing** | From `$2.00/IP/mo` down to `$1.00/IP/mo` for 100+ IPs; 1/7/30/90/180/365-day plans ([view pricing](https://www.joyproxy.com/pricing.html?network_type=hosting)) |
| **Best For** | Bulk public data monitoring, API forwarding, SERP tracking, performance testing |
