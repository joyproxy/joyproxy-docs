# Check usage

In the JoyProxy console you can watch Rotating Proxies consumption in real time and as history.

## Where to look

1. Log in and open **<a href="https://www.joyproxy.com/admin-overview.html" target="_blank" rel="noopener noreferrer">Overview</a>** in the left menu, or open the **Usage** tab in a network console.
2. Key metrics:
   - **Traffic quota**: Total GB, Used GB, and Remaining GB for the current pack.
   - **Usage trend chart**: view consumption by day, week, or month.
3. If **<a href="https://www.joyproxy.com/admin-my-orders.html" target="_blank" rel="noopener noreferrer">My Proxies</a>** has more than one Rotating Proxies order, the page shows remaining traffic for all active packs combined.

> 💡 **Balance and usage via API**  
> To query remaining traffic from an internal dashboard, see **<a href="https://www.joyproxy.com/admin-openapi.html" target="_blank" rel="noopener noreferrer">OpenAPI Center</a>** or **<a href="../../best-practices/developer/buy-and-renew.md" target="_blank" rel="noopener noreferrer">Query balance and orders via API</a>**.
