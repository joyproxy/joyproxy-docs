# Restricted targets and compliance

To keep the cloud network healthy and compliant, Web Scraping API blocks high-risk destinations.

---

## Categories that are blocked

Web Scraping API detects and rejects fetches in these areas:

- **Finance and payment gateways**: online-banking login pages, card-payment APIs, securities trading platforms.
- **Government and public agencies**: government portals, public-safety and identity gateways.
- **Private communications**: personal webmail, social-network private-message APIs, bulk spam posting.

For acceptable-use rules and liability, see the **<a href="https://www.joyproxy.com/terms.html" target="_blank" rel="noopener noreferrer">JoyProxy Terms of Service</a>**.
