# Generate proxy endpoints

In the console, you can generate a list of the Static Proxies endpoints you purchased.

---

## Web generator (console)

1. Open **<a href="https://www.joyproxy.com/admin-ip-extraction-center.html" target="_blank" rel="noopener noreferrer">Endpoint generator</a>**.
2. Choose the matching network and switch to the **Static Proxies** tab.
3. In the filter area:
   - Narrow by country/region or the search box.
   - Choose **Protocol**: `HTTP / HTTPS / SOCKS5`.
   - Choose **Output format**: `host:port` or a standard URI.
4. Click **Generate now**, then **Copy host:port list** to copy the endpoints, or export them as CSV/JSON/TXT.
