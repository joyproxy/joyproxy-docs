# Network types and how to choose

Static Proxies are billed by line and duration. **Dedicated 4G/5G Mobile Proxies (Static 4G/5G)**, **ISP Proxies**, and **Datacenter Proxies** are available (<a href="https://www.joyproxy.com/pricing.html" target="_blank" rel="noopener noreferrer">see current pricing</a>):

---

## Static dedicated network comparison

| Network | IP source and trust | Strengths | Typical use |
| --- | --- | --- | --- |
| **Dedicated 4G/5G Mobile Proxies** | Real physical 4G/5G SIM card slots (carrier CGNAT) | **Highest mobile trust + fixed static port + unlimited traffic + on-demand IP switch**. | High-trust AI accounts, TikTok/Instagram social media, Amazon/PayPal e-commerce anti-ban (<a href="../dedicated-mobile/">see guide</a>). |
| **ISP Proxies** | Carrier business ISP dedicated lines | **High trust + dedicated bandwidth**. Faster and more stable than typical residential, with a business ISP identity. | Long-lived B2B portal access, cross-border enterprise logins, high-throughput stable transfers, accounts that need a fixed identity. |
| **Datacenter Proxies** | Enterprise datacenter ASN lines | **Very low latency, high throughput, strong value**. | Large-scale public data monitoring, API forwarding, performance tests. |

---

## How to choose

1. **Highest anti-ban trust for AI, social media, and e-commerce accounts** ➔ **Dedicated 4G/5G Mobile Proxies** (real 4G/5G static devices, unlimited traffic, on-demand IP switch).
2. **Long-lived identity, enterprise links, and B2B data exchange** ➔ **ISP Proxies** (speed plus trust).
3. **High concurrency, high throughput, budget-sensitive** ➔ **Datacenter Proxies**.

> **Tip**: If you require ultra-low latency or high dedicated bandwidth, please submit a ticket to apply for Private Proxies.
