# Residential Proxies (Rotating)

**Residential Proxies** route traffic through real home broadband networks across 200+ countries and 25,000+ cities (such as Comcast, AT&T, and Verizon). Traffic is billed per GB and **never expires**. All connections use the unified rotating gateway `gate.joyproxy.com:9001`, supporting per-request rotation or 1–1440 minute sticky sessions.

---

## Key Specifications

| Feature | Details |
| :--- | :--- |
| **Product Mode** | Rotating (pay-per-GB, traffic never expires) |
| **IP Source** | Real home broadband ISPs with high site trust |
| **Gateway** | Shared gateway `gate.joyproxy.com:9001` (HTTP / HTTPS / SOCKS5) |
| **Targeting** | Country (ISO-2), state/province, city, and carrier/ASN |
| **Pricing** | From `$3.50/GB` (1 GB starter) down to `$1.00/GB` at volume ([view pricing](https://www.joyproxy.com/pricing.html?network_type=residential)) |
| **Best For** | E-commerce price monitoring, SERP collection, locale verification, large-scale web scraping |
