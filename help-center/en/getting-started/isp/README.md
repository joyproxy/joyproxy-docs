# ISP (Static Residential) Proxies

**ISP (Static Residential) Proxies** provide dedicated static residential exits hosted on genuine carrier ISP lines, combining residential reputation with low-latency stability. Billed by IP count × duration with **unlimited traffic and concurrency**, each line gives you a fixed `host:port` (such as `isp.joyproxy.com:port`) exclusively for your account.

---

## Key Specifications

| Feature | Details |
| :--- | :--- |
| **Product Mode** | Static Dedicated (per IP × duration, **unlimited traffic & concurrency**) |
| **IP Source** | Carrier ISP static residential ASN (choose country, city, and carrier/ASN at checkout) |
| **Reference Bandwidth** | ~10–100 Mbps per line |
| **Connection** | Fixed `host:port` (HTTP / HTTPS / SOCKS5), supports Username/Password or IP Whitelist |
| **Exit IP Refresh** | Region locked at checkout; free manual **Change IP** in the same region via console |
| **Pricing** | From `$3.00/IP/mo` down to `$2.40/IP/mo` at volume; 1/7/30/90/180/365-day plans ([view pricing](https://www.joyproxy.com/pricing.html?network_type=isp)) |
| **Best For** | E-commerce accounts, antidetect browsers, B2B portals, long-lived static sessions |
