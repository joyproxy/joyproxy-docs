## How to buy

- Open [Purchase → Rotating](https://www.joyproxy.com/admin-purchase.html?tab=short-term)
- Select network type **Mobile**
- Choose a traffic package and pay

## Authorize, generate endpoints, and use

Mobile Rotating uses the same gateway as Rotating Residential: `gate.joyproxy.com:9001`, credentials required, generated username as-is. IP whitelist for Rotating is coming soon.

- **2.2 Rotating → Whitelist & Users** — create username/password
- **2.2 Rotating → Generate endpoints** — same Endpoints UI; your Mobile order appears there
- **2.2 Rotating → Code & third-party software**
