# Integrate Proxies in AI

Use JoyProxy with OpenClaw Skill, AI MCP, and AI assistants across Residential / Mobile rotating lines and other SKUs.

- Create Rotating **username/password** in [Whitelist & Users](https://www.joyproxy.com/admin-authorization.html) (IP whitelist for Rotating is coming soon)
- Get an **API token** from the Endpoint generator / OpenAPI Center
- Open the [OpenClaw Skill page](https://www.joyproxy.com/products/openclaw-skill.html) for setup
- For IDE tools, use **AI MCP** with your AI Access Token
- Test endpoint APIs in [OpenAPI Center](https://www.joyproxy.com/admin-openapi.html)

**🤖 Note**AI Access Token cannot connect to the Rotating gateway. Use the generated endpoint username plus the Whitelist & Users password. AI tokens are separate from the API token.
