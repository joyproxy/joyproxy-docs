# Proxy Server

High-performance open-source HTTP/SOCKS5 gateway for Linux and Windows.

- Read the [Proxy Server product page](https://www.joyproxy.com/products/proxy-server.html)
- Download binaries from [GitHub Releases](https://github.com/joyproxy/joyproxy-server/releases/latest)
- Choose a startup mode (open, whitelist, password, API auth, or combined)
- Point upstream at JoyProxy endpoint credentials from [Endpoint generator](https://www.joyproxy.com/admin-ip-extraction-center.html), or use as a local entry proxy
- Optionally enable auth and traffic reporting HTTP APIs for integration
