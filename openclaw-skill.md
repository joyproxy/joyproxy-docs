# OpenClaw Skill

Use natural language to generate rotating residential proxy endpoints and check balance in OpenClaw.

- Read the [OpenClaw Skill product page](https://www.joyproxy.com/products/openclaw-skill.html)
- Open [AI endpoint generator](https://www.joyproxy.com/admin-ip-extraction-center.html?panel=ai) → copy AI Access Token
- In OpenClaw chat, ask the AI to learn `https://api.joyproxy.com/Skill` with your token
- Use the prompt examples on the product page
