# Register & Login

Create your JoyProxy account and access the dashboard.

**Register**
- Open [Sign Up](https://www.joyproxy.com/register.html)
- Complete email verification if required
- Sign in at [Log In](https://www.joyproxy.com/login.html)

**After login**
- Open [Dashboard](https://www.joyproxy.com/admin-overview.html)
- Go to [Account Settings](https://www.joyproxy.com/admin-settings.html) for tokens
- Copy **API token** for proxy API / endpoint generation
- **Master Token** is for order management APIs only
